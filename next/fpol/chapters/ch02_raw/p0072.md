2.5. 조밀 라인/스페이스 패턴의 회절 패턴이 피치가 무한대로 갈수록(일정한 스페이스 폭에서) 고립 스페이스의 회절 패턴이 됨을 보여라. 이는 다음을 증명하는 것과 같다

$$\lim_{p \to \infty} \frac{1}{p} \sum_{j=-\infty}^{\infty} \delta\left(f_x - \frac{j}{p}\right) = 1$$

2.6. 상보적(complimentary) 마스크 피처(예를 들어, 동일 폭의 고립 라인과 고립 스페이스)는 다음과 같이 정의된다

$$t_{\text{m}}^{\text{c}}(x, y) = 1 - t_{\text{m}}(x, y)$$

상보적 마스크 피처의 회절 패턴이 다음과 같이 주어짐을 증명하라

$$t_{\text{m}}^{\text{c}}(f_x, f_y) = \delta(f_x, f_y) - T_{\text{m}}(f_x, f_y)$$

이 식을 사용하여 고립 라인의 회절 패턴을 유도하라.

2.7. 푸리에 변환이 선형 연산임을 보여라. 즉, 두 함수 $f(x, y)$와 $g(x, y)$, 그리고 두 상수 $a$와 $b$에 대해 다음을 보여라

$$\mathcal{F}\{af(x, y) + bg(x, y)\} = aF(f_x, f_y) + bG(f_x, f_y)$$

2.8. 푸리에 변환의 이동 정리를 증명하라:

$$\text{만약 } \mathcal{F}\{g(x, y)\} = G(f_x, f_y) \text{이면, } \mathcal{F}\{g(x - a, y - b)\} = G(f_x, f_y) \mathrm{e}^{-i2\pi(f_x a + f_y b)}$$

2.9. 푸리에 변환의 닮음 정리를 증명하라:

$$\text{만약 } \mathcal{F}\{g(x, y)\} = G(f_x, f_y) \text{이면, } \mathcal{F}\{g(ax, by)\} = \frac{1}{|ab|} G\left(\frac{f_x}{a}, \frac{f_y}{b}\right)$$

2.10. 푸리에 변환의 컨볼루션 정리를 증명하라:

$$\text{만약 } \mathcal{F}\{g(x, y)\} = G(f_x, f_y) \text{ 이고 } \mathcal{F}\{h(x, y)\} = H(f_x, f_y) \text{이면,}$$

$$\mathcal{F}\left\{\int \int_{-\infty}^{\infty} g(\xi, \eta) h(x - \xi, y - \eta) \mathrm{d}\xi \mathrm{d}\eta\right\} = G(f_x, f_y) H(f_x, f_y)$$
