[Table 9.1] 리소그래피 공정 단계 및 해당 정보 지표 요약

| 공정 단계 | 정보 | 오차 원인 | 정보 지표 |
| :--- | :--- | :--- | :--- |
| 설계 (Design) | 폴리곤, 바이너리 | (일반적으로 완벽하다고 가정됨) | |
| 마스크 (Mask) | 진폭 투과율, $t_m(x,y)$ | CD 및 정합 오차, 모서리 라운딩, 위상 및 투과율 | |
| 공간상 (Aerial Image) | $I(x,y)$ | 회절 한계, 수차, 디포커스, 플레어, 편광 | NILS |
| 레지스트 내 이미지 (Image in Resist) | $I(x,y,z)$ | 기판 반사/박막 효과, 편광 효과, 레지스트를 통과하는 디포커스 | NILS |
| 노광 (Exposure) | 잠상 $m(x,y,z)$ 또는 $h(x,y,z)$ (PEB 전) | 노광량 오차 | 잠상 기울기 (Latent image gradient) |
| 노광 후 베이크 (Post-exposure Bake) | 잠상 $m^*(x,y,z)$ (PEB 후) | 열적 선량 오차, 확산 | 잠상 기울기 (Latent image gradient) |
| 현상 (Development) | 현상 속도 $r(x,y,z)$ + 레지스트 프로파일 (CD, 측벽 각도, 레지스트 손실) | 유한한 콘트라스트, $r_{\max}/r_{\min}$ | 현상 속도 로그 기울기, 감마 + 노광 관용도, CD 오차 |

현상과 확산을 포함한다. NILS는 예측 가능한 방식으로 초점에 따라 저하되므로, 최종 식 (9.88)은 최종 CD 제어에 미치는 초점과 노광의 영향을 모두 포착하는 간단한 수단을 제공한다. 분명히, 이 간단한 기울기 접근법은 한계가 있다. 특히, 등초점 바이어스(isofocal bias)가 초점 심도에 미치는 영향은 기울기만 봐서는 포착되지 않는다. 그러나 정규화된 이미지 로그 기울기의 사용으로 구체화된 기울기 기반 최적화는 전체 리소그래피 최적화를 위한 매우 강력한 이론 기반 가이드임이 입증되었다.

미분의 연쇄 법칙은 공정의 각 단계의 효과를 식별하기 위한 간단한 접근 방식을 제공한다.

$$ \frac{\partial \ln R}{\partial x} = \left( \frac{\partial \ln R}{\partial m^*} \right) \left( \frac{\partial m^*}{\partial m} \right) \left( \frac{\partial m}{\partial \ln E} \right) \left( \frac{\partial \ln I}{\partial x} \right) \tag{9.100} $$

이 식을 리소그래피 이미징 식 (9.53)과 비교하면 포토레지스트 콘트라스트가 노광, PEB, 현상의 결합된 지표임을 알 수 있다.

$$ \gamma = \left( \frac{\partial \ln R}{\partial m^*} \right) \left( \frac{\partial m^*}{\partial m} \right) \left( \frac{\partial m}{\partial \ln E} \right) \tag{9.101} $$
