## CLT와 뭐가 다른가

2.5에서 CLT를 배웠다. "표본 평균의 분포가 정규분포에 가까워진다." 이번에 배울 LLN은 이렇다:

> **표본 평균의 값이 모평균에 가까워진다.**

비슷해 보이지만 말하는 것이 다르다.

- **CLT**: 표본 평균의 **분포의 형태**를 말한다. "종 모양이 된다."
- **LLN**: 표본 평균의 **값의 수렴**을 말한다. "특정 숫자에 가까워진다."

비유를 하나 들겠다. 활을 쏜다고 하자.

- **LLN**: "화살을 많이 쏠수록, 평균 적중점이 과녁 중심에 가까워진다." (표본 평균이 모평균에 수렴한다)
- **CLT**: "화살을 많이 쏠수록, 평균 적중점의 분포가 정규분포 모양이 된다." (흩어짐의 형태를 말한다)

## LLN이 말하는 것

### 수식

$X_1, X_2, \ldots, X_n$이 평균 $\mu$인 분포에서 i.i.d.로 뽑힌 표본이면:

$$\bar{X}_n = \frac{1}{n}\sum_{i=1}^{n} X_i \xrightarrow{P} \mu \quad \text{as } n \to \infty$$

"표본을 많이 모을수록, 표본 평균이 모평균에 가까워진다."

### 이것이 왜 자명하지 않은가

"평균을 많이 내면 진짜 값에 가까워진다"는 것이 당연해 보일 수 있다. 하지만 수학적으로는 전혀 자명하지 않다.

2.2에서 본 코시 분포를 기억하는가? 코시 분포에서 뽑아서 평균을 내면, 아무리 $n$을 키워도 특정 값으로 수렴하지 않는다. 기댓값 자체가 존재하지 않기 때문이다.

LLN은 "어떤 조건에서 표본 평균이 수렴하는가"를 명확히 한 정리다. 핵심 조건은:

- 데이터가 **독립**이어야 한다
- **동일한 분포**에서 나와야 한다
- 기댓값이 **존재**(유한)해야 한다

이 조건 중 하나라도 깨지면 수렴이 보장되지 않는다.

<details>
<summary>🔬 Deep Dive — 약한 LLN과 강한 LLN</summary>

LLN에는 두 가지 버전이 있다.

**약한 큰 수의 법칙 (Weak LLN, WLLN):**

$$\bar{X}_n \xrightarrow{P} \mu$$

확률 수렴(convergence in probability). 임의의 $\epsilon > 0$에 대해:

$$P(|\bar{X}_n - \mu| > \epsilon) \to 0 \quad \text{as } n \to \infty$$

"$\bar{X}_n$이 $\mu$에서 $\epsilon$ 이상 벗어날 확률이 0으로 간다." 분산이 유한하면 성립한다 (체비셰프 부등식으로 증명 가능).

**강한 큰 수의 법칙 (Strong LLN, SLLN):**

$$\bar{X}_n \xrightarrow{a.s.} \mu$$

거의 확실한 수렴(almost sure convergence).

$$P\left(\lim_{n \to \infty} \bar{X}_n = \mu\right) = 1$$

"$\bar{X}_n$이 $\mu$에 수렴할 확률이 1이다." 더 강한 결론이고, i.i.d.이면서 기댓값이 유한하면 성립한다. WLLN도 마찬가지로 기댓값만 유한하면 충분하다(Khintchine의 정리). 다만 체비셰프 부등식으로 증명하는 경로에서는 분산 유한 조건이 필요하다.

실무적으로 두 버전의 차이를 체감할 일은 거의 없다. 중요한 것은 "충분히 많이 모으면 수렴한다"는 보장 자체다.

## ML에서 LLN이 작동하는 현장

### 1. 학습 곡선의 수렴

모델을 학습시키면 loss가 점점 줄어들다가 안정된다. 이 수렴의 뒤에 LLN이 있다.

SGD에서 각 미니배치의 gradient는 전체 gradient의 **노이즈 낀 추정값**이다. 하지만 학습이 진행되면서 가중치가 업데이트될 때, 효과적으로 수많은 gradient 추정값을 "누적 평균"내는 것과 비슷한 일이 일어난다. LLN에 의해, 이 누적 효과가 진짜 gradient 방향으로 수렴한다.

물론 실제 SGD는 i.i.d. 조건을 완벽히 만족하지 않는다 — 가중치가 업데이트되면 gradient의 분포도 바뀌니까. 하지만 학습률이 충분히 작고 학습이 안정적이면, LLN의 직관이 대체로 적용된다.

```
Epoch 1:  loss = 2.341  (추정이 불안정)
Epoch 5:  loss = 0.892  (방향을 잡아감)
Epoch 20: loss = 0.234  (수렴에 가까워짐)
Epoch 50: loss = 0.231  (안정화)
Epoch 100: loss = 0.230  (변화 거의 없음)
```

### 2. 몬테카를로 방법

적분을 풀기 어려울 때 난수를 써서 근사하는 기법이 **몬테카를로(Monte Carlo)** 방법이다. LLN이 이것의 이론적 보장이다.

예를 들어 $E[g(X)]$를 계산하고 싶은데 해석적으로 풀 수 없다면:

$$E[g(X)] \approx \frac{1}{n}\sum_{i=1}^{n} g(x_i), \quad x_i \sim P(X)$$

분포에서 $n$개 뽑아서 $g(x_i)$의 평균을 구한다. LLN에 의해 $n \to \infty$이면 이 근사가 정확해진다.

ML에서 어디에 쓰이는가?

- **기대 손실 추정**: 2.2에서 봤듯이, 학습 데이터의 평균 손실로 기대 손실을 근사하는 것이 몬테카를로다
- **Dropout의 추론**: 학습 시 랜덤 드롭아웃을 적용하고, 추론 시 여러 번 샘플링해서 평균 내는 MC Dropout
- **강화학습의 리턴 추정**: 에피소드를 많이 돌려서 기대 보상을 평균으로 추정
- **VAE의 ELBO**: 재매개변수화 트릭으로 기댓값을 몬테카를로 근사

```python
# 몬테카를로로 π 추정하기 — LLN의 가장 유명한 예제
n = 100000
x = np.random.uniform(0, 1, n)
y = np.random.uniform(0, 1, n)

inside_circle = (x**2 + y**2) <= 1
pi_estimate = 4 * inside_circle.mean()

print(f"π 추정값: {pi_estimate:.5f} (실제: {np.pi:.5f})")
```

### 3. 경험적 분포 → 진짜 분포

LLN의 가장 일반적인 버전은 **Glivenko-Cantelli 정리**로 확장된다. 이것은 표본의 경험적 CDF가 모집단의 CDF에 균등하게 수렴한다는 것이다.

$$\sup_x |F_n(x) - F(x)| \to 0 \quad \text{a.s.}$$

직관적으로: 데이터를 많이 모을수록, `np.histogram(data)`가 그리는 모양이 진짜 분포의 모양에 가까워진다. 히스토그램이 "의미 있는" 이유가 이 정리다. 데이터가 적으면 히스토그램이 진짜 분포를 반영하지 못할 수 있지만, 충분히 많으면 반영한다.

## LLN이 깨지는 경우

LLN의 조건을 다시 보자: 독립, 동일 분포, 기댓값 유한. 각각이 깨지면:

### 기댓값이 무한 (코시 분포)

```python
from scipy.stats import cauchy

# 코시 분포: E[X]가 존재하지 않음
n_values = [10, 100, 1000, 10000, 100000]
for n in n_values:
    sample_mean = cauchy.rvs(size=n).mean()
    print(f"n={n:>6}: 표본평균 = {sample_mean:>10.2f}  (수렴 안 함!)")
```

$n$이 아무리 커져도 표본 평균이 안정되지 않는다. 극단적인 이상치가 가끔 등장해서 평균을 확 끌어간다.

### 독립이 아닌 경우

시계열 데이터에서 연속된 관측값은 독립이 아니다. 양의 자기상관이 있으면, 표본 평균이 진짜 평균 주변을 오랫동안 맴돌다가 갑자기 확 이동하는 패턴을 보인다. 수렴은 하지만 **매우 느리게** 수렴한다.

### 동일 분포가 아닌 경우 (분포 이동)

학습 데이터와 테스트 데이터의 분포가 다르면 — 이것이 **분포 이동(distribution shift)** — 학습 데이터에서 계산한 경험적 위험이 테스트 데이터의 진짜 위험에 수렴하지 않는다. LLN의 "동일 분포" 조건이 깨진 것이다.

구체적인 예: 반도체 공정에서 장비 A의 데이터로 학습한 모델을 장비 B에 적용하면, 장비 간 미세한 특성 차이 때문에 성능이 떨어진다. 계절별로 온습도가 달라지면 공정 데이터의 분포도 바뀐다. 의료 영상에서는 병원마다 다른 장비, 다른 프로토콜이 분포 이동을 일으킨다.

이것이 ML에서 가장 흔하게 LLN이 실패하는 시나리오다. 학습 데이터에서 loss가 작아도 프로덕션에서 성능이 나쁜 이유.

## LLN과 CLT: 한 장으로 정리

| | LLN | CLT |
|--|-----|-----|
| 말하는 것 | $\bar{X}_n$의 **값**이 $\mu$에 가까워진다 | $\bar{X}_n$의 **분포**가 정규분포에 가까워진다 |
| 핵심 질문 | "어디로 수렴하는가?" | "어떤 모양으로 수렴하는가?" |
| 필요 조건 | 기댓값 유한 | 분산 유한 (기댓값 유한보다 강한 조건) |
| 결과 | $\bar{X}_n \to \mu$ | $\bar{X}_n \sim N(\mu, \sigma^2/n)$ |
| ML 활용 | 경험적 위험 → 진짜 위험 | 신뢰구간, 가설검정, batch gradient |

<!-- [DIAGRAM: 하나의 그래프에 LLN과 CLT를 동시에 표현. x축: n(표본 크기). 가운데에 μ 수평선. n이 작을 때는 표본평균이 넓게 흩어져 있다가(CLT: 넓은 정규분포), n이 커질수록 μ 주변으로 모인다(LLN: 수렴). 각 n에서의 표본평균 분포를 세로 정규곡선으로 표시하되, n이 커질수록 곡선이 좁아짐.] -->

두 정리는 경쟁이 아니라 **보완 관계**다. LLN은 "표본 평균이 어디로 가는가"를 말하고, CLT는 "그 과정에서 불확실성이 어떤 형태인가"를 말한다. 둘을 합치면:

> **표본 평균은 $\mu$ 쪽으로 수렴하되(LLN), 그 과정에서 $\mu$ 주변에 정규분포 형태로 흩어진다(CLT). 흩어짐의 크기는 $\sigma/\sqrt{n}$이다.**

## Python으로 확인하기

```python
import numpy as np
from scipy import stats

np.random.seed(42)

# LLN 시각화: 다양한 분포에서 표본평균의 수렴
distributions = {
    "지수분포 Exp(1)":   lambda n: stats.expon.rvs(size=n),
    "균등분포 U(0,10)":  lambda n: stats.uniform.rvs(loc=0, scale=10, size=n),
    "베르누이 Bern(0.3)": lambda n: stats.bernoulli.rvs(p=0.3, size=n),
}
true_means = {"지수분포 Exp(1)": 1.0, "균등분포 U(0,10)": 5.0, "베르누이 Bern(0.3)": 0.3}

for name, sampler in distributions.items():
    samples = sampler(10000)
    running_mean = np.cumsum(samples) / np.arange(1, 10001)
    final_error = abs(running_mean[-1] - true_means[name])
    print(f"{name}: 최종 오차 = {final_error:.4f} (μ = {true_means[name]})")

# LLN vs CLT 구분
print("\n=== LLN vs CLT 구분 ===")
mu, sigma = 5.0, 2.0
n = 1000
n_experiments = 5000

sample_means = [np.random.normal(mu, sigma, n).mean() for _ in range(n_experiments)]

print(f"LLN이 말하는 것: 표본평균 → μ = {mu}")
print(f"  실제 표본평균들의 평균: {np.mean(sample_means):.4f}")

print(f"\nCLT가 말하는 것: 표본평균 ~ N(μ, σ²/n)")
print(f"  이론 SE: {sigma/np.sqrt(n):.4f}")
print(f"  실제 SE: {np.std(sample_means):.4f}")
print(f"  정규성 (Shapiro-Wilk p): {stats.shapiro(sample_means[:500])[1]:.4f}")

# 코시: LLN 실패
print("\n=== 코시 분포: LLN 실패 ===")
for trial in range(5):
    cauchy_mean = stats.cauchy.rvs(size=100000).mean()
    print(f"  시행 {trial+1}: n=100000 표본평균 = {cauchy_mean:.2f}")
```

## 핵심 정리

- **LLN: 표본 평균이 모평균에 수렴한다.** "충분히 많이 모으면 진짜 값을 알 수 있다"의 보장.
- **LLN ≠ CLT.** LLN은 "어디로 가는가"(값의 수렴), CLT는 "어떤 모양으로 가는가"(분포의 형태).
- **LLN이 깨지는 세 가지**: 기댓값 무한(코시), 독립 아님(시계열), 동일 분포 아님(분포 이동). 세 번째가 ML에서 가장 흔한 실패 원인이다.
- **몬테카를로 = LLN의 실전.** 기댓값을 표본 평균으로 근사. 학습, 추론, 강화학습에서 모두 사용.
