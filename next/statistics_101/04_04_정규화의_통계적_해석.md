# 4.4 정규화의 통계적 해석 — L1/L2와 베이즈 사전분포

## 이 챕터에서 배우는 것

- L2 정규화(Ridge)가 가중치에 가우시안 사전분포를 부여하는 것과 같다는 사실
- L1 정규화(Lasso)가 라플라스 사전분포와 같고, 왜 희소성을 만드는지
- MLE → MAP: 정규화가 베이지안의 문을 여는 방법
- Elastic Net, Dropout — 모두 같은 프레임워크의 변주

---

## "왜 정규화가 작동하는가?"

ML 엔지니어라면 정규화를 매일 쓴다. L2 weight decay, L1 sparsity, Dropout. 과적합을 줄여준다는 것은 알고 있다. 하지만 **왜** 작동하는가?

"큰 가중치를 벌하면 모델이 단순해지니까"는 직관적 설명이다. 맞지만 불완전하다. 더 깊은 답이 있다.

**정규화는 "데이터를 보기 전에 가중치에 대해 어떤 믿음을 갖고 있는가"를 수학적으로 표현하는 것이다.**

이것이 베이즈 통계와의 연결이다.

---

## L2 정규화 = 가우시안 사전분포

### 최적화 관점

Ridge 회귀의 목적함수:

$$\hat{\beta}_{\text{Ridge}} = \arg\min_\beta \left[ \sum_{i=1}^n (y_i - x_i^T\beta)^2 + \lambda \sum_{j=1}^p \beta_j^2 \right]$$

첫 번째 항은 MSE(데이터 적합도), 두 번째 항은 $\|\beta\|_2^2$(계수 크기 벌칙). $\lambda$가 두 항의 균형을 조절한다.

### 베이즈 관점

이제 같은 것을 베이즈 프레임워크로 보자.

가중치에 **가우시안 사전분포**를 부여한다:

$$\beta_j \sim N(0, \tau^2) \quad \text{for each } j$$

"학습 전, 가중치가 0 근처에 있을 것이라고 믿는다. 얼마나 강하게 믿는지는 $\tau^2$로 조절한다."

베이즈 정리에 의해 사후분포는:

$$P(\beta \mid \text{data}) \propto P(\text{data} \mid \beta) \cdot P(\beta)$$

로그를 취하면:

$$\log P(\beta \mid \text{data}) = \underbrace{\log P(\text{data} \mid \beta)}_{\text{로그 우도}} + \underbrace{\log P(\beta)}_{\text{로그 사전}} + \text{const}$$

각 항을 전개하면:

- 로그 우도 (정규 노이즈 가정): $-\frac{1}{2\sigma^2}\sum(y_i - x_i^T\beta)^2 + \text{const}$
- 로그 사전 (가우시안): $-\frac{1}{2\tau^2}\sum \beta_j^2 + \text{const}$

사후확률을 최대화(**MAP 추정**)하면:

$$\hat{\beta}_{\text{MAP}} = \arg\max_\beta \left[ -\frac{1}{2\sigma^2}\sum(y_i - x_i^T\beta)^2 - \frac{1}{2\tau^2}\sum \beta_j^2 \right]$$

부호를 뒤집으면:

$$= \arg\min_\beta \left[ \sum(y_i - x_i^T\beta)^2 + \frac{\sigma^2}{\tau^2}\sum \beta_j^2 \right]$$

$\lambda = \sigma^2/\tau^2$로 놓으면 **Ridge 회귀와 정확히 같다.**

---

## L1 정규화 = 라플라스 사전분포

### 최적화 관점

Lasso의 목적함수:

$$\hat{\beta}_{\text{Lasso}} = \arg\min_\beta \left[ \sum(y_i - x_i^T\beta)^2 + \lambda \sum_{j=1}^p |\beta_j| \right]$$

제곱 대신 절대값으로 벌한다.

### 베이즈 관점

가중치에 **라플라스 사전분포**를 부여한다:

$$P(\beta_j) = \frac{1}{2b}\exp\left(-\frac{|\beta_j|}{b}\right)$$

2.4에서 라플라스가 지수분포를 양쪽으로 대칭시킨 것이라고 했다. 0에서 뾰족한 봉우리를 가진 분포다.

로그 사전: $-\frac{1}{b}\sum|\beta_j| + \text{const}$

MAP 추정을 하면 MSE + $\lambda\sum|\beta_j|$를 최소화하는 것이 되고, 이것이 Lasso와 같다.

| | L2 (Ridge) | L1 (Lasso) |
|--|-----------|-----------|
| 벌칙 항 | $\sum \beta_j^2$ | $\sum \|\beta_j\|$ |
| 사전분포 | 가우시안 $N(0, \tau^2)$ | 라플라스 $\text{Lap}(0, b)$ |
| 추정 방법 | MAP with Gaussian prior | MAP with Laplace prior |
| $\lambda$ 의미 | $\sigma^2 / \tau^2$ | $\sigma^2 / b$ |

## 왜 L1은 희소성을 만들고 L2는 안 만드는가

이것이 이 챕터에서 가장 중요한 질문이다.

### 기하학적 설명

제약 조건 관점에서 보면:

- L2: $\sum \beta_j^2 \leq t$ → 원(구) 모양의 제약 영역
- L1: $\sum |\beta_j| \leq t$ → 다이아몬드(마름모) 모양의 제약 영역

MSE의 등고선이 이 제약 영역과 만나는 점이 해다.

<!-- [DIAGRAM: 2D에서 β₁, β₂ 평면. 왼쪽(L1): 다이아몬드 제약과 타원 등고선이 꼭짓점(축 위)에서 만남 → β₂=0. 오른쪽(L2): 원 제약과 타원 등고선이 원 위의 점에서 만남 → 둘 다 0이 아님. "L1의 꼭짓점이 희소 해를 만든다"는 주석.] -->

L1의 다이아몬드는 **축 위에 꼭짓점**이 있다. 등고선이 꼭짓점에서 만나면 하나의 계수가 정확히 0이 된다. L2의 원에는 꼭짓점이 없으므로 계수가 0이 되는 일이 거의 없다.

### 베이지안 설명

라플라스 사전분포의 뾰족한 봉우리는 "가중치가 정확히 0일 확률이 높다"는 사전 믿음을 표현한다. 가우시안 사전분포는 0 근처에 확률이 집중되지만, 0에서 부드러우므로 "정확히 0"이라는 믿음은 약하다.

<details>
<summary>🔬 Deep Dive — L1의 서브그래디언트와 정확한 0의 발생</summary>

수학적으로 더 정확하게 보면, $|\beta_j|$는 $\beta_j = 0$에서 미분 불가능하다. 서브그래디언트(subgradient)를 쓰면:

$$\frac{\partial}{\partial \beta_j}\left[\text{MSE} + \lambda|\beta_j|\right] = -2\sum_i x_{ij}(y_i - x_i^T\beta) + \lambda \cdot \text{sign}(\beta_j)$$

$\text{sign}(\beta_j)$는 $\beta_j > 0$이면 +1, $\beta_j < 0$이면 -1, $\beta_j = 0$이면 [-1, 1] 구간의 아무 값.

$\beta_j = 0$에서 기울기의 데이터 기여분이 $\lambda$보다 작으면, 즉:

$$\left|-2\sum_i x_{ij}(y_i - x_i^T\beta)\right| < \lambda$$

이면 $\beta_j = 0$이 최적이다. **데이터가 이 피처를 "밀어내는 힘"이 정규화의 "0으로 끌어당기는 힘"보다 약하면, 그 피처는 완전히 제거된다.**

L2에서는 벌칙이 $2\lambda\beta_j$이므로, $\beta_j = 0$ 근처에서 벌칙의 기울기도 0에 가까워진다. "끌어당기는 힘"이 0 근처에서 약해지니, 정확히 0에 도달하기 어렵다.

</details>

## MLE → MAP → 완전 베이즈

이 챕터의 연결을 큰 그림으로 보자.

| 방법 | 수식 | 사전분포 | 결과 |
|------|------|---------|------|
| **MLE** | $\arg\max_\beta P(\text{data} \mid \beta)$ | 없음 (또는 균등) | 정규화 없는 OLS |
| **MAP (L2)** | $\arg\max_\beta P(\text{data} \mid \beta) \cdot P(\beta)$ | 가우시안 | Ridge |
| **MAP (L1)** | $\arg\max_\beta P(\text{data} \mid \beta) \cdot P(\beta)$ | 라플라스 | Lasso |
| **완전 베이즈** | $P(\beta \mid \text{data})$ 전체 분포 | 임의 | 사후 분포 전체 |

MLE는 사전분포를 쓰지 않고 데이터만 본다. MAP는 사전분포를 추가하되, 사후확률의 **최댓값**만 쓴다. 완전 베이즈는 사후분포 전체를 사용한다. Part 5에서 이 연속선을 더 깊이 탐구한다.

정규화 강도 $\lambda$는 "데이터를 얼마나 믿을 것인가" vs "사전 믿음을 얼마나 믿을 것인가"의 균형이다:
- $\lambda = 0$: 사전분포 무시, MLE = OLS
- $\lambda \to \infty$: 데이터 무시, 모든 계수 → 0 (사전분포의 평균)

## Elastic Net과 Dropout

### Elastic Net: L1 + L2

$$\text{Elastic Net} = \sum(y_i - x_i^T\beta)^2 + \lambda_1\sum|\beta_j| + \lambda_2\sum\beta_j^2$$

L1의 희소성과 L2의 안정성을 결합한다. 상관된 피처 그룹이 있으면 Lasso는 하나만 선택하지만, Elastic Net은 그룹 전체를 함께 선택/제거한다.

베이지안 관점: 라플라스와 가우시안을 혼합한 사전분포.

```python
from sklearn.linear_model import ElasticNet

model = ElasticNet(alpha=0.1, l1_ratio=0.5)  # l1_ratio: L1의 비율
model.fit(X, y)
print(f"0인 계수: {(model.coef_ == 0).sum()}/{len(model.coef_)}")
```

### Dropout: 암묵적 정규화

Dropout은 학습 중에 뉴런을 랜덤하게 끈다. 이것이 앙상블 효과를 내면서 동시에 **가중치에 대한 암묵적 정규화**로 작용한다.

정확한 대응은 복잡하지만, 직관적으로: Dropout은 "어떤 뉴런이든 꺼질 수 있으니, 특정 뉴런에 과도하게 의존하지 마라"는 제약이다. 이것은 가중치를 0 쪽으로 밀어내는 효과를 낳고, L2 정규화와 비슷한 역할을 한다.

> 💡 **Weight decay와 L2 정규화**: PyTorch에서 `optimizer = Adam(params, weight_decay=1e-4)`는 L2 정규화와 비슷하지만 정확히 같지는 않다. Adam에서 weight decay와 L2 정규화의 차이는 AdamW 논문에서 다뤄졌다. 실무적으로 대부분의 경우 차이가 작지만, 정밀한 제어가 필요하면 `AdamW`를 쓰라.

## 실무 가이드: 언제 뭘 쓸 것인가

| 상황 | 추천 | 이유 |
|------|------|------|
| 피처가 많고 대부분 관련 있을 것 같다 | Ridge (L2) | 계수를 줄이되 제거하지 않음 |
| 피처가 많고 일부만 관련 있을 것 같다 | Lasso (L1) | 불필요한 피처를 자동 제거 |
| 피처가 많고 상관된 그룹이 있다 | Elastic Net | 그룹 단위 선택 |
| 다중공선성이 심하다 | Ridge (L2) | 4.2에서 봤듯이 $(X^TX + \lambda I)^{-1}$ 안정화 |
| 해석 가능한 모델이 필요하다 | Lasso (L1) | 희소 계수 → 어떤 피처가 중요한지 명확 |

## Python으로 확인하기

```python
import numpy as np
from sklearn.linear_model import Ridge, Lasso, LinearRegression
import matplotlib.pyplot as plt

np.random.seed(42)

# 데이터: 20개 피처, 5개만 관련
n, p = 100, 20
X = np.random.normal(0, 1, (n, p))
true_beta = np.zeros(p)
true_beta[:5] = [3, -2, 1.5, -1, 0.5]  # 5개만 0이 아님
y = X @ true_beta + np.random.normal(0, 1, n)

# 세 모델 비교
models = {
    'OLS (MLE)': LinearRegression(),
    'Ridge (L2)': Ridge(alpha=1.0),
    'Lasso (L1)': Lasso(alpha=0.3),
}

print(f"진짜 계수: {true_beta[:7]}...")
print(f"{'모델':<15} {'R²':>6} {'0인 계수':>8}  처음 7개 계수")
print("-" * 70)

for name, model in models.items():
    model.fit(X, y)
    r2 = model.score(X, y)
    n_zero = (np.abs(model.coef_) < 1e-6).sum()
    coefs = model.coef_[:7].round(3)
    print(f"{name:<15} {r2:>6.3f} {n_zero:>8}  {coefs}")

# λ에 따른 계수 경로
print(f"\n=== λ 경로: Ridge vs Lasso ===")
alphas = np.logspace(-2, 2, 50)

ridge_coefs = np.array([Ridge(alpha=a).fit(X, y).coef_ for a in alphas])
lasso_coefs = np.array([Lasso(alpha=a, max_iter=10000).fit(X, y).coef_ for a in alphas])

# 관련 피처(idx 0)와 무관 피처(idx 10)의 경로
print(f"Ridge: λ=0.01 → β₁={ridge_coefs[0, 0]:.3f}, "
      f"λ=100 → β₁={ridge_coefs[-1, 0]:.3f} (0에 가까워지지만 0은 아님)")
print(f"Lasso: λ=0.01 → β₁={lasso_coefs[0, 0]:.3f}, "
      f"λ=1.0에서 β₁ 소멸 여부: "
      f"{'소멸' if abs(lasso_coefs[25, 0]) < 0.01 else '생존'}")
```

## 핵심 정리

- **L2 (Ridge) = 가우시안 사전분포를 가진 MAP.** 가중치를 0 쪽으로 줄이되, 정확히 0으로 만들지는 않는다.
- **L1 (Lasso) = 라플라스 사전분포를 가진 MAP.** 일부 가중치를 정확히 0으로 만든다 (희소성). 자동 피처 선택.
- **희소성의 원리**: L1의 다이아몬드 제약에 꼭짓점이 있어서 축 위에서 만남. L2의 원에는 꼭짓점이 없어서 0에 도달 안 함.
- **MLE → MAP → 완전 베이즈**: 정규화는 이 연속선의 중간(MAP)에 해당. λ는 "데이터 vs 사전분포"의 균형.
- **λ = 0이면 MLE, λ → ∞이면 사전분포만.** 정규화 강도는 데이터에 대한 신뢰와 사전 믿음 사이의 저울질이다.
