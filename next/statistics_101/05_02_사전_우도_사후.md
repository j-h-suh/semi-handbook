## 베이즈 정리: 모수 추정 버전

2.1에서 베이즈 정리를 사건에 대해 배웠다. 이제 **모수에 대해** 다시 쓴다:

$$P(\theta \mid \text{data}) = \frac{P(\text{data} \mid \theta) \cdot P(\theta)}{P(\text{data})}$$

$$\underbrace{P(\theta \mid \text{data})}_{\text{사후분포}} \propto \underbrace{P(\text{data} \mid \theta)}_{\text{우도}} \times \underbrace{P(\theta)}_{\text{사전분포}}$$

분모 $P(\text{data})$는 **정규화 상수(normalizing constant)**이며, $\theta$와 무관하다. 왜 무관한가? $P(\text{data}) = \int P(\text{data} \mid \theta) P(\theta) \, d\theta$인데, 이 적분은 모든 가능한 $\theta$에 대해 합산하므로 결과에 $\theta$가 남지 않는다. $\theta$에 대해 최적화(MAP)하거나 비례 관계만 필요한 경우 이 상수를 무시할 수 있다.

각 항의 역할:

| 항 | 역할 | ML 대응 |
|---|------|---------|
| **사전분포** $P(\theta)$ | 데이터를 보기 전 $\theta$에 대한 믿음 | 정규화 항 (4.4) |
| **우도** $P(\text{data} \mid \theta)$ | 이 $\theta$에서 데이터가 나올 확률 | 손실함수 (BCE, MSE) |
| **사후분포** $P(\theta \mid \text{data})$ | 데이터를 본 후 업데이트된 믿음 | 학습된 모델 |

## 사전분포의 스펙트럼

### 무정보 사전분포 (Non-informative Prior)

"아무것도 모른다." $\theta$의 가능한 범위에서 균등하게.

- $p \sim \text{Uniform}(0, 1)$ — 비율
- $\mu \sim N(0, 10000)$ — 분산이 매우 큰 정규분포 (사실상 균등)

MLE와 거의 같은 결과를 준다. "데이터가 말하는 대로."

### 약정보 사전분포 (Weakly Informative Prior)

"대략적인 범위는 안다." 극단적인 값을 배제하되, 데이터에 주도권을 준다.

- $\beta_j \sim N(0, 10)$ — "계수가 ±20을 넘지는 않을 것이다"
- $\sigma \sim \text{Half-Normal}(0, 5)$ — "표준편차가 양수이고 너무 크지는 않다"

실무에서 가장 추천되는 선택. 데이터가 약간 부족해도 안정적이고, 데이터가 충분하면 무정보와 같은 결과.

### 강정보 사전분포 (Informative Prior)

"이전 연구나 도메인 지식에서 꽤 확실하게 안다."

- 이전 실험에서 $\mu \approx 100 \pm 5$였다면 → $\mu \sim N(100, 25)$

데이터가 적을 때 강력하지만, 사전 지식이 틀리면 위험하다.

> 💡 **정규화 강도와의 대응**: 사전분포의 분산 $\tau^2$이 작을수록(= 강정보) 정규화가 강하다. $\lambda = \sigma^2/\tau^2$이므로, $\tau^2$↓ → $\lambda$↑. 무정보($\tau^2 = \infty$)면 $\lambda = 0$ (정규화 없음, MLE).

## 켤레 사전분포: 손으로 풀 수 있는 베이즈

일반적으로 사후분포는 닫힌 형태로 구해지지 않는다 — 정규화 상수 $P(\text{data})$의 적분이 해석적으로 풀리지 않기 때문이다. 하지만 특정 우도-사전 조합에서는 **사후분포가 사전분포와 같은 분포 족(family)에 속한다.** 이것을 **켤레 사전분포(conjugate prior)**라 한다.

켤레가 실무적으로 중요한 이유는 두 가지다. 첫째, MCMC 없이 사후분포를 닫힌 형태로 바로 구할 수 있어 계산이 빠르다. 둘째, 데이터가 들어올 때마다 파라미터만 업데이트하면 되므로 **온라인 학습에 자연스럽게 맞는다** — 오늘의 사후가 내일의 사전이 된다.

| 우도 | 켤레 사전 | 사후 | ML 연결 |
|------|----------|------|---------|
| 베르누이/이항 | Beta(α, β) | Beta(α+k, β+n-k) | 이진 분류 |
| 포아송 | Gamma(α, β) | Gamma(α+Σx, β+n) | 카운트 예측 |
| 정규 (μ 추정) | 정규 N(μ₀, τ²) | 정규 | 회귀 계수 |

5.1에서 동전 문제가 Beta-Binomial 켤레를 쓴 것이다:

$$\text{사전: } \text{Beta}(\alpha_0, \beta_0) \quad + \quad \text{데이터: } k\text{번 성공, }n-k\text{번 실패}$$
$$\Rightarrow \quad \text{사후: } \text{Beta}(\alpha_0 + k, \; \beta_0 + n - k)$$

사전의 $\alpha_0, \beta_0$를 **가상 관측(pseudo-observations)**이라 생각할 수 있다. $\text{Beta}(5, 5)$를 사전으로 쓰는 것은 "데이터를 보기 전에 이미 5번 성공, 5번 실패를 관측한 것처럼" 시작하는 것과 같다.

## 사전분포와 데이터의 줄다리기

사후분포는 사전분포와 데이터 사이의 **가중 평균**이다.

정규-정규 켤레의 경우, 사후 평균이 정확히 가중 평균 형태로 나온다:

$$\mu_{\text{post}} = \frac{\frac{n}{\sigma^2}}{\frac{n}{\sigma^2} + \frac{1}{\tau^2}} \cdot \bar{x} + \frac{\frac{1}{\tau^2}}{\frac{n}{\sigma^2} + \frac{1}{\tau^2}} \cdot \mu_0$$

$$= w \cdot \bar{x} + (1-w) \cdot \mu_0$$

$w$는 데이터의 가중치, $(1-w)$는 사전분포의 가중치.

- $n$이 크면 ($n/\sigma^2$ 지배) → $w \to 1$ → 사후 ≈ 데이터 (MLE)
- $n$이 작으면 ($1/\tau^2$ 지배) → $w \to 0$ → 사후 ≈ 사전분포
- $\tau^2$가 크면 (약정보) → 사전의 영향 작음
- $\tau^2$가 작으면 (강정보) → 사전의 영향 큼

이 줄다리기가 베이즈 추론의 핵심 메커니즘이다. 4.4에서 배웠듯이, Ridge의 $\lambda = \sigma^2/\tau^2$는 바로 이 가중치의 비율이다 — $\lambda$가 크면 사전(0 근처)에 끌려가고, 작으면 데이터(MLE)에 끌려간다.

---

## Python으로 확인하기

```python
import numpy as np
from scipy import stats

# 정규-정규 켤레: 사후 = 가중 평균
sigma = 2.0        # 데이터 노이즈 (알려진 것으로 가정)
mu_0, tau = 80, 10  # 사전: N(80, 100)

for n in [1, 5, 20, 100]:
    x_bar = 95.0    # 표본 평균이 항상 95라고 가정
    
    # 가중치
    w_data = (n / sigma**2) / (n / sigma**2 + 1 / tau**2)
    mu_post = w_data * x_bar + (1 - w_data) * mu_0
    var_post = 1 / (n / sigma**2 + 1 / tau**2)
    
    print(f"n={n:>3}: 사후평균={mu_post:.1f} "
          f"(데이터 가중치={w_data:.2f}, 사전 가중치={1-w_data:.2f})")

# 출력 해석: n이 커질수록 사후평균이 95(데이터)에 가까워짐
```

## 핵심 정리

- **사후 ∝ 우도 × 사전.** 데이터를 보고 믿음을 업데이트하는 구조.
- **사전분포의 강도가 정규화 강도다.** 무정보 → λ=0(MLE), 강정보 → 큰 λ.
- **켤레 사전분포**를 쓰면 사후분포를 닫힌 형태로 구할 수 있다. Beta-Binomial이 가장 흔한 예.
- **사후분포 = 사전과 데이터의 가중 평균.** n이 크면 데이터 지배, n이 작으면 사전 지배.
- **사전의 α₀, β₀는 가상 관측.** Beta(5,5)는 "10번의 가상 실험"과 같다.
