# 6.3 정보이론 기초 — 엔트로피, KL-divergence, cross-entropy loss의 뿌리

## 이 챕터에서 배우는 것

- 엔트로피가 "불확실성의 양"을 측정하는 원리
- Cross-entropy loss가 왜 그 형태인지의 정보이론적 설명
- KL-divergence — 두 분포가 얼마나 다른지를 재는 자
- 이 개념들이 ML의 손실함수, VAE, 지식 증류에 어떻게 연결되는지

---

## 엔트로피: 불확실성을 숫자로

### 정의

$$H(X) = -\sum_{x} p(x) \log p(x)$$

각 사건의 "놀라움"($-\log p(x)$)의 기댓값. 확률이 낮은 사건일수록 놀라움이 크고, 높은 사건일수록 놀라움이 작다.

| 분포 | 엔트로피 | 직관 |
|------|---------|------|
| 동전 (50/50) | 1 bit | 최대 불확실성 |
| 동전 (90/10) | 0.47 bit | 거의 예측 가능 |
| 동전 (100/0) | 0 bit | 확실. 놀라움 없음 |

**엔트로피가 높다 = 불확실성이 크다 = 예측이 어렵다.**

ML에서의 직접적 의미: 클래스 분포의 엔트로피가 높을수록(균등 분포에 가까울수록) 분류가 어렵다. 결정 트리가 split을 고를 때 **정보 이득(Information Gain) = 엔트로피 감소**를 기준으로 쓰는 이유다.

## Cross-Entropy: 진짜 분포와 추정 분포의 차이

### 정의

$$H(p, q) = -\sum_x p(x) \log q(x)$$

$p$는 진짜 분포, $q$는 모델이 추정한 분포. "진짜 분포에서 사건이 발생하는데, 모델의 분포로 놀라움을 측정하면 얼마나 되는가?"

$q = p$이면 $H(p, q) = H(p)$ (최소). $q$가 $p$에서 멀어질수록 cross-entropy가 커진다.

### Cross-Entropy Loss = Cross-Entropy

분류의 Cross-Entropy Loss:

$$\text{CE} = -\frac{1}{n}\sum_{i=1}^n \sum_{k=1}^K y_{ik} \log \hat{p}_{ik}$$

이것은 정확히 경험적 분포 $p$(원핫 레이블)와 모델 분포 $q$($\hat{p}$) 사이의 cross-entropy다.

2.3에서 BCE가 베르누이 NLL이라고 했고, 4.3에서 CCE가 카테고리 NLL이라고 했다. 정보이론 관점에서 같은 것을 다시 보면: **NLL 최소화 = cross-entropy 최소화 = 모델 분포를 진짜 분포에 가깝게.**

세 관점이 하나로 수렴한다:

$$\text{MLE} = \min \text{NLL} = \min H(p, q) = \min [H(p) + D_{KL}(p \| q)]$$

---

## KL-Divergence: 두 분포 사이의 거리

### 정의

$$D_{KL}(p \| q) = \sum_x p(x) \log \frac{p(x)}{q(x)} = H(p, q) - H(p)$$

Cross-entropy에서 엔트로피를 빼면 KL-divergence. $H(p)$는 데이터의 본질적 불확실성(상수), $D_{KL}$은 모델이 추가로 만드는 오차. **CE를 최소화하는 것 = KL을 최소화하는 것** ($H(p)$는 상수이므로).

KL-divergence의 성질:
- $D_{KL}(p \| q) \geq 0$ (항상 비음수)
- $D_{KL}(p \| q) = 0$ iff $p = q$
- **비대칭**: $D_{KL}(p \| q) \neq D_{KL}(q \| p)$. 거리(distance)가 아니라 발산(divergence)이라 부르는 이유.

### ML에서 KL이 등장하는 곳

| 응용 | KL의 역할 |
|------|----------|
| 분류 손실 (CE) | $H(p,q) = H(p) + D_{KL}(p \| q)$. CE 최소화 = KL 최소화 |
| VAE | ELBO = 재구성 손실 + $D_{KL}(q(z\|x) \| p(z))$. 잠재 분포를 사전분포에 가깝게 |
| 지식 증류 | 학생 분포를 교사 분포에 가깝게: $D_{KL}(p_{\text{teacher}} \| p_{\text{student}})$ |
| PPO (강화학습) | 정책 업데이트 폭 제한: $D_{KL}(\pi_{\text{old}} \| \pi_{\text{new}}) < \epsilon$ |
| 변분 추론 (5.4) | 근사 사후분포를 진짜 사후분포에 가깝게 |

## Python으로 확인하기

```python
import numpy as np
from scipy.stats import entropy
from sklearn.metrics import log_loss

# 1. 엔트로피: 분포의 불확실성
distributions = {
    '균등 (50/50)': [0.5, 0.5],
    '편향 (90/10)': [0.9, 0.1],
    '확실 (99/1)':  [0.99, 0.01],
}

print("=== 엔트로피 ===")
for name, p in distributions.items():
    h = entropy(p, base=2)
    print(f"  {name}: H = {h:.3f} bits")

# 2. CE loss = KL + H(p)
print(f"\n=== CE = H(p) + KL ===")
p_true = np.array([0.7, 0.2, 0.1])  # 진짜 분포
q_model = np.array([0.5, 0.3, 0.2])  # 모델 분포

h_p = entropy(p_true, base=np.e)
kl = entropy(p_true, q_model, base=np.e)
ce = h_p + kl

print(f"  H(p) = {h_p:.4f}")
print(f"  KL(p||q) = {kl:.4f}")
print(f"  CE = H(p) + KL = {ce:.4f}")
print(f"  CE 직접 계산 = {-np.sum(p_true * np.log(q_model)):.4f}")

# 3. KL의 비대칭성
kl_pq = entropy(p_true, q_model)
kl_qp = entropy(q_model, p_true)
print(f"\n=== KL 비대칭 ===")
print(f"  KL(p||q) = {kl_pq:.4f}")
print(f"  KL(q||p) = {kl_qp:.4f}")
print(f"  → 다르다!")
```

## 핵심 정리

- **엔트로피 = 불확실성의 양.** 균등 분포에서 최대, 확실한 분포에서 0. 결정 트리의 정보 이득 기준.
- **Cross-entropy = 모델이 진짜 분포와 얼마나 다른지 + 데이터의 본질적 불확실성.** CE 최소화 = 모델을 진짜 분포에 맞추기.
- **CE = H(p) + KL(p||q).** CE 최소화 = KL 최소화 (H(p)는 상수). MLE와 동치.
- **KL-divergence는 비대칭이다.** 거리가 아니라 발산. VAE, 지식 증류, PPO에서 핵심 역할.
- **MLE = NLL 최소화 = CE 최소화 = KL 최소화.** 네 관점이 하나로 수렴.
