# 2.4 연속분포 — 정규, 균등, 지수

## 이 챕터에서 배우는 것

- 정규분포가 통계학의 주인공인 이유 — 그리고 MSE가 정규분포의 NLL이라는 충격적 사실
- 균등분포 — "아무것도 모른다"를 수학으로 표현하는 법
- 지수분포 — "다음 사건까지 얼마나 기다리는가"와 기억 없는 성질
- 세 분포가 ML 파이프라인에서 만나는 지점들

## 정규분포: 왜 모든 곳에 있는가

### PDF

$$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{(x-\mu)^2}{2\sigma^2}\right)$$

$$X \sim N(\mu, \sigma^2), \quad E[X] = \mu, \quad \text{Var}(X) = \sigma^2$$

이 공식을 외울 필요는 없다. 중요한 것은 구조다. 지수 안의 $(x - \mu)^2$가 핵심이다. 평균 $\mu$에서 멀어질수록 확률밀도가 **제곱으로** 빠르게 감소한다. 이것이 종 모양을 만든다.

<!-- [GRAPH: 정규분포 PDF. μ=0에서 σ=0.5, 1, 2, 3으로 4개의 곡선. σ가 작을수록 좁고 높고, σ가 클수록 넓고 낮음. 모두 같은 넓이(=1).] -->

### 정규분포가 어디에나 있는 이유

정규분포가 통계학의 주인공인 이유는 자연이 정규분포를 좋아해서가 아니다. **중심극한정리(CLT)** 때문이다.

간단히 말하면: 어떤 분포에서 뽑든, 충분히 많이 뽑아서 평균을 내면 그 평균의 분포가 정규분포에 가까워진다. 원래 분포가 지수분포든, 균등분포든, 이상하게 생긴 분포든 상관없다.

이것이 왜 중요한가? 우리가 다루는 대부분의 통계량(평균, 회귀 계수, 검정 통계량)은 데이터의 **합 또는 평균**으로 만들어진다. CLT에 의해 이 통계량들이 정규분포를 따르므로, 정규분포 기반의 검정과 신뢰구간을 쓸 수 있다. 정규분포가 어디에나 있는 것이 아니라, **우리가 만드는 통계량이 정규분포를 따르는 것**이다.

CLT의 상세한 내용은 2.5에서 본격적으로 다룬다.

### MSE = 정규분포의 NLL

2.3에서 BCE가 베르누이의 NLL이라는 것을 봤다. 같은 논리가 여기서도 작동한다.

회귀 모델이 이런 가정을 한다고 하자:

$$Y = f(X) + \epsilon, \quad \epsilon \sim N(0, \sigma^2)$$

"타겟은 모델의 예측에 정규 노이즈가 더해진 것이다." 이것은 곧:

$$Y \mid X \sim N(f(X), \sigma^2)$$

이 가정 하에서 단일 관측의 로그 우도를 쓰면:

$$\log P(y \mid x) = -\frac{1}{2\sigma^2}(y - f(x))^2 - \frac{1}{2}\log(2\pi\sigma^2)$$

$n$개 데이터에 대해 합산하고, $\sigma$와 상수를 무시하면:

$$\text{NLL} \propto \sum_{i=1}^{n} (y_i - f(x_i))^2 = n \cdot \text{MSE}$$

**MSE를 최소화하는 것은, 잔차가 정규분포를 따른다는 가정 하에서 우도를 최대화하는 것과 같다.**

| 분포 가정 | NLL 손실 | ML에서의 이름 |
|----------|---------|-------------|
| 베르누이 | $-[y\log p + (1-y)\log(1-p)]$ | Binary Cross-Entropy |
| 정규분포 | $(y - \hat{y})^2$ (+ 상수) | MSE |
| 포아송 | $\hat{\lambda} - y\log\hat{\lambda}$ (+ 상수) | Poisson Loss |

손실함수의 선택은 **타겟의 분포 가정**과 같다. 이것이 1.1에서 "손실함수 = 대표값의 철학"이라고 했던 것의 더 깊은 버전이다.

<details>
<summary>🔬 Deep Dive — MSE가 정규분포 NLL인 이유의 전체 유도</summary>

$Y_i \mid X_i \sim N(f(X_i), \sigma^2)$일 때, 데이터 $\{(x_i, y_i)\}_{i=1}^n$의 로그 우도:

$$\ell(f) = \sum_{i=1}^n \log P(y_i \mid x_i) = \sum_{i=1}^n \left[ -\frac{(y_i - f(x_i))^2}{2\sigma^2} - \frac{1}{2}\log(2\pi\sigma^2) \right]$$

$$= -\frac{1}{2\sigma^2} \sum_{i=1}^n (y_i - f(x_i))^2 - \frac{n}{2}\log(2\pi\sigma^2)$$

$f$에 대해 최대화할 때, 두 번째 항은 $f$와 무관한 상수이고, 첫 번째 항의 $-1/(2\sigma^2)$도 상수이므로:

$$\arg\max_f \ell(f) = \arg\min_f \sum_{i=1}^n (y_i - f(x_i))^2 = \arg\min_f \text{MSE}$$

$\sigma$도 함께 추정하면? MLE로 구한 $\hat{\sigma}^2$는:

$$\hat{\sigma}^2_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n (y_i - \hat{f}(x_i))^2 = \text{MSE}$$

잔차의 MSE 자체가 노이즈 분산의 MLE 추정값이 된다.

</details>

### 표준 정규분포와 z-score

$\mu = 0$, $\sigma = 1$인 정규분포를 **표준 정규분포** $N(0, 1)$이라 한다. 어떤 정규분포든 표준화할 수 있다:

$$Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$$

이것이 1.2에서 배운 **z-score**다. StandardScaler가 하는 일이 바로 이 변환이다. 데이터가 정규분포를 따른다면, StandardScaler를 거친 데이터는 표준 정규분포를 따른다.

## 균등분포: "아무것도 모른다"

### PDF

$$f(x) = \frac{1}{b-a}, \quad a \leq x \leq b$$

$$X \sim \text{Uniform}(a, b), \quad E[X] = \frac{a+b}{2}, \quad \text{Var}(X) = \frac{(b-a)^2}{12}$$

구간 $[a, b]$ 안의 모든 값이 동일한 확률밀도를 갖는다. "이 범위 안에서 어디가 더 가능성 있는지 전혀 모르겠다"를 수학으로 표현한 것이다.

<!-- [GRAPH: Uniform(0,1)의 PDF(높이 1인 직사각형)와 CDF(0에서 1로 직선 증가).] -->

### ML에서 균등분포가 있는 곳

**1. 가중치 초기화**

```python
nn.init.uniform_(layer.weight, a=-0.1, b=0.1)
```

신경망의 가중치를 초기화할 때, "어떤 값이 좋을지 모르니 균등하게 뿌린다." Xavier/He 초기화도 내부적으로 균등분포나 정규분포를 쓴다.

**2. 랜덤 서치 하이퍼파라미터 탐색**

```python
from scipy.stats import uniform
param_distributions = {
    'learning_rate': uniform(loc=1e-5, scale=1e-1),
    'dropout_rate': uniform(loc=0.0, scale=0.5),
}
```

하이퍼파라미터의 최적값을 모르니까, 범위 안에서 균등하게 뽑아본다. 이것이 `RandomizedSearchCV`의 기본 작동 방식이다.

**3. 베이지안에서의 무정보 사전분포**

Part 5에서 자세히 다루겠지만, 베이지안 통계에서 "사전 지식이 없다"를 표현하는 가장 간단한 방법이 균등 사전분포(uniform prior)다. "파라미터가 이 범위 안 어디든 동일하게 가능하다."

> 💡 **`np.random.random()`과 `torch.rand()`는 $\text{Uniform}(0, 1)$에서 뽑는 것이다.** 난수 생성의 가장 기본적인 벽돌. 다른 분포의 난수도 대부분 균등분포 난수를 변환해서 만든다 (역변환 샘플링).

## 지수분포: "다음 사건까지 얼마나 기다리는가"

### PDF

$$f(x) = \lambda e^{-\lambda x}, \quad x \geq 0$$

$$X \sim \text{Exp}(\lambda), \quad E[X] = \frac{1}{\lambda}, \quad \text{Var}(X) = \frac{1}{\lambda^2}$$

포아송 분포가 "일정 시간에 사건이 몇 번 일어나는가"를 다뤘다면, 지수분포는 **"사건과 사건 사이에 얼마나 기다리는가"**를 다룬다. 포아송의 쌍둥이다.

포아송 과정에서 사건이 평균 $\lambda$회/시간 발생하면, 사건 간 대기 시간은 $\text{Exp}(\lambda)$를 따른다.

<!-- [GRAPH: 지수분포 PDF. λ=0.5, 1, 2로 3개의 곡선. λ가 클수록 빠르게 감소(평균 대기 시간이 짧음).] -->

### 기억 없는 성질 (Memoryless Property)

지수분포의 가장 특이한 성질:

$$P(X > s + t \mid X > s) = P(X > t)$$

"이미 $s$시간 기다렸다는 사실이 앞으로 더 기다려야 할 시간에 영향을 주지 않는다."

버스를 10분 기다렸다면, 보통은 "곧 오겠지"라고 생각한다. 하지만 버스 도착이 지수분포를 따르면, 10분을 기다렸든 1시간을 기다렸든, 앞으로의 대기 시간 분포는 동일하다.

이것은 연속 분포 중 지수분포만 가지는 성질이다 (이산에서는 기하분포).

### ML에서 지수분포가 있는 곳

**1. 서비스 응답 시간 모델링**

1.3에서 추론 지연시간의 p50, p90, p99를 봤다. 이런 응답 시간은 종종 지수분포(또는 감마분포)로 모델링된다. 대부분 빠르고, 소수가 극단적으로 느리다.

**2. 사건 간격 데이터**

장비 고장 간격, 고객 방문 간격 등 "다음 사건까지의 시간"을 예측할 때 지수분포가 기본 가정이 된다.

**3. L1 정규화와 라플라스 분포**

지수분포의 "사촌"인 **라플라스 분포(Laplace Distribution)**는 지수분포를 양쪽으로 대칭시킨 것이다:

$$f(x) = \frac{1}{2b} \exp\left(-\frac{|x-\mu|}{b}\right)$$

Part 4.4에서 다루겠지만, L1 정규화(Lasso)는 가중치에 라플라스 사전분포를 부여하는 것과 같다. 라플라스의 뾰족한 봉우리가 가중치를 0으로 밀어내서 희소성(sparsity)을 만든다. 지수분포 계열의 "뾰족함"이 L1의 핵심 성질과 연결된다.

## 세 분포의 비교

| | 정규 $N(\mu, \sigma^2)$ | 균등 $U(a, b)$ | 지수 $\text{Exp}(\lambda)$ |
|--|----------------------|--------------|----------------------|
| 형태 | 종 모양 (대칭) | 직사각형 | 급감소 (비대칭) |
| 범위 | $(-\infty, +\infty)$ | $[a, b]$ | $[0, +\infty)$ |
| ML 주 용도 | 잔차, 노이즈, 가중치 | 초기화, 탐색, 사전분포 | 대기 시간, 응답 시간 |
| 손실 연결 | MSE | — | — |
| 정규화 연결 | L2 (가우시안 사전) | — | L1 (라플라스 사전) |

마지막 행이 중요하다. L2 정규화 = 가우시안 사전분포, L1 정규화 = 라플라스 사전분포. 이 연결은 Part 4.4에서 완성된다.

## 분포를 고르는 것이 모델링이다

이 챕터와 2.3을 관통하는 핵심 메시지를 하나로 정리한다.

**분포를 가정하는 것 자체가 모델링의 핵심 결정이다.**

| 타겟의 성격 | 적절한 분포 가정 | 대응하는 손실함수 |
|-----------|----------------|----------------|
| 이진 (0/1) | 베르누이 | BCE |
| 연속, 대칭 | 정규분포 | MSE |
| 카운트 (0, 1, 2, ...) | 포아송 | Poisson Loss |
| 양수, 오른쪽 꼬리 | 감마 또는 지수 | Gamma Loss |

`sklearn`이나 `PyTorch`에서 손실함수를 "고르는" 행위는, 실은 타겟의 확률분포를 가정하는 것이다. 이 연결을 아는 것과 모르는 것이, "손실함수를 쓰는 사람"과 "손실함수를 이해하는 사람"의 차이다.

---

## Python으로 확인하기

```python
import numpy as np
from scipy import stats

# 1. MSE = 정규분포 NLL 확인
y_true = np.array([3.0, 5.2, 4.1, 6.3, 2.8])
y_pred = np.array([3.2, 4.9, 4.3, 6.0, 3.1])
sigma = 1.0  # 노이즈 표준편차

mse = np.mean((y_true - y_pred) ** 2)
nll = -np.mean(stats.norm.logpdf(y_true, loc=y_pred, scale=sigma))
nll_manual = mse / (2 * sigma**2) + 0.5 * np.log(2 * np.pi * sigma**2)

print(f"MSE:           {mse:.6f}")
print(f"정규 NLL:      {nll:.6f}")
print(f"MSE/(2σ²)+C:   {nll_manual:.6f}")
print(f"NLL ≈ MSE/(2σ²)+상수? {np.isclose(nll, nll_manual)}")

# 2. 지수분포: 기억 없는 성질 시뮬레이션
lam = 2.0
samples = stats.expon.rvs(scale=1/lam, size=100000)

# 전체 평균 대기 시간
mean_all = samples.mean()

# "이미 0.5 이상 기다린" 샘플에서, 추가 대기 시간
survived = samples[samples > 0.5]
additional_wait = (survived - 0.5).mean()

print(f"\nExp(λ=2) 기억 없는 성질:")
print(f"전체 평균 대기:     {mean_all:.3f} (이론: {1/lam:.3f})")
print(f"0.5 초과 후 추가 대기: {additional_wait:.3f} (이론: {1/lam:.3f})")
print(f"→ 같다! 이미 기다린 시간이 무의미")

# 3. 균등분포에서 다른 분포 만들기 (역변환 샘플링)
u = np.random.uniform(0, 1, 10000)          # Uniform(0,1)
exp_samples = -np.log(1 - u) / lam           # → Exp(λ)
print(f"\n역변환 샘플링으로 만든 Exp(2):")
print(f"평균: {exp_samples.mean():.3f} (이론: {1/lam:.3f})")
print(f"분산: {exp_samples.var():.3f} (이론: {1/lam**2:.3f})")
```

## 핵심 정리

- **정규분포가 어디에나 있는 이유는 CLT 때문이다.** 원래 분포가 뭐든, 평균의 분포는 정규로 수렴한다. (2.5에서 계속)
- **MSE = 정규분포의 NLL.** MSE를 쓴다는 것은 "잔차가 정규분포를 따른다"고 가정하는 것이다.
- **균등분포 = "모른다"의 표현.** 가중치 초기화, 하이퍼파라미터 탐색, 무정보 사전분포의 기반.
- **지수분포 = 대기 시간의 분포.** 기억 없는 성질이 핵심. 사촌인 라플라스 분포는 L1 정규화와 연결된다.
- **손실함수를 고르는 것 = 타겟의 분포를 가정하는 것.** BCE↔베르누이, MSE↔정규, Poisson Loss↔포아송.
