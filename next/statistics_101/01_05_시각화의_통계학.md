## 히스토그램: 가장 익숙하고 가장 위험한 그래프

히스토그램은 데이터를 구간(bin)으로 나누고, 각 구간에 몇 개의 데이터가 있는지를 막대 높이로 표현한 것이다. 분포의 "모양"을 한눈에 파악할 수 있는 가장 직관적인 도구다.

```python
import matplotlib.pyplot as plt
import numpy as np

data = np.random.exponential(scale=2.0, size=1000)
plt.hist(data, bins=30)
plt.title("지수분포에서 뽑은 1000개 샘플")
```

문제는 **bin의 개수(또는 너비)에 따라 완전히 다른 그림이 나온다**는 것이다.

<!-- [GRAPH: 동일한 데이터(이봉 분포, bimodal)를 bins=5, bins=20, bins=100으로 각각 그린 히스토그램 3개를 나란히. bins=5에서는 봉우리가 하나로 보이고, bins=20에서는 두 개가 명확히 보이고, bins=100에서는 노이즈가 심해서 패턴이 흐려짐.] -->

위 그림이 핵심이다. 같은 데이터인데:
- bin이 너무 적으면 → 세부 구조(이봉성 등)가 사라진다
- bin이 적당하면 → 분포의 진짜 형태가 드러난다
- bin이 너무 많으면 → 노이즈가 과도하게 표현되어 패턴이 흐려진다

이것은 ML에서 **편향-분산 트레이드오프**와 정확히 같은 구조다. bin이 적으면 편향이 높고(과도한 smoothing), bin이 많으면 분산이 높다(과도한 fitting). 최적의 bin 수는 데이터의 양과 분포에 따라 다르다.

### bin 수를 고르는 실용적 규칙

`matplotlib`의 `plt.hist()`에서 `bins='auto'`를 쓰면 내부적으로 휴리스틱을 적용한다. 직접 고르고 싶다면 몇 가지 규칙이 있다:

| 규칙 | 공식 | 특징 |
|------|------|------|
| Sturges | $1 + \log_2 n$ | 정규분포에 적합. 데이터 적을 때 |
| Freedman-Diaconis | $\text{bin width} = \frac{2 \times IQR}{n^{1/3}}$ | IQR 기반이라 이상치에 강건 |
| Scott | $\text{bin width} = \frac{3.5 \times s}{n^{1/3}}$ | 표준편차 기반 |

실무적 조언: 규칙 하나에 의존하지 말고, **2~3개의 bin 수로 그려보고 비교하라.** bin 수를 바꿨는데 보이는 패턴이 달라진다면, 그 패턴은 신뢰하기 어렵다. bin 수에 관계없이 일관되게 보이는 패턴만 믿어라.

### KDE: 히스토그램의 연속 버전

히스토그램의 bin 의존성 문제를 완화하는 대안이 **커널 밀도 추정(Kernel Density Estimation, KDE)**이다.

```python
import seaborn as sns
sns.kdeplot(data)
```

KDE는 각 데이터 포인트에 부드러운 커널(보통 가우시안)을 얹고 전부 합산하여 연속적인 밀도 곡선을 만든다. bin으로 쪼개지 않으므로 계단 현상이 없다.

다만 KDE도 **bandwidth** 파라미터에 의존한다. bandwidth가 너무 작으면 데이터 하나하나에 뾰족한 봉우리가 생기고(과적합), 너무 크면 모든 구조가 뭉개진다(과소적합). bin 수 문제가 bandwidth 문제로 바뀐 것일 뿐, 본질은 같다.

> 💡 **실무 팁**: `sns.histplot(data, kde=True)`를 쓰면 히스토그램과 KDE를 겹쳐 그릴 수 있다. 히스토그램의 이산적 모양과 KDE의 연속적 추세를 동시에 보는 것이 가장 안전하다.

## 박스플롯: describe()를 눈으로 보기

1.3에서 박스플롯의 구조를 이미 다뤘다. 여기서는 **박스플롯이 잘 보여주는 것과 놓치는 것**에 집중한다.

박스플롯이 보여주는 것:
- **중심 위치**: 중앙값 (박스 안의 선)
- **산포**: IQR (박스의 높이)
- **비대칭성**: 중앙값이 박스 중간에 없으면 skewed
- **이상치**: 위스커 너머의 점들
- **그룹 간 비교**: 여러 박스플롯을 나란히 놓으면 그룹 차이가 한눈에 보임

```python
import seaborn as sns

# 3개 모델의 교차검증 성능 비교
sns.boxplot(data=cv_results_df, x='model', y='accuracy')
```

<!-- [GRAPH: 모델 A, B, C의 교차검증 accuracy를 박스플롯으로 비교. A는 박스가 좁고(안정적), B는 박스가 넓고(불안정), C는 중앙값이 높지만 이상치가 아래에 있음.] -->

이것이 박스플롯의 최대 강점이다. 여러 그룹을 **나란히 놓고 비교하는 것**. 히스토그램을 여러 개 겹쳐 그리면 복잡해지지만, 박스플롯은 깔끔하게 정렬된다.

### 박스플롯이 놓치는 것: 분포의 "모양"

박스플롯의 치명적인 약점이 하나 있다. **분포의 형태(modality)를 보여주지 못한다.**

<!-- [GRAPH: 세 개의 서로 다른 분포 — (1) 정규분포, (2) 이봉분포(bimodal), (3) 균등분포 — 가 동일한 박스플롯을 만드는 예시. 위쪽에 각 분포의 히스토그램, 아래쪽에 동일하게 생긴 박스플롯 3개.] -->

위 그림이 핵심이다. 정규분포, 이봉분포, 균등분포가 **같은 박스플롯**을 만들 수 있다. 중앙값, Q1, Q3, IQR이 같으면 분포의 형태가 아무리 달라도 박스플롯은 구분하지 못한다. 이것은 앤스콤 사중주의 박스플롯 버전이다.

### 바이올린 플롯: 박스플롯 + KDE

이 약점을 보완한 것이 **바이올린 플롯(Violin Plot)**이다.

```python
sns.violinplot(data=cv_results_df, x='model', y='accuracy')
```

바이올린 플롯은 박스플롯의 요약 통계 위에 KDE를 겹쳐서, 분포의 형태까지 보여준다. 이봉분포면 바이올린 모양에 "허리"가 잘록하게 들어간다.

> 💡 **언제 뭘 쓸까?** 그룹이 2~5개이고 분포 형태가 중요하면 바이올린 플롯. 그룹이 10개 이상이거나 빠른 비교가 목적이면 박스플롯. 단일 변수의 분포를 자세히 보려면 히스토그램 + KDE.

## QQ플롯: "정규분포인가?"를 판단하는 최강 도구

이 챕터에서 가장 실전적으로 중요한 플롯이 **QQ플롯(Quantile-Quantile Plot)**이다.

### 왜 정규성 검사가 중요한가

Part 3에서 배울 t-검정, 신뢰구간, 많은 통계적 검정은 **데이터가 정규분포를 따른다**는 가정 위에 서 있다. Part 4에서 배울 선형 회귀의 잔차도 정규성을 가정한다. 이 가정이 깨지면 검정 결과를 신뢰할 수 없다.

"이 데이터가 정규분포를 따르는가?"를 어떻게 확인하는가?

히스토그램을 그려서 "종 모양 같은데?"라고 눈대중으로 판단하는 것은 위험하다. bin 수에 따라 달라 보이니까. 정규성 검정(Shapiro-Wilk 등)을 돌리는 방법도 있지만, n이 크면 거의 항상 기각된다 — 현실 데이터가 "완벽한" 정규분포일 리가 없으니까.

QQ플롯은 이 둘 사이의 **최적의 균형점**이다. "완벽한 정규분포인가?"가 아니라 **"정규분포에서 얼마나, 어디서 벗어나는가?"**를 시각적으로 보여준다.

### QQ플롯의 원리

QQ플롯의 아이디어는 간단하다.

1. 데이터를 크기 순으로 정렬한다 — 이것이 데이터의 **표본 분위수(sample quantiles)**.
2. 이 데이터가 정규분포를 따른다면 이론적으로 있어야 할 위치를 계산한다 — 이것이 **이론 분위수(theoretical quantiles)**.
3. 표본 분위수(y축) vs 이론 분위수(x축)를 산점도로 그린다.

데이터가 정규분포를 정확히 따르면, 모든 점이 **45도 대각선** 위에 놓인다. 벗어나는 패턴이 있다면, 그 패턴 자체가 "어디서 어떻게 벗어나는지"를 말해준다.

```python
from scipy import stats
import matplotlib.pyplot as plt

data = np.random.normal(0, 1, 500)  # 정규분포에서 뽑은 데이터
stats.probplot(data, dist="norm", plot=plt)
plt.title("QQ플롯: 정규분포 데이터")
```

### QQ플롯 읽는 법

<!-- [GRAPH: 4개의 QQ플롯을 2×2 격자로. (1) 정규분포: 점들이 대각선 위에 깔끔하게 놓임. (2) 오른쪽 꼬리가 두꺼운 분포(heavy tail): 오른쪽 위에서 대각선 위로 휘어짐. (3) 왼쪽으로 skewed: S자 형태. (4) 이봉분포: 계단 모양. 각 그래프에 해석 주석.] -->

| QQ플롯 패턴 | 의미 | 실무적 함의 |
|------------|------|-----------|
| 점이 대각선 위에 놓임 | 정규분포를 잘 따름 | t-검정, 선형 회귀 가정 OK |
| 양쪽 끝이 대각선 위로 휘어짐 | 꼬리가 두꺼움 (heavy-tailed) | 이상치 빈번. 강건한 방법 필요 |
| 양쪽 끝이 대각선 아래로 휘어짐 | 꼬리가 얇음 (light-tailed) | 균등분포에 가까움 |
| S자 형태 | 비대칭 (skewed) | 로그 변환 고려 (1.1 참조) |
| 계단 또는 평탄 구간 | 이산적이거나 이봉 분포 | 혼합 분포일 가능성. 그룹 분리 고려 |

QQ플롯의 진가는 **꼬리(tail) 행동**을 드러내는 데 있다. 히스토그램에서는 꼬리 부분의 데이터가 워낙 적어서 bin이 납작해지고 잘 안 보이지만, QQ플롯에서는 꼬리의 벗어남이 **그래프의 양 끝에서 극적으로 확대**되어 나타난다.

<details>
<summary>🔬 Deep Dive — QQ플롯의 이론 분위수는 어떻게 계산되는가?</summary>

데이터 $n$개를 크기 순으로 정렬한 것을 $x_{(1)} \leq x_{(2)} \leq \cdots \leq x_{(n)}$이라 하자.

$i$번째 데이터의 이론 분위수는, 표준 정규분포의 $\frac{i - 0.5}{n}$ 분위수로 계산한다. 즉:

$$q_i = \Phi^{-1}\left(\frac{i - 0.5}{n}\right)$$

여기서 $\Phi^{-1}$은 표준 정규분포의 역누적분포함수(inverse CDF, 또는 percent-point function)다. `scipy.stats.norm.ppf()`가 이것을 계산한다.

$(i - 0.5)/n$에서 0.5를 빼는 것은 **연속성 보정(continuity correction)**이다. $i/n$을 그대로 쓰면 마지막 데이터($i = n$)의 이론 분위수가 $\Phi^{-1}(1) = \infty$가 되어 그래프가 터진다. 0.5를 빼서 $\Phi^{-1}(n-0.5/n)$으로 유한한 값을 만든다.

데이터가 $N(\mu, \sigma^2)$를 정확히 따르면, $x_{(i)} \approx \mu + \sigma \cdot q_i$가 성립한다. 즉 점들이 기울기 $\sigma$, 절편 $\mu$인 직선 위에 놓인다. 기울기가 1이 아닌 것은 스케일의 차이일 뿐, **직선 위에 놓이는지 여부**가 정규성 판단의 핵심이다.

</details>

## 산점도: 관계를 보는 가장 직접적인 방법

1.4에서 피어슨 r의 함정을 배우면서, 결국 가장 확실한 방법은 **산점도를 그려보는 것**이라는 결론에 도달했다. 여기서는 산점도를 더 효과적으로 쓰는 몇 가지 팁을 짚는다.

### 데이터가 많을 때: 오버플로팅 문제

데이터가 수만~수십만 개이면 점이 겹쳐서 밀도가 보이지 않는다. 모든 점이 까만 덩어리로 뭉쳐 보인다.

해결법:
- **투명도(alpha)**: `plt.scatter(x, y, alpha=0.1)`. 겹치는 영역이 진하게 보인다.
- **2D 히스토그램**: `plt.hist2d(x, y, bins=50)`. 밀도를 색상으로 표현.
- **Hexbin**: `plt.hexbin(x, y, gridsize=30)`. 2D 히스토그램의 육각형 버전. 더 부드럽다.

```python
fig, axes = plt.subplots(1, 3, figsize=(15, 4))

axes[0].scatter(x, y, alpha=0.05)
axes[0].set_title("alpha=0.05")

axes[1].hist2d(x, y, bins=50, cmap='Blues')
axes[1].set_title("2D Histogram")

axes[2].hexbin(x, y, gridsize=30, cmap='Blues')
axes[2].set_title("Hexbin")
```

### 피처-타겟 관계 빠르게 훑기

피처가 수십 개일 때, 각각의 타겟과의 관계를 빠르게 확인하고 싶으면:

```python
# seaborn pairplot — 피처가 적을 때 (10개 이하)
sns.pairplot(df[['feat1', 'feat2', 'feat3', 'target']])

# 피처가 많을 때 — 타겟 기준 1열 산점도
fig, axes = plt.subplots(4, 5, figsize=(20, 16))
for i, col in enumerate(feature_cols[:20]):
    ax = axes[i // 5, i % 5]
    ax.scatter(df[col], df['target'], alpha=0.1, s=1)
    ax.set_xlabel(col)
```

1.4의 교훈과 연결하면: 이 산점도에서 **비선형 패턴이 보이는 피처**는 피어슨 r이 낮더라도 버리면 안 된다. 눈으로 확인하는 것이 `df.corr()`보다 정직하다.

## EDA의 순서: 실무 워크플로우

Part 1 전체를 관통하는 실무 워크플로우를 정리하자. 새로운 데이터셋을 받았을 때 첫 30분 동안 해야 할 일이다.

**1단계: 숫자로 요약** (1.1~1.3)
```python
df.describe()                    # 평균, 표준편차, 사분위수
df.skew()                        # 왜도 — 로그 변환 필요한 피처 식별
df.isnull().sum()                # 결측치
```

**2단계: 분포 확인** (1.5)
```python
for col in feature_cols:
    sns.histplot(df[col], kde=True)   # 분포 형태, 이봉성, 이상치
```

**3단계: 관계 확인** (1.4 + 1.5)
```python
df.corr(method='spearman')           # 피어슨 대신 스피어만
# + 타겟 대비 산점도로 비선형 관계 확인
```

**4단계: 정규성 확인** (1.5)
```python
from scipy import stats
stats.probplot(residuals, dist="norm", plot=plt)   # QQ플롯
```

이 순서를 습관화하면, 모델을 만들기 전에 데이터의 성격을 파악한 상태에서 출발하게 된다. 손실함수 선택(1.1), 스케일링 방식(1.2), 이상치 전략(1.3), 피처 선택(1.4)에 대한 판단이 데이터에 근거하게 된다.

## 핵심 정리

- **히스토그램은 bin 수에 민감하다.** 하나의 bin 설정만 보지 말고, 여러 설정으로 비교하라. KDE를 겹쳐 그리면 더 안정적이다.
- **박스플롯은 그룹 비교에 최적이지만, 분포의 형태(이봉성 등)를 놓친다.** 바이올린 플롯이 이 약점을 보완한다.
- **QQ플롯은 정규성을 판단하는 최강 도구다.** 대각선에서 벗어나는 패턴이 "어디서 어떻게 벗어나는지"를 알려준다. Part 3, 4의 가정 검증에 반복적으로 사용된다.
- **EDA의 순서**: describe() → 분포 시각화 → 관계 확인(스피어만 + 산점도) → 정규성 확인(QQ플롯).
- **항상 데이터를 눈으로 봐라.** 통계량은 데이터의 압축이고, 압축에는 항상 정보 손실이 있다.
