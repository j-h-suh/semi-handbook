# 3.3 가설검정의 프레임워크 — p-value, 유의수준, 검정력

## 이 챕터에서 배우는 것

- 가설검정의 논리 구조 — "효과가 있다"를 직접 증명하지 않고 "효과가 없다"를 부정하는 이유
- p-value의 정확한 정의 — 가장 오해받는 통계 개념
- 유의수준 α와 두 종류의 오류 — 왜 α = 0.05인가
- 검정력(Power) — 모델 비교에서 "차이를 발견하지 못했다 ≠ 차이가 없다"인 이유

---

## 가설검정이 필요한 순간

모델 A의 정확도가 0.85이고, 모델 B의 정확도가 0.87이다. B가 더 좋은가?

3.2에서 배운 것으로 판단해 보자. A의 95% CI가 (0.82, 0.88)이고 B의 95% CI가 (0.84, 0.90)이라면, 두 CI가 겹친다. "B가 진짜 더 좋은지, 우연인지" 확신이 안 선다.

**가설검정(Hypothesis Testing)**은 이 질문에 체계적으로 답하는 프레임워크다. "이 차이가 우연으로 설명 가능한가?"를 묻는다.

---

## 가설검정의 논리 구조

### 귀류법의 통계적 버전

가설검정은 **귀류법(proof by contradiction)**의 구조를 따른다.

1. "효과가 없다"고 가정한다 (귀무가설)
2. 이 가정 하에서 관측된 결과가 얼마나 극단적인지 계산한다
3. 극단적이면 → 가정이 틀렸을 가능성이 높다 → 가정을 기각한다
4. 극단적이지 않으면 → 가정을 기각할 근거가 부족하다

### 두 가설

**귀무가설 (Null Hypothesis, $H_0$)**: "효과가 없다", "차이가 없다", "변화가 없다."
- "두 모델의 성능 차이는 0이다" ($H_0: \mu_A = \mu_B$)
- "이 피처는 타겟과 관계가 없다"
- "새 알고리즘은 기존 것과 같다"

**대립가설 (Alternative Hypothesis, $H_1$ 또는 $H_a$)**: "효과가 있다", "차이가 있다."
- "두 모델의 성능이 다르다" ($H_1: \mu_A \neq \mu_B$)
- "이 피처는 타겟과 관계가 있다"
- "새 알고리즘이 기존 것보다 낫다"

핵심: **우리가 증명하고 싶은 것이 대립가설이다.** 하지만 직접 증명하지 않는다. 대신 귀무가설을 부정함으로써 간접적으로 대립가설을 지지한다.

왜 이런 우회적 방법을 쓰는가? "효과가 있다"를 직접 증명하려면 모든 가능한 "효과 없음"의 시나리오를 배제해야 한다. 이것은 불가능하다. 반면 "효과가 없다고 가정했을 때 이런 데이터가 나올 확률"은 계산할 수 있다. 그 확률이 매우 작으면, "효과가 없다"는 가정이 그럴듯하지 않다고 판단하는 것이다.

---

## 검정 통계량

귀무가설 하에서 "관측 결과가 얼마나 극단적인지"를 하나의 숫자로 요약한 것이 **검정 통계량(test statistic)**이다.

두 모델의 성능 차이를 검정하는 가장 단순한 경우:

$$z = \frac{\bar{x}_B - \bar{x}_A}{\text{SE}_{\text{diff}}} = \frac{\text{관측된 차이}}{\text{차이의 표준오차}}$$

분자는 "얼마나 차이가 나는가", 분모는 "그 차이의 불확실성은 얼마인가". 이 비율이 크면 "불확실성에 비해 차이가 크다" = 우연이 아닐 가능성이 높다.

$H_0$이 참이면 ($\mu_A = \mu_B$), CLT에 의해 이 검정 통계량은 대략 $N(0, 1)$을 따른다. 이것이 가설검정과 CLT의 연결 고리다.

---

## p-value: 가장 오해받는 숫자

### 정의

$$p\text{-value} = P(\text{검정 통계량이 관측값만큼 또는 더 극단적} \mid H_0\text{이 참})$$

"귀무가설이 참이라고 가정했을 때, 현재 데이터만큼 또는 더 극단적인 결과가 나올 확률."

구체적으로: $z = 2.3$이 나왔다면, $P(|Z| \geq 2.3 \mid H_0) = 0.021$. 귀무가설 하에서 이 정도 차이가 우연히 나올 확률이 2.1%라는 뜻이다.

### 올바른 해석

✅ "귀무가설이 참일 때, 이 데이터만큼 극단적인 결과가 우연히 나올 확률이 p다."

### 잘못된 해석들

❌ **"귀무가설이 참일 확률이 p다."** — p-value는 $P(\text{데이터} \mid H_0)$이지, $P(H_0 \mid \text{데이터})$가 아니다. 2.1에서 배운 $P(A|B) \neq P(B|A)$의 정확한 재현이다.

❌ **"효과의 크기가 크다."** — p-value는 효과 크기를 말해주지 않는다. n이 충분히 크면 아무리 작은 차이도 유의미해진다.

❌ **"결과가 재현 가능하다."** — p = 0.04라고 해서 다음에도 유의미하게 나온다는 보장이 없다.

❌ **"p = 0.06이면 효과가 없다."** — 0.05는 임의의 경계선이지, 자연법칙이 아니다.

<!-- [GRAPH: 표준 정규분포 곡선. z=2.3 이상과 z=-2.3 이하의 영역을 빨간색으로 칠함(양측검정). 빨간 영역의 넓이 = p-value = 0.021. "이 영역의 넓이가 p-value"라는 주석.] -->

## 유의수준 α: 선을 어디에 긋는가

### 정의

**유의수준(Significance Level, α)**은 "귀무가설이 참인데 기각하는 오류를 허용하는 최대 확률"이다.

$p\text{-value} < \alpha$ → $H_0$ 기각. "통계적으로 유의미하다(statistically significant)."

$p\text{-value} \geq \alpha$ → $H_0$ 기각하지 못함. "통계적으로 유의미하지 않다."

### 왜 α = 0.05인가

역사적 관습이다. 로널드 피셔(Ronald Fisher)가 20세기 초에 "p < 0.05면 주목할 만하다"고 제안한 것이 굳어진 것이다. 자연법칙적 근거는 없다. 0.05라는 숫자에 물리적·수학적 특별함은 없으며, "20번 중 1번꼴로 우연히 나올 수 있는 수준"을 직관적으로 수용 가능하다고 본 것에 불과하다.

분야에 따라 오류의 비용이 다르기 때문에 다른 기준을 쓴다:

| 분야 | 통상적 α | 이유 |
|------|---------|------|
| 사회과학 | 0.05 | 관습 |
| 입자물리학 | 0.0000003 (5σ) | 힉스 입자(Higgs boson) 발견 기준. 1000만 분의 3 |
| 의약 임상시험 | 0.01 ~ 0.05 | 환자 안전 |
| A/B 테스트 | 0.05 ~ 0.10 | 비즈니스 맥락에서 유연하게 |

입자물리학에서 5σ를 쓰는 이유는, 한 번의 거짓 발견이 교과서를 고쳐 써야 하는 수준의 비용을 수반하기 때문이다. 반면 A/B 테스트에서 α = 0.10을 쓰는 것은, 버튼 색상을 잘못 바꾸는 비용이 신약의 부작용보다 훨씬 낮기 때문이다. **α는 "거짓 양성의 비용"을 반영한 설계자의 판단이다.**

α를 작게 잡으면 "거짓 양성"이 줄지만, 진짜 효과를 놓칠 위험이 커진다. 이것이 두 종류의 오류다.

---

## 두 종류의 오류

|  | $H_0$ 참 (효과 없음) | $H_0$ 거짓 (효과 있음) |
|--|---------------------|---------------------|
| **$H_0$ 기각** | **제1종 오류 (Type I)** α | 올바른 판단 (검정력) |
| **$H_0$ 기각 안 함** | 올바른 판단 | **제2종 오류 (Type II)** β |

**제1종 오류 (False Positive, α)**: 효과가 없는데 "있다"고 판단. "불량이 아닌데 불량이라고 판정."

**제2종 오류 (False Negative, β)**: 효과가 있는데 "없다"고 판단. "불량인데 정상이라고 통과."

ML의 confusion matrix와 정확히 같은 구조다:

| 가설검정 | ML 분류 |
|---------|---------|
| 제1종 오류 (α) | False Positive (1 - Specificity) |
| 제2종 오류 (β) | False Negative (1 - Recall) |
| 검정력 (1 - β) | Recall (Sensitivity) |
| 유의수준 (α) | FPR (False Positive Rate) |

**α와 β는 트레이드오프다.** α를 줄이면(기각 기준을 엄격히 하면) β가 커진다(진짜 효과를 놓칠 확률이 높아진다). 이것은 ML에서 threshold를 올리면 Precision은 오르지만 Recall이 내려가는 것과 같은 구조다.

---

## 검정력: "차이를 발견하지 못했다 ≠ 차이가 없다"

### 정의

**검정력(Power) = $1 - \beta$**

"진짜 효과가 있을 때, 그것을 발견할 확률."

검정력이 낮으면, 효과가 있어도 "유의미하지 않다"라는 결과가 나온다. **"유의미하지 않다"는 "효과가 없다"와 같은 말이 아니다.** 검정력이 부족해서 발견 못한 것일 수 있다.

구체적 수치로 보자. 두 모델의 진짜 성능 차이가 작은 편(Cohen's d = 0.3)이고 표본이 각 그룹 50개일 때, 검정력은 약 48%에 불과하다. 즉 진짜 차이가 있어도 **절반 이상의 확률로 "유의미하지 않다"**는 결과가 나온다. 80% 검정력을 확보하려면 각 그룹 약 176개가 필요하다.

이것이 ML에서 흔히 저지르는 실수다:

> "모델 A와 B를 비교했더니 p = 0.15였어. 유의미한 차이가 없으니 둘 다 같은 성능이야."

이 결론은 **검정력을 확인하지 않으면** 정당화되지 않는다. 만약 테스트셋이 50개뿐이었다면, 검정력이 30%밖에 안 될 수 있다. 즉, 진짜 차이가 있더라도 70% 확률로 놓치는 상황이다.

### 검정력에 영향을 주는 것

$$\text{Power} = f(\text{효과 크기}, \, n, \, \alpha, \, \sigma)$$

| 요인 | 검정력에 미치는 영향 |
|------|-------------------|
| **효과 크기** ↑ | Power ↑ (큰 차이는 발견하기 쉽다) |
| **표본 크기 n** ↑ | Power ↑ (데이터가 많으면 발견력 증가) |
| **유의수준 α** ↑ | Power ↑ (기준을 느슨히 하면 발견하기 쉽다) |
| **변동성 σ** ↑ | Power ↓ (노이즈가 크면 신호를 찾기 어렵다) |

<!-- [GRAPH: 두 개의 정규분포 곡선. 왼쪽 곡선: H₀의 분포 (μ=0 중심). 오른쪽 곡선: H₁의 분포 (μ=δ 중심, δ는 효과 크기). α 영역(왼쪽 곡선의 오른쪽 꼬리)과 β 영역(오른쪽 곡선에서 α 임계값 왼쪽 부분)을 색칠. Power = 오른쪽 곡선에서 임계값 오른쪽 부분.] -->

### 사전 검정력 분석 (Power Analysis)

실험 전에 "원하는 검정력을 달성하려면 데이터가 얼마나 필요한가?"를 계산하는 것이 **검정력 분석(power analysis)**이다.

```python
from statsmodels.stats.power import TTestIndPower

analysis = TTestIndPower()

# 효과 크기 0.3 (small-medium), α=0.05, power=0.80
n = analysis.solve_power(effect_size=0.3, alpha=0.05, power=0.80)
print(f"효과 크기 0.3을 80% 확률로 탐지하려면: n = {n:.0f} (각 그룹)")
```

이것을 실험 후에 하면 의미가 없다 — **사후 검정력 분석(post-hoc power analysis)**은 p-value의 변환에 불과하므로 새로운 정보를 주지 않는다. 반드시 실험 전에 해야 한다.

A/B 테스트 설계에서 이것이 핵심이다. Part 6.1에서 본격적으로 다룬다.

## 가설검정의 완전한 절차

정리하면 가설검정은 5단계로 진행된다.

**1단계: 가설 설정**
- $H_0$: 두 모델의 성능 차이 = 0
- $H_1$: 두 모델의 성능 차이 ≠ 0

**2단계: 유의수준 결정**
- α = 0.05 (또는 맥락에 맞게)

**3단계: 검정 통계량 계산**
- $z = (\bar{x}_B - \bar{x}_A) / \text{SE}_{\text{diff}}$

**4단계: p-value 계산**
- 검정 통계량의 표본 분포에서 관측값 이상의 확률

**5단계: 판단**
- $p < \alpha$ → $H_0$ 기각
- $p \geq \alpha$ → $H_0$ 기각 실패 (≠ $H_0$ 수용)

"기각 실패"와 "수용"은 다르다. "기각할 증거가 부족하다"는 것이지 "귀무가설이 맞다"는 뜻이 아니다. 형사 재판의 "무죄"와 비슷하다 — "유죄가 아님"이지 "결백함"이 아니다.

---

## 효과 크기: p-value가 말해주지 않는 것

p-value는 "이 차이가 우연인가?"를 말하지, "이 차이가 의미 있는가?"를 말하지 않는다.

예를 들어 모델 A의 정확도가 0.8500이고 B가 0.8502다. 차이는 0.0002. 테스트셋이 1,000,000개라면 p < 0.001이 나올 수 있다. "통계적으로 유의미하다." 하지만 0.02% 차이가 실무적으로 의미가 있는가? 아마 아닐 것이다.

**효과 크기(Effect Size)**는 차이의 크기를 표준화한 것이다. 가장 흔한 것이 **코헨의 d(Cohen's d)**:

$$d = \frac{\bar{x}_B - \bar{x}_A}{s_{\text{pooled}}}$$

| Cohen's d | 해석 |
|-----------|------|
| 0.2 | 작은 효과 |
| 0.5 | 중간 효과 |
| 0.8 | 큰 효과 |

p-value와 효과 크기를 함께 보고해야 완전한 판단이 가능하다. "차이가 유의미하고(p < 0.05), 효과 크기가 충분히 크다(d = 0.5)."

> 💡 **p-value, 신뢰구간, 효과 크기는 같은 동전의 세 면이다.** 차이의 95% CI가 0을 포함하지 않으면 p < 0.05이고, CI의 폭이 효과 크기의 불확실성을 보여준다. 셋 중 하나만 보고하면 정보의 1/3만 전달하는 것이다.

## Python으로 확인하기

```python
import numpy as np
from scipy import stats

np.random.seed(42)

# 1. 기본 가설검정: 두 모델 비교
model_a_scores = np.array([0.83, 0.86, 0.84, 0.87, 0.85, 0.84, 0.86, 0.83, 0.85, 0.84])
model_b_scores = np.array([0.86, 0.89, 0.87, 0.88, 0.90, 0.87, 0.88, 0.86, 0.89, 0.87])

# 대응 표본 t-검정 (같은 데이터에서 두 모델을 비교)
t_stat, p_value = stats.ttest_rel(model_b_scores, model_a_scores)
diff = model_b_scores - model_a_scores
cohen_d = diff.mean() / diff.std(ddof=1)

print(f"=== 두 모델 비교 ===")
print(f"A 평균: {model_a_scores.mean():.3f}")
print(f"B 평균: {model_b_scores.mean():.3f}")
print(f"차이: {diff.mean():.3f}")
print(f"t 통계량: {t_stat:.3f}")
print(f"p-value: {p_value:.4f}")
print(f"Cohen's d: {cohen_d:.3f}")
print(f"결론: {'유의미' if p_value < 0.05 else '유의미하지 않음'} (α=0.05)")

# 2. 샘플 크기와 p-value의 관계
print(f"\n=== 같은 효과, 다른 n ===")
true_diff = 0.02  # 진짜 차이는 2%p
for n in [10, 50, 100, 500, 1000]:
    a = np.random.normal(0.85, 0.05, n)
    b = np.random.normal(0.85 + true_diff, 0.05, n)
    _, p = stats.ttest_ind(a, b)
    print(f"  n={n:>5}: p = {p:.4f} {'*' if p < 0.05 else ''}")

# 3. 검정력 분석
from statsmodels.stats.power import TTestIndPower
analysis = TTestIndPower()

print(f"\n=== 검정력 분석: 효과 크기별 필요 n ===")
for d in [0.2, 0.3, 0.5, 0.8]:
    n_needed = analysis.solve_power(effect_size=d, alpha=0.05, power=0.80)
    print(f"  d={d}: n = {n_needed:.0f} (각 그룹)")

# 4. 검정력 시뮬레이션
print(f"\n=== 검정력 시뮬레이션 (d=0.3, n=50) ===")
n_sim = 10000
significant = 0
for _ in range(n_sim):
    a = np.random.normal(0, 1, 50)
    b = np.random.normal(0.3, 1, 50)  # 진짜 차이 d=0.3
    _, p = stats.ttest_ind(a, b)
    if p < 0.05:
        significant += 1

print(f"  {n_sim}회 중 유의미 판정: {significant} ({significant/n_sim:.1%})")
print(f"  → 실제 검정력: {significant/n_sim:.1%} (이론적으로 ~48%)")
print(f"  → n=50으로는 d=0.3을 절반도 못 잡는다!")
```

## 핵심 정리

- **가설검정은 귀류법이다.** "효과 없다"를 가정하고, 데이터가 이 가정과 모순되는지 본다.
- **p-value = $P(\text{이 데이터 이상으로 극단적} \mid H_0)$.** $P(H_0 \mid \text{데이터})$가 아니다. 조건의 방향을 뒤집지 마라.
- **"유의미하지 않다" ≠ "효과가 없다."** 검정력이 부족하면 진짜 효과도 놓친다. 결론 내기 전에 검정력을 확인하라.
- **n이 크면 아무리 작은 차이도 유의미해진다.** p-value만으로는 차이의 "크기"를 알 수 없다. 효과 크기(Cohen's d)를 함께 보고하라.
- **p-value, 신뢰구간, 효과 크기를 함께 보고하라.** 하나만 보면 정보의 1/3이다.
- **검정력 분석은 실험 전에 하라.** "이 효과를 잡으려면 데이터가 얼마나 필요한가?"
