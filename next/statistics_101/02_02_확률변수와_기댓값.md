## 이 챕터에서 배우는 것

- 확률변수(Random Variable)가 "변수"도 "랜덤"도 아닌 이유 — 그것은 함수다
- PMF, PDF, CDF — 분포를 기술하는 세 가지 언어
- 기댓값 $E[X]$이 평균과 같으면서도 다른 이유
- ML의 손실함수가 사실은 기댓값이라는 것

## "X ~ N(μ, σ²)"를 소리 내어 읽을 수 있는가?

ML 논문이나 코드에서 이런 표기를 수없이 본다:

$$X \sim N(\mu, \sigma^2)$$

"X는 평균 μ, 분산 σ²인 정규분포를 따른다"라고 읽는다. 여기까지는 대부분 안다.

하지만 조금만 더 파고들면 애매해진다. $X$가 정확히 뭔가? "랜덤한 변수"? 그러면 값이 정해지지 않은 건가? `np.random.normal(mu, sigma)`를 한 번 호출한 결과인가? 아니면 호출할 수 있는 가능성 자체를 말하는 건가?

이 개념을 명확히 하지 않으면, 기댓값, 분산, 분포라는 단어를 쓰면서도 정확히 뭘 말하는 건지 흐릿한 상태로 남게 된다. 이 챕터에서 그 흐릿함을 잡는다.

## 확률변수: 사실은 함수다

**확률변수(Random Variable)**는 이름이 오해를 부르는 대표적인 사례다. 변수(variable)도 아니고 랜덤(random)도 아니다. 정확히는 **함수(function)**다.

표본공간(sample space) $\Omega$의 각 결과를 숫자로 대응시키는 함수:

$$X: \Omega \rightarrow \mathbb{R}$$

동전 두 개를 던지는 실험을 생각하자. 표본공간은 $\Omega = \{HH, HT, TH, TT\}$다. "앞면의 수"를 세는 확률변수 $X$를 정의하면:

| 결과 ω | X(ω) |
|--------|------|
| HH | 2 |
| HT | 1 |
| TH | 1 |
| TT | 0 |

$X$는 각 결과에 숫자를 붙이는 규칙이다. "랜덤"한 것은 $X$ 자체가 아니라, 어떤 $\omega$가 실현될지 모른다는 것이다.

CS 비유로 설명하면, 확률변수는 **인터페이스(interface)**에 가깝다. `.sample()`을 호출할 때마다 다른 값이 나오지만, 어떤 값이 얼마나 자주 나오는지의 규칙(= 분포)은 고정되어 있다.

```python
import torch.distributions as dist

# X ~ N(0, 1) 정의 — 이 시점에서 X는 "분포 객체"
X = dist.Normal(loc=0, scale=1)

# .sample()을 호출해야 구체적인 값이 나온다
x1 = X.sample()          # 하나의 실현값 (realization)
x100 = X.sample((100,))  # 100개의 실현값
```

`X`는 분포 자체(= 확률변수)이고, `x1`이나 `x100`은 그 분포에서 실현된 구체적 값(= 관측값, observation)이다. ML에서 데이터셋은 확률변수의 **실현값들의 모음**이다.

그리고 중요한 점 — 입력 데이터만 확률변수가 아니다. **모델의 예측값 $\hat{Y} = f(X)$도 확률변수다.** $X$가 확률변수이고 $f$가 고정된 함수라면, $f(X)$도 확률변수가 된다. 학습된 모델의 성능 지표(accuracy, loss)가 테스트셋마다 달라지는 이유가 이것이다 — 입력이 확률적이면 출력도 확률적이다.

## 이산 vs 연속: 두 가지 세계

확률변수는 취할 수 있는 값의 종류에 따라 두 가지로 나뉜다.

### 이산 확률변수 (Discrete)

셀 수 있는 값을 취한다. 동전 앞면의 수(0, 1, 2), 결함 개수(0, 1, 2, ...), 클래스 레이블(0, 1, 2, ..., K-1).

분포를 기술하는 도구: **확률질량함수(PMF, Probability Mass Function)**

$$p(x) = P(X = x)$$

각 값 $x$에 대해 "그 값이 나올 확률"을 직접 지정한다. 모든 $p(x) \geq 0$이고 합이 1.

```python
# 주사위의 PMF
x_values = [1, 2, 3, 4, 5, 6]
pmf = [1/6] * 6  # 각 값의 확률
```

### 연속 확률변수 (Continuous)

연속적인 값을 취한다. 온도, 전압, overlay 오차, 모델의 예측 확률.

여기서 직관이 살짝 무너진다. 연속 확률변수에서 $P(X = 2.5) = 0$이다. 정확히 2.5일 확률은 0이다. 정확히 2.500000...일 확률은 무한히 많은 가능한 값 중 하나이므로 0이다. 그런데 2.5 근처의 값이 나올 확률은 0이 아니다. 이 "근처"를 다루는 것이 **확률밀도함수(PDF, Probability Density Function)**다.

$$P(a \leq X \leq b) = \int_a^b f(x) \, dx$$

PDF $f(x)$는 확률 자체가 아니라 **확률의 밀도**다. $f(x)$의 값이 높다는 것은 "그 근처에서 값이 나올 확률이 상대적으로 높다"는 뜻이다. 확률은 구간에 대해서만 정의된다 — 밀도를 구간에 걸쳐 적분해야 확률이 된다.

> 💡 **PDF는 1을 초과할 수 있다.** 확률은 0~1이지만, 밀도는 그렇지 않다. 예를 들어 $\text{Uniform}(0, 0.5)$의 PDF는 $f(x) = 2$이다 (구간 길이가 0.5이므로 높이가 2여야 넓이가 1). 처음에 헷갈릴 수 있지만, "밀도 × 구간 너비 = 확률"이므로 밀도 자체는 1 이상이어도 된다.

### CDF: 둘을 통합하는 도구

**누적분포함수(CDF, Cumulative Distribution Function)**는 이산이든 연속이든 상관없이 쓸 수 있다.

$$F(x) = P(X \leq x)$$

"$x$ 이하일 확률"을 $x$의 함수로 그린 것이다. 항상 0에서 시작해서 1로 끝나고, 단조 비감소(non-decreasing)한다. 엄밀히는 "strictly increasing"이 아니다 — 이산 확률변수의 CDF는 계단 함수이고, 연속 확률변수라도 확률이 0인 구간에서는 CDF가 평평하다.

<!-- [GRAPH: 2×2 격자. 왼쪽 열: 이산 확률변수. PMF(막대그래프)와 CDF(계단 함수). 오른쪽 열: 연속 확률변수(정규분포). PDF(종 모양 곡선)와 CDF(S자 곡선). 각 그래프에 특징 주석.] -->

ML에서 CDF를 직접 다루는 상황:

- **백분위수 계산**: 1.3에서 배운 p50, p90, p99는 CDF의 역함수다. "$P(X \leq x) = 0.99$인 $x$가 p99."
- **p-value 계산**: Part 3에서 배울 p-value는 검정 통계량의 CDF에서 읽는다.
- **`scipy.stats.norm.cdf(x)`**: 정규분포의 CDF. `norm.ppf(0.975)`는 그 역함수(= 97.5번째 백분위수 = 1.96).

## 기댓값: 평균의 이론적 버전

### 정의

이산:
$$E[X] = \sum_x x \cdot p(x)$$

연속:
$$E[X] = \int_{-\infty}^{\infty} x \cdot f(x) \, dx$$

"각 값에 그 확률(또는 밀도)을 가중치로 곱해서 더한 것." 1.1에서 배운 **가중평균**의 확률 버전이다.

기댓값과 표본평균의 관계:

| | 기댓값 $E[X]$ | 표본평균 $\bar{x}$ |
|--|-------------|------------------|
| 대상 | 확률분포 (이론) | 데이터 (관측) |
| 계산 | 확률로 가중 | 균등하게 가중 (1/n) |
| 값 | 고정된 상수 | 표본마다 달라짐 |
| 표기 | $\mu$ | $\bar{x}$ |

표본평균 $\bar{x}$은 기댓값 $E[X]$의 **추정값(estimator)**이다. 데이터를 많이 모을수록 $\bar{x} \rightarrow E[X]$에 가까워진다 — 이것이 Part 2.6에서 배울 큰 수의 법칙(LLN)이다.

### 기댓값의 성질

기댓값에는 놀라울 정도로 편리한 성질들이 있다.

**1. 선형성**: 어떤 상황에서든 (독립이든 아니든) 성립한다.

$$E[aX + bY + c] = aE[X] + bE[Y] + c$$

**2. 독립일 때 곱의 기댓값**:

$$E[XY] = E[X] \cdot E[Y] \quad \text{(X, Y가 독립일 때만)}$$

**3. 함수의 기댓값 (LOTUS)**:

$$E[g(X)] = \sum_x g(x) \cdot p(x) \quad \text{or} \quad \int g(x) \cdot f(x) \, dx$$

$g(X)$의 분포를 따로 구하지 않아도 원래 분포에서 바로 계산할 수 있다.

<details>
<summary>🔬 Deep Dive — 분산을 기댓값으로 다시 쓰기</summary>

1.2에서 분산을 "편차 제곱의 평균"이라고 정의했다. 이것을 기댓값 표기로 다시 쓰면:

$$\text{Var}(X) = E[(X - E[X])^2]$$

전개하면 실용적인 공식이 나온다:

$$\text{Var}(X) = E[X^2] - (E[X])^2$$

"제곱의 기댓값 - 기댓값의 제곱." 이 공식은 이론적 유도에서 자주 쓰이니 기억해 두면 좋다.

그리고 기댓값의 선형성에서 중요한 것: **분산은 선형성이 없다.**

$$\text{Var}(aX + b) = a^2 \text{Var}(X)$$

상수를 더하면($+b$) 분산은 변하지 않고, 상수를 곱하면($aX$) 분산은 $a^2$배가 된다. 1.2에서 StandardScaler가 표준편차로 나누면 분산이 1이 되는 이유가 이것이다: $\text{Var}(X/\sigma) = \text{Var}(X)/\sigma^2 = 1$.

독립인 확률변수의 합의 분산:

$$\text{Var}(X + Y) = \text{Var}(X) + \text{Var}(Y) \quad \text{(독립일 때)}$$

이것이 1.2에서 언급한 "분산의 덧셈 성질"이고, 앙상블에서 분산이 $1/n$로 줄어드는 근거이기도 하다.

</details>

## ML의 손실함수는 기댓값이다

여기서부터가 이 챕터의 핵심 연결이다.

ML 모델의 목표를 수식으로 쓰면:

$$\hat{f} = \arg\min_f E_{(X,Y) \sim P_{\text{data}}} [L(Y, f(X))]$$

"데이터 분포에서 뽑은 $(X, Y)$에 대해, 손실 $L$의 **기댓값**을 최소화하는 함수 $f$를 찾아라."

우리가 실제로 계산하는 것은:

$$\hat{f} = \arg\min_f \frac{1}{n} \sum_{i=1}^{n} L(y_i, f(x_i))$$

학습 데이터의 **표본 평균**으로 기댓값을 근사하는 것이다. 모든 ML 학습은 이 구조 위에 서 있다.

| 이론 | 실제 |
|------|------|
| $E[L(Y, f(X))]$ — 기대 손실 (risk) | $\frac{1}{n}\sum L(y_i, f(x_i))$ — 경험적 손실 (empirical risk) |
| 모든 가능한 데이터에 대해 | 우리가 가진 $n$개 데이터에 대해 |
| 알 수 없음 (분포를 모르니까) | 직접 계산 가능 |

이것을 **경험적 위험 최소화(Empirical Risk Minimization, ERM)**라고 부른다. 왜 경험적(empirical)인가? 진짜 기댓값 대신 표본 평균으로 근사하기 때문이다.

이 구조를 이해하면 몇 가지가 명확해진다:

**과적합(overfitting)의 본질**: 경험적 손실(학습 데이터)은 낮추는 데 성공했는데, 기대 손실(새로운 데이터)은 여전히 높은 상태. 표본 평균이 기댓값을 잘 대표하지 못하는 것이다. 학습 데이터가 적거나 모델이 너무 복잡하면 이 괴리가 커진다.

**교차검증의 이유**: 기대 손실을 알 수 없으니, 학습에 안 쓴 데이터로 기대 손실을 추정하는 것이다. 검증 세트의 손실은 기대 손실의 또 다른 표본 평균이다.

## 분포의 파라미터가 뜻하는 것

이제 처음으로 돌아가자. $X \sim N(\mu, \sigma^2)$가 뜻하는 것:

- $X$는 확률변수다 — `.sample()`을 호출할 때마다 다른 값이 나오는 "규칙"
- $N$은 정규분포를 뜻한다 — PDF의 형태가 종 모양으로 정해져 있다
- $\mu$는 기댓값 $E[X]$이다 — 분포의 중심
- $\sigma^2$은 분산 $\text{Var}(X)$이다 — 분포의 퍼짐

이 두 파라미터만으로 정규분포의 모든 것이 결정된다. 이것을 **충분 통계량(sufficient statistic)**이라 한다 — Part 3에서 다시 만난다.

다른 분포는 다른 파라미터를 갖는다:

| 분포 | 표기 | 파라미터의 의미 |
|------|------|---------------|
| 정규분포 | $N(\mu, \sigma^2)$ | 중심, 퍼짐 |
| 베르누이 | $\text{Bern}(p)$ | 성공 확률 |
| 포아송 | $\text{Pois}(\lambda)$ | 평균 발생 횟수 (= $E[X]$ = $\text{Var}(X)$) |
| 지수분포 | $\text{Exp}(\lambda)$ | 발생률 ($E[X] = 1/\lambda$) |

각 분포의 세부 사항은 2.3 (이산분포)과 2.4 (연속분포)에서 다룬다. 여기서는 "파라미터가 분포의 성격을 결정한다"는 구조만 잡고 넘어간다.

## 기댓값이 존재하지 않는 경우

대부분의 실무에서는 마주치지 않지만, 알아두면 유용한 경우가 하나 있다.

**코시 분포(Cauchy distribution)**는 기댓값이 존재하지 않는다. 꼬리가 너무 두꺼워서 $\int x \cdot f(x) \, dx$가 발산한다. 데이터를 아무리 많이 모아도 표본 평균이 특정 값으로 수렴하지 않는다.

```python
from scipy.stats import cauchy
samples = cauchy.rvs(size=10000)
running_means = np.cumsum(samples) / np.arange(1, 10001)
```

<!-- [GRAPH: x축: 샘플 수 (1~10000), y축: 누적 평균. 정규분포 샘플은 빠르게 0으로 수렴하는 반면, 코시 분포 샘플은 수렴하지 않고 계속 요동치는 두 곡선을 겹쳐 그림.] -->

왜 이것이 ML 엔지니어에게 관련이 있는가? 모델의 gradient나 loss가 극단적으로 두꺼운 꼬리를 가질 때, 표본 평균 기반의 최적화(SGD)가 불안정해지는 현상의 이론적 배경이다. gradient clipping이 필요한 이유 중 하나가 바로 이것이다 — 꼬리를 잘라서 기댓값이 안정적으로 존재하게 만드는 것이다.

---

## Python으로 확인하기

```python
import numpy as np
from scipy import stats

# 확률변수 = 분포 객체
X = stats.norm(loc=5, scale=2)  # N(5, 4)

# 이론적 성질
print(f"E[X] = {X.mean():.2f}")        # 5.00
print(f"Var(X) = {X.var():.2f}")        # 4.00
print(f"P(X ≤ 5) = {X.cdf(5):.4f}")    # 0.5000 (중앙)
print(f"P(3 ≤ X ≤ 7) = {X.cdf(7) - X.cdf(3):.4f}")  # ±1σ ≈ 0.6827

# 표본 평균 → 기댓값 수렴
sample_sizes = [10, 100, 1000, 10000, 100000]
for n in sample_sizes:
    sample_mean = X.rvs(size=n).mean()
    print(f"  n={n:>6} → 표본평균: {sample_mean:.4f} (이론값: 5.0)")

# 손실함수 = 기댓값의 표본 근사
print(f"\n=== ERM 구조 확인 ===")
np.random.seed(42)
X_data = np.random.normal(3, 1, 1000)
y_data = 2 * X_data + 1 + np.random.normal(0, 0.5, 1000)

# 경험적 위험 (MSE)
def empirical_risk(w, b, X, y):
    return np.mean((y - (w * X + b)) ** 2)

print(f"w=2.0, b=1.0: risk = {empirical_risk(2.0, 1.0, X_data, y_data):.4f}")
print(f"w=1.5, b=0.5: risk = {empirical_risk(1.5, 0.5, X_data, y_data):.4f}")
print(f"w=3.0, b=2.0: risk = {empirical_risk(3.0, 2.0, X_data, y_data):.4f}")
```

## 핵심 정리

- **확률변수는 함수다.** 표본공간의 결과를 숫자로 대응시키는 규칙. `dist.Normal(0, 1)`이 확률변수이고, `.sample()`의 결과가 실현값이다.
- **PMF는 이산, PDF는 연속, CDF는 둘 다 쓸 수 있다.** PDF는 확률 자체가 아니라 밀도이므로 1을 초과할 수 있다. 확률은 구간에 대해서만 정의된다.
- **기댓값 $E[X]$는 표본평균 $\bar{x}$의 이론적 버전이다.** 데이터를 많이 모을수록 $\bar{x} \rightarrow E[X]$.
- **ML 학습 = 경험적 위험 최소화(ERM).** 기대 손실의 표본 평균 근사. 과적합은 이 근사가 실패한 것이다.
- **$X \sim N(\mu, \sigma^2)$**: $X$는 확률변수, $N$은 분포 형태, $\mu$는 기댓값, $\sigma^2$은 분산. 두 파라미터가 분포의 전부를 결정한다.
