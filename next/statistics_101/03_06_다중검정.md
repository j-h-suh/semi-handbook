# 3.6 다중검정 문제 — 하이퍼파라미터 100개 돌려보고 "유의미"라고?

## 이 챕터에서 배우는 것

- 검정을 반복하면 거짓 양성이 왜 폭증하는지
- 본페로니 보정 — 가장 보수적이고 가장 간단한 해법
- FDR과 Benjamini-Hochberg — "발견 중 거짓 양성의 비율"을 통제하는 현대적 방법
- ML에서 다중검정이 숨어 있는 곳들

---

## 하이퍼파라미터 100개를 시도했다

이런 상황을 생각해 보자.

학습률, 드롭아웃, 레이어 수, 배치 사이즈 등을 조합해서 100가지 설정으로 모델을 돌렸다. 각 설정마다 기준 모델(baseline)과 t-검정을 해서, "이 설정이 기준보다 유의미하게 좋은가?"를 테스트한다. α = 0.05.

100번 검정했더니, 7개 설정에서 p < 0.05가 나왔다. "7개의 유의미한 설정을 발견했다!"

정말 그런가?

기준 모델과 **실제로 차이가 없는** 설정이 100개라고 하자. 각 검정에서 거짓 양성 확률이 5%이니, 100개 중 약 5개는 **우연히** p < 0.05가 나온다. 7개 중 5개가 거짓 양성이면, "발견"의 71%가 환상이다.

이것이 **다중검정 문제(Multiple Testing Problem)**다. 검정을 많이 할수록, 우연히 유의미하게 나오는 것이 늘어난다.

---

## 가족별 오류율 (FWER)

### 정의

$m$번의 검정 중 **하나라도** 거짓 양성이 나올 확률:

$$\text{FWER} = P(\text{적어도 하나의 거짓 양성}) = 1 - (1-\alpha)^m$$

| 검정 횟수 $m$ | FWER (α=0.05) |
|-------------|--------------|
| 1 | 5.0% |
| 5 | 22.6% |
| 10 | 40.1% |
| 20 | 64.2% |
| 100 | 99.4% |

100번 검정하면 거짓 양성이 **하나도 안 나올** 확률이 0.6%. 거의 확실하게 하나 이상의 거짓 양성이 발생한다.

3.5에서 시뮬레이션으로 확인했다: 5그룹 t-검정 반복에서 FWER이 40%. 이론값 $1 - 0.95^{10} = 40.1\%$와 정확히 일치했다.

---

## 보정 방법 1: 본페로니 (Bonferroni)

가장 간단하고 가장 보수적인 방법.

$$\alpha_{\text{adjusted}} = \frac{\alpha}{m}$$

100번 검정하면 각 검정의 유의수준을 $0.05 / 100 = 0.0005$로 낮춘다. 또는 동등하게, p-value에 $m$을 곱해서 조정된 p-value를 쓴다:

$$p_{\text{adjusted}} = \min(p \times m, \; 1)$$

```python
from statsmodels.stats.multitest import multipletests

p_values = [0.001, 0.008, 0.039, 0.041, 0.042, 0.06, 0.50, 0.91]
rejected, p_adj, _, _ = multipletests(p_values, alpha=0.05, method='bonferroni')

for i, (p, p_a, rej) in enumerate(zip(p_values, p_adj, rejected)):
    print(f"  검정 {i+1}: p={p:.3f} → p_adj={p_a:.3f} {'✓' if rej else '✗'}")
```

보정 전에는 5개가 유의미(p < 0.05)했지만, 본페로니 보정 후에는 1개만 남았다. 나머지 4개는 다중검정에 의한 거짓 양성이었을 가능성이 높다.

### 본페로니의 문제: 너무 보수적

본페로니는 FWER을 α 이하로 보장하지만, 대가가 크다. 검정 횟수가 많아지면 개별 기준이 극도로 엄격해져서, **진짜 효과도 놓칠 확률이 급증한다.** 100번 검정에서 각 p < 0.0005여야 하니, 상당히 강한 효과만 살아남는다.

유전체학(genomics)에서 20,000개 유전자를 동시에 검정할 때 본페로니를 쓰면? 각 p < 0.0000025. 거의 아무것도 유의미하지 않게 된다. 이런 상황에서 더 실용적인 접근이 필요하다.

---

## 보정 방법 2: FDR과 Benjamini-Hochberg

### 관점의 전환: FWER → FDR

본페로니는 "거짓 양성이 단 하나도 없어야 한다"는 입장이다. 하지만 현실에서는 이렇게 물을 수도 있다:

> "거짓 양성이 좀 섞여도 괜찮아. 대신 **발견한 것들 중에서** 거짓 양성의 비율만 통제해줘."

이것이 **위발견율(False Discovery Rate, FDR)**이다.

$$\text{FDR} = E\left[\frac{\text{거짓 양성 수}}{\text{유의미 판정 수}}\right]$$

FDR = 0.05란 "유의미하다고 판정한 것들 중 5%가 거짓 양성"이라는 뜻이다.

| | FWER (본페로니) | FDR (BH) |
|--|--------------|---------|
| 통제하는 것 | 거짓 양성이 1개라도 나올 확률 | 발견 중 거짓 양성의 비율 |
| 보수성 | 매우 보수적 | 덜 보수적 |
| 검정력 | 낮음 (진짜도 많이 놓침) | 높음 (더 많이 발견) |
| 적합한 상황 | 하나의 거짓 양성도 치명적 | 발견 목록의 품질이 중요 |

### Benjamini-Hochberg (BH) 절차

1. $m$개의 p-value를 작은 순서로 정렬: $p_{(1)} \leq p_{(2)} \leq \cdots \leq p_{(m)}$
2. 각 $p_{(i)}$에 대해 임계값을 계산: $\frac{i}{m} \cdot \alpha$
3. $p_{(i)} \leq \frac{i}{m} \cdot \alpha$를 만족하는 가장 큰 $i$를 찾는다. 이 $i$ 이하의 모든 검정을 유의미로 판정.

```python
rejected_bh, p_adj_bh, _, _ = multipletests(p_values, alpha=0.05, method='fdr_bh')

print("=== Bonferroni vs BH ===")
for i, (p, p_bon, p_bh, rej_bon, rej_bh) in enumerate(
    zip(p_values, p_adj, p_adj_bh, rejected, rejected_bh)):
    print(f"  검정 {i+1}: p={p:.3f} | Bonf: {p_bon:.3f} {'✓' if rej_bon else '✗'}"
          f" | BH: {p_bh:.3f} {'✓' if rej_bh else '✗'}")
```

## ML에서 다중검정이 숨어 있는 곳

다중검정 문제는 명시적으로 "가설검정을 반복한다"는 인식 없이도 발생한다. ML 파이프라인 곳곳에 숨어 있다.

### 1. 하이퍼파라미터 탐색

100개 설정을 시도하고 "가장 좋은 것"을 고르는 것은 사실상 100번의 암묵적 비교다. 검증 세트에서 가장 좋은 설정이 테스트 세트에서도 좋을 거라는 보장은 없다 — 검증 세트에서의 "최고"가 우연일 수 있다.

**대응**: 검증 세트와 테스트 세트를 분리하라. 하이퍼파라미터 선택에 쓴 데이터(검증)로 최종 성능을 평가하면 안 된다. 이것이 train/validation/test 3분할의 이유다.

### 2. 피처 선택

1000개 피처 각각에 대해 "이 피처가 타겟과 관련 있는가?"를 검정하면, 50개는 우연히 유의미하게 나온다 (α = 0.05). 1.4에서 `df.corr()`로 피처를 거르는 것도 암묵적으로 이 문제를 안고 있다.

**대응**: 피처 선택 시 BH 보정을 적용하거나, 교차검증 기반 피처 선택(recursive feature elimination 등)을 쓴다.

### 3. 여러 지표 동시 비교

모델을 정확도, F1, AUC, 속도 등 5개 지표로 동시에 평가하고, "하나라도 유의미하게 좋으면 채택"이라고 하면 FWER이 올라간다.

### 4. 서브그룹 분석

"전체적으로는 차이가 없지만, 특정 서브그룹(남성, 20대, 서울 거주)에서는 차이가 있다!" — 서브그룹을 많이 나눌수록 우연히 유의미한 서브그룹이 나올 확률이 높아진다. 데이터 드레징(data dredging)이라 불리는 나쁜 관행이다.

## 실무 가이드: 언제 뭘 쓸 것인가

| 상황 | 권장 방법 | 이유 |
|------|----------|------|
| 소수의 사전 정의된 비교 (2~5개) | 본페로니 | 보수적이지만 안전. 검정 수가 적으면 검정력 손실도 작음 |
| 많은 동시 검정 (수십~수천) | BH (FDR) | 본페로니는 너무 엄격. BH가 더 많이 발견 |
| 탐색적 분석 (EDA) | 보정 없이 + 명시 | "이것은 탐색적 분석이며 보정 없음"을 명시. 발견은 추후 확인 실험 필요 |
| 하이퍼파라미터 탐색 | train/val/test 분리 | 통계적 보정보다 실험 설계로 해결 |
| ANOVA 사후 비교 | Tukey HSD | ANOVA 전용 다중비교 보정이 내장 |

## xkcd의 젤리빈 만화

다중검정 문제를 가장 유명하게 풍자한 것이 xkcd의 "Significant" 만화다. 과학자들이 "젤리빈이 여드름을 유발하는가?"를 검정한다. 전체적으로는 유의미하지 않다. 그래서 20가지 색깔별로 따로 검정한다. 초록색 젤리빈에서 p = 0.05가 나온다. 다음날 신문: "초록 젤리빈이 여드름과 연관!"

20가지 색깔을 검정하면 $1 - 0.95^{20} = 64\%$ 확률로 하나는 유의미하게 나온다. 초록색이 "발견"된 것은 다중검정의 희생양일 뿐이다.

ML에서 이것의 대응: "100개 피처를 검정했더니 5개가 유의미했다." 보정 없이는 그 5개 중 대부분이 우연일 수 있다.

---

## Python으로 확인하기

```python
import numpy as np
from scipy import stats
from statsmodels.stats.multitest import multipletests

np.random.seed(42)

# 시뮬레이션: 100개 검정, 실제로 효과가 있는 것은 10개
n_tests = 100
n_true_effects = 10
n_null = n_tests - n_true_effects

# p-value 생성
p_null = np.random.uniform(0, 1, n_null)           # 효과 없음: p가 균등분포
p_effect = np.random.beta(1, 20, n_true_effects)    # 효과 있음: p가 작은 쪽에 몰림

p_values = np.concatenate([p_null, p_effect])
is_true_effect = np.array([False]*n_null + [True]*n_true_effects)

# 셔플
idx = np.random.permutation(n_tests)
p_values = p_values[idx]
is_true_effect = is_true_effect[idx]

# 보정 없음
sig_none = p_values < 0.05
tp_none = (sig_none & is_true_effect).sum()
fp_none = (sig_none & ~is_true_effect).sum()

# 본페로니
sig_bonf, _, _, _ = multipletests(p_values, alpha=0.05, method='bonferroni')
tp_bonf = (sig_bonf & is_true_effect).sum()
fp_bonf = (sig_bonf & ~is_true_effect).sum()

# BH (FDR)
sig_bh, _, _, _ = multipletests(p_values, alpha=0.05, method='fdr_bh')
tp_bh = (sig_bh & is_true_effect).sum()
fp_bh = (sig_bh & ~is_true_effect).sum()

print(f"=== 100개 검정 (10개 진짜 효과) ===\n")
print(f"{'방법':<12} {'유의미':>6} {'진양성':>6} {'거짓양성':>8} {'FDR':>8}")
print("-" * 45)
print(f"{'보정 없음':<12} {sig_none.sum():>6} {tp_none:>6} {fp_none:>8} "
      f"{fp_none/max(sig_none.sum(),1):>8.1%}")
print(f"{'본페로니':<12} {sig_bonf.sum():>6} {tp_bonf:>6} {fp_bonf:>8} "
      f"{fp_bonf/max(sig_bonf.sum(),1):>8.1%}")
print(f"{'BH (FDR)':<12} {sig_bh.sum():>6} {tp_bh:>6} {fp_bh:>8} "
      f"{fp_bh/max(sig_bh.sum(),1):>8.1%}")

# FWER 시뮬레이션: 검정 횟수별
print(f"\n=== FWER vs 검정 횟수 ===")
for m in [1, 5, 10, 20, 50, 100]:
    fwer = 1 - (1 - 0.05)**m
    print(f"  m={m:>3}: FWER = {fwer:.1%}")
```

## 핵심 정리

- **검정을 반복하면 거짓 양성이 폭증한다.** 100번 검정에서 FWER ≈ 99.4%. 하나쯤은 거의 확실하게 우연히 유의미.
- **본페로니: α/m으로 각 검정 기준을 낮춘다.** 간단하고 안전하지만 보수적. 검정 수가 많으면 진짜도 놓친다.
- **BH (FDR): "발견 중 거짓 양성 비율"을 통제.** 본페로니보다 많이 발견하면서 품질을 유지. 대규모 검정의 표준.
- **ML에서 다중검정은 하이퍼파라미터 탐색, 피처 선택, 다중 지표 평가에 숨어 있다.** 인식하지 못하면 "발견"의 대부분이 환상일 수 있다.
- **탐색적 분석에서 발견한 것은 확인 실험으로 검증하라.** 보정으로 해결하는 것보다 실험 설계가 더 근본적인 해법이다.
