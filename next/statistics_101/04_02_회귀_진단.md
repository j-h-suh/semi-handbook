# 4.2 회귀 진단 — 잔차, 이분산성, 다중공선성

## 이 챕터에서 배우는 것

- 잔차 플롯이 "모델의 건강 검진표"인 이유
- 이분산성(Heteroscedasticity) — 잔차가 나팔 모양이면 왜 위험한가
- 다중공선성(Multicollinearity) — VIF로 진단하고, 왜 계수가 폭발하는지
- 모든 진단은 하나의 질문으로 수렴한다: "가정이 맞는가?"

---

## R²가 높은데 모델이 나쁠 수 있다

4.1에서 R²의 한계를 언급했다. 여기서 구체적으로 보자.

R² = 0.95인 모델이 있다. 타겟 변동의 95%를 설명한다. 좋아 보인다. 하지만 잔차를 그려보면:

![잔차 패턴 진단](/content/images/stats/04_02/residual_patterns.svg)

잔차에 패턴이 있다. U자 형태는 "선형 모델로는 잡지 못하는 비선형 관계가 남아 있다"는 뜻이다. R²가 아무리 높아도, 잔차에 구조가 남아 있으면 모델이 불완전하다.

**잔차 분석이 R²보다 중요한 이유가 이것이다.** R²는 "얼마나 설명했는가"를 말하고, 잔차는 **"무엇을 놓쳤는가"**를 말한다.

---

## 잔차 진단의 4가지 플롯

회귀 모델을 피팅한 후 반드시 확인해야 할 4가지 플롯이 있다.

### 1. 잔차 vs 예측값 (Residuals vs Fitted)

가장 중요한 플롯. 이상적으로는 **패턴 없이 랜덤하게 흩어져야 한다.**

| 패턴 | 의미 | 대응 |
|------|------|------|
| 패턴 없음 (랜덤) | 가정이 잘 만족됨 | OK |
| U자 또는 곡선 | 비선형 관계 존재 | 다항 피처, 비선형 모델 고려 |
| 나팔 모양 (퍼져감) | 이분산성 | 가중최소제곱, 로그 변환 |
| 깔때기 모양 (좁아짐) | 역 이분산성 | 드물지만 동일 대응 |

```python
import matplotlib.pyplot as plt
import statsmodels.api as sm

model = sm.OLS(y, sm.add_constant(X)).fit()
residuals = model.resid
fitted = model.fittedvalues

plt.scatter(fitted, residuals, alpha=0.5)
plt.axhline(y=0, color='red', linestyle='--')
plt.xlabel('예측값')
plt.ylabel('잔차')
plt.title('잔차 vs 예측값')
```

### 2. QQ플롯 (정규성)

1.5에서 배운 QQ플롯을 잔차에 적용한다.

```python
from scipy import stats
stats.probplot(residuals, dist="norm", plot=plt)
plt.title('잔차의 QQ플롯')
```

대각선에서 벗어나면 잔차의 정규성 가정이 위반된 것이다. 양쪽 끝이 위로 휘면 꼬리가 두꺼운 것(이상치가 많다), S자 형태면 비대칭(1.1의 왜도 문제).

### 3. Scale-Location 플롯 (등분산성)

**Scale-Location 플롯(Spread-Location 플롯이라고도 한다)**은 $\sqrt{|\text{표준화 잔차}|}$를 y축, 예측값을 x축에 놓은 그래프다. 표준화 잔차의 절대값에 제곱근을 취한 것이므로 잔차의 "크기"만 본다(방향은 무시). 등분산이면 수평 밴드, 이분산이면 우상향 또는 우하향 경향이 보인다.

### 4. 잔차 vs 레버리지 (영향력)

특정 관측치가 회귀 결과에 과도한 영향을 미치는지 확인한다. **Cook's distance**가 높은 점은 "이 점 하나를 빼면 회귀선이 크게 바뀐다"는 뜻이다. 실무에서 흔히 쓰는 임계값은 두 가지다: 보수적 기준은 Cook's D > 1, 데이터 적응적 기준은 Cook's D > $4/n$이다. 둘 중 상황에 맞는 것을 쓰되, 수치보다 해당 관측치가 물리적으로 타당한지를 먼저 확인하라.

```python
# statsmodels에서 4가지 진단 플롯 한 번에
fig = sm.graphics.plot_regress_exog(model, 'x1', fig=plt.figure(figsize=(12, 8)))
# 또는 개별 진단
sm.graphics.plot_leverage_resid2(model)
```

## 이분산성: 잔차의 분산이 일정하지 않다

### 왜 위험한가

4.1의 가우스-마르코프 가정 중 "등분산"이 깨진 상태다. OLS 추정량 자체는 여전히 불편이지만, **표준오차(SE) 추정이 틀린다.**

SE가 틀리면:
- 신뢰구간이 부정확하다
- t-검정의 p-value가 틀린다
- "유의미하다"와 "유의미하지 않다"의 판단이 뒤집힐 수 있다

즉, **계수의 값은 맞는데 그 계수를 얼마나 믿어야 하는지가 틀린다.** 이것은 "점추정은 맞지만 구간추정이 틀리는" 상황으로, 3.2에서 배운 불확실성 보고가 무의미해진다.

### 진단: Breusch-Pagan 검정

```python
from statsmodels.stats.diagnostic import het_breuschpagan

bp_stat, bp_pvalue, _, _ = het_breuschpagan(model.resid, model.model.exog)
print(f"Breusch-Pagan: stat={bp_stat:.3f}, p={bp_pvalue:.4f}")
print(f"→ {'이분산성 있음' if bp_pvalue < 0.05 else '등분산 가정 OK'}")
```

시각적 진단이 더 직관적인 경우가 많다. 잔차 vs 예측값 플롯에서 나팔 모양이 보이면 이분산성이다.

### 대응

**방법 1: 강건 표준오차 (Robust Standard Errors)**

이분산성이 있어도 올바른 SE를 추정하는 방법. 추정량 자체는 OLS 그대로 쓰고, SE만 보정한다.

```python
# HC3 강건 표준오차
model_robust = sm.OLS(y, sm.add_constant(X)).fit(cov_type='HC3')
print(model_robust.summary())
# → 계수는 같지만 SE, t, p가 다를 수 있다
```

> 💡 **실무 팁**: 이분산성 여부를 모르겠으면, 그냥 강건 표준오차를 쓰라. 등분산이더라도 큰 손해가 없고, 이분산이면 보호해 준다. 보험과 같다.

**방법 2: 가중최소제곱 (Weighted Least Squares, WLS)**

분산이 큰 관측치에 낮은 가중치를, 작은 관측치에 높은 가중치를 부여한다.

**방법 3: 타겟 변환**

1.1에서 배운 로그 변환. 타겟에 로그를 취하면 분산이 안정화되는 경우가 많다. 특히 "예측값이 커질수록 오차도 커지는" 상황에서 효과적이다.

## 다중공선성: 피처끼리 너무 닮았다

### 문제의 정체

두 피처 $X_1$과 $X_2$가 거의 완벽한 선형 관계에 있다고 하자 ($X_2 \approx 2X_1$). 

$$y = \beta_1 X_1 + \beta_2 X_2 + \epsilon \approx \beta_1 X_1 + \beta_2 (2X_1) + \epsilon = (\beta_1 + 2\beta_2) X_1 + \epsilon$$

$\beta_1 + 2\beta_2$의 합만 결정되고, 개별 $\beta_1$, $\beta_2$는 결정되지 않는다. $\beta_1 = 10, \beta_2 = -3$이든 $\beta_1 = 0, \beta_2 = 2$이든 예측값은 거의 같다.

결과:
- 개별 계수의 **분산이 폭발한다** (SE가 매우 커짐)
- 계수의 **부호가 직관과 반대**가 될 수 있다
- **p-value가 커져서** 실제로 중요한 피처도 유의미하지 않게 나온다
- 하지만 **전체 모델의 R²는 여전히 높다** — 개별 계수가 불안정할 뿐 예측 자체는 괜찮다

이것이 혼란스러운 부분이다. "예측은 잘 되는데 해석이 안 된다." 예측만 목적이면 문제가 덜하지만, "이 피처가 중요한가?"를 알고 싶으면 다중공선성은 치명적이다.

### 진단: VIF (Variance Inflation Factor)

$$\text{VIF}_j = \frac{1}{1 - R^2_j}$$

$R^2_j$는 피처 $X_j$를 나머지 피처들로 회귀했을 때의 R²다. "이 피처가 다른 피처들로 얼마나 잘 설명되는가?"

| VIF | 해석 |
|-----|------|
| 1 | 다중공선성 없음 |
| 1~5 | 약한 공선성. 보통 무시 가능 |
| 5~10 | 주의 필요 |
| > 10 | 심각. 대응 필요 |

```python
from statsmodels.stats.outliers_influence import variance_inflation_factor

X_const = sm.add_constant(X)
for i in range(X_const.shape[1]):
    vif = variance_inflation_factor(X_const, i)
    name = 'const' if i == 0 else f'X{i}'
    print(f"  {name}: VIF = {vif:.2f}")
```

### 대응

**방법 1: 피처 제거.** VIF가 높은 피처 쌍 중 하나를 제거한다. 도메인 지식으로 판단.

**방법 2: PCA.** 상관된 피처들을 주성분으로 압축한다. 공선성이 사라지지만 해석성도 사라진다.

**방법 3: 정규화 (Ridge, Lasso).** 4.4에서 자세히 다루지만, Ridge 회귀(L2)는 다중공선성에 의한 계수 폭발을 직접적으로 억제한다. $(X^TX + \lambda I)^{-1}$에서 $\lambda I$가 $X^TX$의 역행렬을 안정화시킨다.

<details>
<summary>🔬 Deep Dive — 다중공선성이 계수 분산을 폭발시키는 수학적 이유</summary>

4.1에서 OLS 계수의 분산이 다음과 같다고 했다:

$$\text{Var}(\hat{\beta}) = \sigma^2 (X^TX)^{-1}$$

$X^TX$의 역행렬이 핵심이다. 두 피처가 강하게 상관되면 $X^TX$의 행렬식(determinant)이 0에 가까워진다. 행렬식이 작을수록 역행렬의 원소가 커지고, 따라서 $\text{Var}(\hat{\beta})$가 폭발한다.

VIF와의 관계: $(X^TX)^{-1}$의 대각 원소가 $\text{VIF}_j / (\text{피처 분산})$에 비례한다. VIF가 크다 = $(X^TX)^{-1}$의 대각 원소가 크다 = 그 계수의 분산이 크다.

Ridge 회귀는 $X^TX$에 $\lambda I$를 더해서:

$$(X^TX + \lambda I)^{-1}$$

$\lambda > 0$이면 행렬식이 커지므로 역행렬의 원소가 작아진다. 계수 분산이 줄어들지만, 대가로 약간의 편향이 생긴다. 이것이 편향-분산 트레이드오프(4.5)다.

</details>

## 진단 워크플로우

회귀 모델을 피팅한 후의 체크리스트:

```python
import matplotlib.pyplot as plt
import statsmodels.api as sm
from statsmodels.stats.diagnostic import het_breuschpagan
from statsmodels.stats.outliers_influence import variance_inflation_factor
from scipy import stats

model = sm.OLS(y, sm.add_constant(X)).fit()

# 1. 잔차 vs 예측값 (비선형성, 이분산성)
plt.scatter(model.fittedvalues, model.resid, alpha=0.3)
plt.axhline(0, color='red', linestyle='--')
plt.title('잔차 vs 예측값')

# 2. QQ플롯 (정규성)
stats.probplot(model.resid, dist="norm", plot=plt)

# 3. Breusch-Pagan (이분산성)
bp_stat, bp_p, _, _ = het_breuschpagan(model.resid, model.model.exog)
print(f"이분산성: p = {bp_p:.4f}")

# 4. VIF (다중공선성)
X_const = sm.add_constant(X)
for i in range(1, X_const.shape[1]):
    vif = variance_inflation_factor(X_const, i)
    print(f"  X{i}: VIF = {vif:.2f}")

# 5. Durbin-Watson (잔차 자기상관 → 독립성)
from statsmodels.stats.stattools import durbin_watson
dw = durbin_watson(model.resid)
print(f"Durbin-Watson: {dw:.3f} (2에 가까우면 OK)")
```

| 진단 | 확인하는 가정 | 도구 | 기준 |
|------|-------------|------|------|
| 잔차 vs 예측값 플롯 | 선형성, 등분산성 | 시각적 | 패턴 없어야 |
| QQ플롯 | 정규성 | 시각적 | 대각선 따라야 |
| Breusch-Pagan | 등분산성 | 검정 | p > 0.05 |
| VIF | 다중공선성 없음 | 수치 | VIF < 5~10 |
| Durbin-Watson | 독립성 | 수치 | ≈ 2 |

## Python으로 확인하기

```python
import numpy as np
import statsmodels.api as sm
from statsmodels.stats.outliers_influence import variance_inflation_factor

np.random.seed(42)

# 1. 이분산성 시뮬레이션
n = 200
X = np.random.uniform(1, 10, n)
# 이분산: X가 클수록 노이즈도 큼
y_hetero = 2 * X + np.random.normal(0, X * 0.5, n)  # σ ∝ X

model_hetero = sm.OLS(y_hetero, sm.add_constant(X)).fit()
model_robust = sm.OLS(y_hetero, sm.add_constant(X)).fit(cov_type='HC3')

print("=== 이분산성: 일반 vs 강건 SE ===")
print(f"X의 계수: {model_hetero.params[1]:.3f}")
print(f"일반 SE:  {model_hetero.bse[1]:.3f}, p = {model_hetero.pvalues[1]:.4f}")
print(f"강건 SE:  {model_robust.bse[1]:.3f}, p = {model_robust.pvalues[1]:.4f}")

# 2. 다중공선성 시뮬레이션
print(f"\n=== 다중공선성: 계수 폭발 ===")
X1 = np.random.normal(0, 1, 200)
X2 = X1 + np.random.normal(0, 0.01, 200)  # X2 ≈ X1 (거의 같음)
X3 = np.random.normal(0, 1, 200)            # 독립
y_mc = 3*X1 + 2*X3 + np.random.normal(0, 1, 200)

X_mc = np.column_stack([X1, X2, X3])
X_mc_const = sm.add_constant(X_mc)

model_mc = sm.OLS(y_mc, X_mc_const).fit()
print(f"진짜 계수: β1=3, β2=0 (X2는 X1의 복사본), β3=2")
print(f"추정된 계수: β1={model_mc.params[1]:.1f}, β2={model_mc.params[2]:.1f}, "
      f"β3={model_mc.params[3]:.3f}")
print(f"SE:         β1={model_mc.bse[1]:.1f}, β2={model_mc.bse[2]:.1f}, "
      f"β3={model_mc.bse[3]:.3f}")

# VIF 확인
for i in range(1, X_mc_const.shape[1]):
    vif = variance_inflation_factor(X_mc_const, i)
    print(f"  X{i}: VIF = {vif:.0f}")

print(f"\nR² = {model_mc.rsquared:.4f} (여전히 높다!)")
print(f"→ 예측은 되지만, 개별 계수는 의미 없다")
```

## 핵심 정리

- **R²보다 잔차를 봐라.** R²는 "얼마나 설명했는가", 잔차는 "무엇을 놓쳤는가". 잔차에 패턴이 있으면 모델이 부족하다.
- **이분산성은 계수를 바꾸지 않지만 SE를 틀리게 만든다.** 신뢰구간과 p-value가 무의미해진다. 강건 표준오차(`cov_type='HC3'`)로 보험을 들어라.
- **다중공선성은 계수를 폭발시킨다.** VIF > 10이면 위험. 예측은 되지만 해석이 안 된다. Ridge(4.4)나 피처 제거로 대응.
- **진단 워크플로우**: 잔차 플롯 → QQ플롯 → Breusch-Pagan → VIF → Durbin-Watson. 모델 피팅 후 반드시 실행하라.
- **가정이 깨졌다고 모델을 버리지 마라.** 어떤 가정이 깨졌는지 진단하고, 그 가정에 맞는 대응을 하라.
