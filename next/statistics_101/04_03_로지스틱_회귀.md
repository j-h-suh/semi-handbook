# 4.3 로지스틱 회귀 — 분류기 이전에 통계 모델이다

## 이 챕터에서 배우는 것

- 왜 분류에 선형회귀를 쓰면 안 되는지
- 로지스틱 함수가 확률을 만드는 원리
- 로그 오즈(log-odds)와 계수 해석 — "이 피처가 1 증가하면 오즈가 몇 배?"
- 로지스틱 회귀가 OLS가 아니라 MLE인 이유

---

## 선형회귀로 분류를 하면 생기는 일

이진 분류 문제가 있다. 타겟 $y \in \{0, 1\}$. 선형회귀로 피팅하면:

$$\hat{y} = w^T x + b$$

문제가 두 가지다:

**1. 출력이 0~1 범위를 벗어난다.** $w^T x + b$는 $-\infty$에서 $+\infty$까지 어떤 값이든 나올 수 있다. 확률은 0~1이어야 하는데, -0.3이나 1.5 같은 값이 나온다.

**2. 오차 가정이 맞지 않는다.** $y$가 0 아니면 1이므로, 잔차 $y - \hat{y}$가 정규분포를 따를 리 없다. OLS의 이론적 기반이 무너진다.

이 두 문제를 해결하는 것이 로지스틱 회귀다.

---

## 로지스틱 함수: 실수를 확률로 변환

**시그모이드(sigmoid) 함수**, 또는 **로지스틱 함수**:

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

이 함수의 성질:
- 입력: $z \in (-\infty, +\infty)$
- 출력: $\sigma(z) \in (0, 1)$
- $z = 0$이면 $\sigma(0) = 0.5$
- $z \to +\infty$이면 $\sigma \to 1$
- $z \to -\infty$이면 $\sigma \to 0$

<!-- [GRAPH: 시그모이드 곡선. x축: z (-6 ~ 6), y축: σ(z) (0 ~ 1). z=0에서 0.5를 지나는 S자 곡선. 0.5 수평선, z=0 수직선 표시.] -->

로지스틱 회귀는 선형 결합 $z = w^T x + b$를 시그모이드에 통과시킨다:

$$P(Y=1 \mid X=x) = \sigma(w^T x + b) = \frac{1}{1 + e^{-(w^Tx + b)}}$$

이러면 출력이 항상 (0, 1) 범위에 있으므로 확률로 해석할 수 있다. 2.1에서 배운 조건부 확률 $P(Y=1 \mid X)$의 추정값이다.

---

## 로그 오즈: 계수를 해석하는 열쇠

시그모이드가 "선형 → 확률" 변환이라면, 그 역변환이 **로짓(logit) 함수**다:

$$\text{logit}(p) = \log\frac{p}{1-p} = w^T x + b$$

$p/(1-p)$를 **오즈(odds)**라 한다. "성공 확률 / 실패 확률." 확률이 0.8이면 오즈는 0.8/0.2 = 4. "실패 1번에 성공 4번" 비율이다.

로지스틱 회귀가 실제로 모델링하는 것은 **로그 오즈가 피처의 선형 함수**라는 것이다:

$$\log\frac{P(Y=1)}{P(Y=0)} = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots$$

이것이 계수를 해석하는 열쇠다.

### 계수의 해석

$\beta_j$의 의미: **$x_j$가 1 단위 증가하면 로그 오즈가 $\beta_j$만큼 변한다.**

로그 오즈보다 직관적인 것은 **오즈비(Odds Ratio)**다:

$$\text{OR}_j = e^{\beta_j}$$

"$x_j$가 1 단위 증가하면 오즈가 $e^{\beta_j}$배가 된다."

예를 들어 $\beta_1 = 0.7$이면:
- 오즈비 = $e^{0.7} = 2.01$
- "$x_1$이 1 증가하면 양성일 오즈가 약 2배"

| $\beta_j$ | $e^{\beta_j}$ (오즈비) | 해석 |
|-----------|---------------------|------|
| 0 | 1.0 | 영향 없음 |
| 0.7 | 2.0 | 오즈 2배 증가 |
| -0.7 | 0.5 | 오즈 절반 감소 |
| 1.1 | 3.0 | 오즈 3배 증가 |

```python
import numpy as np
from sklearn.linear_model import LogisticRegression

model = LogisticRegression().fit(X_train, y_train)

print("=== 계수와 오즈비 ===")
for name, coef in zip(feature_names, model.coef_[0]):
    odds_ratio = np.exp(coef)
    print(f"  {name}: β={coef:.3f}, OR={odds_ratio:.2f}")
```

> 💡 **주의: 오즈비 ≠ 확률의 배수.** 오즈가 2배라는 것은 확률이 2배라는 뜻이 아니다. 확률이 0.1→0.18 정도가 되는 것이지 0.1→0.2가 아니다. 기저 확률에 따라 달라진다. 이것을 혼동하면 효과를 과대평가하게 된다.

## 왜 OLS가 아니라 MLE인가

선형회귀는 잔차 제곱합을 최소화(= OLS)했다. 로지스틱 회귀는 그렇게 할 수 없다.

타겟이 0 또는 1이고, 모델 출력이 확률 $p$이므로, 자연스러운 접근은 2.3에서 봤던 **베르누이 분포의 우도를 최대화**하는 것이다:

$$\ell(\beta) = \sum_{i=1}^n \left[ y_i \log p_i + (1-y_i) \log(1-p_i) \right]$$

이것의 부호를 뒤집으면 **Binary Cross-Entropy**다. 2.3에서 이미 유도했다.

$$\text{BCE} = -\frac{1}{n}\sum_{i=1}^n \left[ y_i \log p_i + (1-y_i) \log(1-p_i) \right]$$

로지스틱 회귀를 학습한다 = BCE를 최소화한다 = 베르누이 우도를 최대화한다 = MLE를 수행한다. 전부 같은 말이다.

닫힌 형태의 해가 없으므로, 경사하강법이나 뉴턴 방법 같은 반복적 최적화가 필요하다. `sklearn`의 `LogisticRegression`은 내부적으로 L-BFGS나 liblinear 같은 최적화 알고리즘을 쓴다.

<details>
<summary>🔬 Deep Dive — BCE의 기울기가 MSE와 같은 형태인 이유</summary>

BCE를 $w$에 대해 미분하면:

$$\frac{\partial \text{BCE}}{\partial w} = -\frac{1}{n}\sum_{i=1}^n (y_i - p_i) x_i$$

선형회귀에서 MSE를 $w$에 대해 미분하면:

$$\frac{\partial \text{MSE}}{\partial w} = -\frac{2}{n}\sum_{i=1}^n (y_i - \hat{y}_i) x_i$$

구조가 같다! 둘 다 "(타겟 - 예측) × 피처"의 합이다. 차이는 $\hat{y}_i$가 선형 예측인지($w^Tx$), 시그모이드를 거친 확률인지($\sigma(w^Tx)$)뿐이다.

이것이 의미하는 바: 경사하강법의 업데이트 규칙이 선형회귀와 로지스틱 회귀에서 거의 같은 형태다. "예측을 틀린 방향으로 계수를 보정한다"는 직관이 동일하다.

</details>

## 로지스틱 회귀의 통계적 추론

4.1에서 선형회귀의 계수에 t-검정을 했던 것처럼, 로지스틱 회귀에서도 계수의 유의성을 검정할 수 있다.

MLE 추정량의 점근적 성질에 의해, 충분히 큰 n에서:

$$\hat{\beta}_j \approx N\left(\beta_j, \, [\mathcal{I}(\beta)^{-1}]_{jj}\right)$$

$\mathcal{I}(\beta)$는 **피셔 정보 행렬(Fisher Information Matrix)**이다. 이로부터 SE를 구하고, z-검정(= Wald 검정)을 할 수 있다.

```python
import statsmodels.api as sm

logit_model = sm.Logit(y, sm.add_constant(X)).fit()
print(logit_model.summary())
```

`summary()`에서 각 계수의 `z`, `P>|z|`, 신뢰구간을 확인할 수 있다. 다시 한 번: sklearn은 이 정보를 주지 않는다.

---

## 다중 클래스 확장: 소프트맥스

이진 분류의 시그모이드를 $K$개 클래스로 확장한 것이 **소프트맥스(Softmax)**다:

$$P(Y=k \mid X) = \frac{e^{z_k}}{\sum_{j=1}^K e^{z_j}}, \quad z_k = w_k^T x + b_k$$

모든 클래스의 확률이 0~1이고 합이 1이 되도록 정규화한다.

대응하는 손실함수는 **Categorical Cross-Entropy**:

$$\text{CCE} = -\sum_{i=1}^n \sum_{k=1}^K y_{ik} \log \hat{p}_{ik}$$

이것은 **카테고리 분포(Categorical Distribution)**의 NLL이다. 패턴이 반복된다:

| 타겟 | 분포 가정 | 링크 함수 | NLL 손실 |
|------|----------|----------|---------|
| 이진 (0/1) | 베르누이 | 시그모이드 | BCE |
| 다중 클래스 | 카테고리 | 소프트맥스 | CCE |
| 연속 | 정규 | 항등(identity) | MSE |
| 카운트 | 포아송 | 로그 | Poisson Loss |

이 표가 이 핸드북 Part 2~4를 관통하는 핵심 구조다. **모든 손실함수는 분포 가정에서 나온다.**

---

## 로지스틱 회귀의 결정 경계

시그모이드 출력에서 $P(Y=1) = 0.5$인 지점, 즉 $w^Tx + b = 0$인 지점이 **결정 경계(decision boundary)**다. 이것은 피처 공간의 **초평면(hyperplane)**이다.

로지스틱 회귀가 "선형 분류기"라 불리는 이유는 결정 경계가 선형(직선, 평면, 초평면)이기 때문이다. 데이터가 선형으로 분리 가능하지 않으면 성능이 떨어진다.

하지만 피처를 비선형으로 변환하면(다항 피처, 상호작용 항 등) 원래 공간에서 비선형 결정 경계를 만들 수 있다. SVM의 커널 트릭도 같은 아이디어다.

---

## 분류기가 아니라 확률 모델이다

이 챕터의 제목을 다시 보자: "분류기 이전에 통계 모델이다."

많은 ML 엔지니어가 로지스틱 회귀를 `model.predict()`로만 쓴다. 0 또는 1을 출력하는 분류기로만 보는 것이다.

하지만 로지스틱 회귀의 진짜 출력은 `model.predict_proba()`다. **확률을 추정하는 통계 모델**이다.

이 관점의 차이가 중요한 상황:

- **임계값 조정**: predict()는 기본 임계값 0.5를 쓰지만, 비용이 비대칭이면 임계값을 바꿔야 한다. 확률 출력이 있어야 가능하다.
- **보정(Calibration)**: 모델이 출력한 "확률"이 진짜 확률에 가까운가? 로지스틱 회귀는 잘 보정된 편이지만, Random Forest나 SVM은 아닐 수 있다.
- **의사결정**: "이 환자가 양성일 확률이 0.7이다"와 "이 환자는 양성이다"는 다른 수준의 정보를 제공한다. 확률은 불확실성을 전달한다.

## Python으로 확인하기

```python
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.datasets import make_classification
import statsmodels.api as sm

# 데이터 생성
X, y = make_classification(n_samples=500, n_features=3, n_informative=2,
                            n_redundant=0, random_state=42)

# 1. sklearn: 예측 중심
sk_model = LogisticRegression().fit(X, y)
print("=== sklearn ===")
print(f"계수: {sk_model.coef_[0].round(3)}")
print(f"오즈비: {np.exp(sk_model.coef_[0]).round(3)}")

# 2. statsmodels: 추론 중심
sm_model = sm.Logit(y, sm.add_constant(X)).fit(disp=0)
print(f"\n=== statsmodels ===")
print(sm_model.summary().tables[1])

# 3. 확률 출력 vs 이진 출력
sample = X[:5]
probs = sk_model.predict_proba(sample)[:, 1]
preds = sk_model.predict(sample)

print(f"\n=== 확률 vs 이진 ===")
for i in range(5):
    print(f"  샘플 {i}: P(Y=1)={probs[i]:.3f} → 예측={preds[i]} "
          f"(실제={y[i]})")

# 4. BCE = 베르누이 NLL 재확인
from sklearn.metrics import log_loss
bce = log_loss(y, sk_model.predict_proba(X))
print(f"\n학습 데이터 BCE: {bce:.4f}")

# 수동 계산
p = sk_model.predict_proba(X)[:, 1]
bce_manual = -np.mean(y * np.log(p + 1e-10) + (1-y) * np.log(1-p + 1e-10))
print(f"수동 계산 BCE:  {bce_manual:.4f}")
print(f"같은가? {np.isclose(bce, bce_manual, atol=1e-4)}")
```

## 핵심 정리

- **로지스틱 회귀는 분류기가 아니라 확률 모델이다.** 진짜 출력은 `predict_proba()`. 확률을 추정하는 것이 본질이다.
- **시그모이드는 선형 결합을 확률로 변환한다.** 로그 오즈가 피처의 선형 함수라는 것이 모델의 가정.
- **계수의 해석: 오즈비 $e^{\beta_j}$.** "$x_j$가 1 증가하면 오즈가 $e^{\beta_j}$배." 확률의 배수가 아님에 주의.
- **학습 = BCE 최소화 = 베르누이 MLE.** 2.3에서 심은 복선의 완성.
- **모든 손실함수는 분포 가정에서 나온다.** BCE↔베르누이, CCE↔카테고리, MSE↔정규, Poisson↔포아송. 이것이 Part 2~4를 관통하는 핵심 구조.
