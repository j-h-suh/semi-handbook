# 3.2 점추정과 구간추정 — 신뢰구간 95%의 진짜 의미

## 이 챕터에서 배우는 것

- 점추정의 한계 — 하나의 숫자만으로는 불확실성을 표현할 수 없다
- 신뢰구간의 정확한 의미 — "95% 확률로 여기에 있다"가 아닌 이유
- 신뢰구간의 구성: 점추정 ± 오차 한계
- ML에서 신뢰구간이 필요한 순간들

---

## 점추정의 한계

3.1에서 표본 평균 $\bar{x}$로 모평균 $\mu$를 추정한다고 했다. 예를 들어 교차검증 결과의 평균 정확도가 0.85라고 하자.

"정확도는 0.85입니다."

이 한 줄에는 결정적인 정보가 빠져 있다. **이 숫자를 얼마나 믿어도 되는가?**

다음 두 상황을 비교해 보자:

- **상황 A**: 테스트셋 10,000개에서 정확도 0.85
- **상황 B**: 테스트셋 50개에서 정확도 0.85

둘 다 점추정값은 0.85로 같다. 하지만 상황 A의 0.85는 상당히 믿을 만하고, 상황 B의 0.85는 다음에 측정하면 0.70이 나올 수도 0.95가 나올 수도 있다. 점추정만으로는 이 차이를 표현할 수 없다.

**구간추정(Interval Estimation)**은 이 문제를 해결한다. "진짜 값은 이 범위 안에 있을 것이다"라고 **신뢰구간(Confidence Interval)**을 제시하여 불확실성을 함께 보고하는 것이다.

---

## 신뢰구간의 구성

### 공식

모평균 $\mu$에 대한 95% 신뢰구간:

$$\bar{x} \pm z_{0.025} \cdot \frac{s}{\sqrt{n}}$$

$$= \bar{x} \pm 1.96 \cdot \text{SE}$$

구성 요소를 하나씩 보자:

- **$\bar{x}$**: 점추정값. 구간의 중심.
- **$z_{0.025} = 1.96$**: 신뢰수준에 대응하는 임계값. 95%이면 1.96, 99%이면 2.576.
- **$\text{SE} = s/\sqrt{n}$**: 표준오차. 2.5에서 배운 것.
- **$z \cdot \text{SE}$**: 오차 한계(margin of error). 구간의 반폭.

이 공식은 CLT에서 직접 나온다. CLT가 "표본 평균은 $N(\mu, \sigma^2/n)$을 따른다"고 말해줬으니:

$$P\left(\bar{X} - 1.96 \cdot \frac{\sigma}{\sqrt{n}} \leq \mu \leq \bar{X} + 1.96 \cdot \frac{\sigma}{\sqrt{n}}\right) = 0.95$$

표준 정규분포에서 ±1.96 안에 95%의 확률이 있으므로, 이 구간이 $\mu$를 포함할 확률이 95%다.

<details>
<summary>🔬 Deep Dive — z 대신 t를 쓰는 경우</summary>

위 공식에서 $\sigma$를 안다고 가정했지만, 현실에서 모표준편차 $\sigma$를 아는 경우는 거의 없다. 표본표준편차 $s$로 대체한다.

문제는, $\sigma$ 대신 $s$를 쓰면 불확실성이 하나 더 추가된다는 것이다 — $s$ 자체가 추정값이니까. 이 추가 불확실성을 반영한 분포가 **t-분포(Student's t-distribution)**다.

$$\frac{\bar{X} - \mu}{s/\sqrt{n}} \sim t(n-1)$$

t-분포는 정규분포보다 꼬리가 두껍다. 특히 $n$이 작을 때 차이가 크다. $n$이 커지면 ($n > 30$ 정도) t-분포는 정규분포에 수렴한다.

실무 규칙:
- $n \geq 30$이고 $\sigma$를 알면 → $z$ 사용
- $n < 30$이거나 $\sigma$를 모르면 → $t$ 사용
- 사실상 대부분의 실무 상황에서는 $t$를 쓰는 것이 안전하다

```python
from scipy.stats import t

# t 임계값 (95% 신뢰구간, n=10)
t_critical = t.ppf(0.975, df=9)  # 2.262 (z=1.96보다 큼)
```

3.4에서 t-검정을 다룰 때 더 자세히 본다.

## "95%"의 진짜 의미

이것이 이 챕터에서 가장 중요한 부분이다.

> "95% 신뢰구간이 (0.82, 0.88)이다."

이것을 **잘못** 해석하는 법:

❌ "진짜 정확도가 0.82~0.88 사이에 있을 확률이 95%다."

이것을 **올바르게** 해석하는 법:

✅ "이 방법으로 100번 구간을 만들면, 그 중 약 95개의 구간이 진짜 값을 포함한다."

차이가 미묘해 보이지만 근본적으로 다르다.

**빈도주의 관점에서 모수 $\mu$는 상수다.** 3.1에서 배웠다. 상수는 "확률적으로 어디에 있다"고 말할 수 없다. $\mu$는 특정 값으로 고정되어 있고, 움직이는 것은 **구간** 쪽이다. 표본을 다시 뽑으면 구간이 달라진다. 100번 뽑아서 100개의 구간을 만들면, 그 중 약 95개가 고정된 $\mu$를 포함한다.

비유하자면 이렇다. 과녁의 정중앙(불스아이)이 $\mu$다. 매번 화살을 쏠 때마다 화살이 꽂힌 위치를 중심으로 일정한 반경의 원을 그린다. 이 원이 신뢰구간이다. 100발을 쏘면 약 95개의 원이 불스아이를 포함한다. 하지만 이미 쏜 특정 한 발의 원이 불스아이를 포함하는지는 — 포함하거나 포함하지 않거나 — 이미 결정된 사실이지, "95% 확률"이 아니다.

![신뢰구간 시뮬레이션](/content/images/stats/03_02/confidence_interval_sim.svg)

```python
# 95% 신뢰구간 시뮬레이션
import numpy as np
from scipy import stats

np.random.seed(42)
true_mu = 100
true_sigma = 15
n = 25
n_experiments = 1000

contains_mu = 0
for _ in range(n_experiments):
    sample = np.random.normal(true_mu, true_sigma, n)
    se = sample.std(ddof=1) / np.sqrt(n)
    # 주의: n=25이면 t-분포를 써야 더 정확하다 (t(24)의 임계값 ≈ 2.064).
    # 여기서는 시뮬레이션 목적으로 z=1.96을 사용했지만, 실무에서는 t를 쓸 것.
    ci_low = sample.mean() - 1.96 * se
    ci_high = sample.mean() + 1.96 * se
    if ci_low <= true_mu <= ci_high:
        contains_mu += 1

print(f"1000개 구간 중 μ를 포함한 구간: {contains_mu}/1000 = {contains_mu/10:.1f}%")
```

### 왜 이 구분이 중요한가

실무에서 "95% 확률로 여기에 있다"와 "이 방법의 적중률이 95%다"의 차이가 문제가 되는 순간이 있다.

**A/B 테스트에서**: "전환율 차이의 95% CI가 (0.01, 0.05)다"는 것은 "진짜 효과가 이 범위에 있을 확률이 95%"가 **아니다**. 이 구간을 만드는 절차가 장기적으로 95%의 적중률을 갖는다는 뜻이다. 한 번의 실험에서 이 특정 구간이 진짜 효과를 포함하는지는 알 수 없다 — 포함하거나 포함하지 않거나 둘 중 하나다.

> 💡 **베이지안 관점에서는 다르다.** 베이즈 통계에서는 모수 자체에 확률분포를 부여하므로, "사후확률 95%로 $\mu$가 이 범위에 있다"고 직접 말할 수 있다. 이것이 **신용구간(credible interval)**이며, 직관적으로 더 자연스러운 해석이다. Part 5에서 다룬다.

## 신뢰구간의 폭을 결정하는 것들

$$\text{구간 폭} = 2 \times z \times \frac{s}{\sqrt{n}}$$

세 가지가 폭에 영향을 준다:

### 1. 신뢰수준 (z 값)

| 신뢰수준 | z | 폭 |
|---------|---|-----|
| 90% | 1.645 | 좁음 |
| 95% | 1.960 | 중간 |
| 99% | 2.576 | 넓음 |

신뢰수준을 높이면 구간이 넓어진다. "더 확신하고 싶으면 더 넓게 잡아야 한다." 100% 신뢰구간은 $(-\infty, +\infty)$다 — 맞지만 쓸모없다.

### 2. 표본 크기 (n)

$\sqrt{n}$에 반비례. 2.5에서 배운 $\sqrt{n}$ 법칙. 구간을 절반으로 좁히려면 데이터가 4배 필요하다.

### 3. 데이터의 변동성 (s)

데이터가 많이 흩어져 있으면 구간이 넓어진다. 이건 바꿀 수 없다 — 데이터의 본질적 성질이니까.

## ML에서 신뢰구간이 필요한 순간들

### 1. 모델 성능 보고

"정확도 85%"가 아니라 "정확도 85% ± 2% (95% CI)"로 보고해야 한다.

```python
from scipy import stats

# 교차검증 결과
cv_scores = np.array([0.83, 0.86, 0.84, 0.87, 0.85])
n = len(cv_scores)
mean = cv_scores.mean()
se = cv_scores.std(ddof=1) / np.sqrt(n)

# t-분포 기반 95% CI (n이 작으므로 t 사용)
t_crit = stats.t.ppf(0.975, df=n-1)
ci = (mean - t_crit * se, mean + t_crit * se)
print(f"정확도: {mean:.3f} ({ci[0]:.3f}, {ci[1]:.3f})")
```

이 코드를 리포트에 포함시키는 습관을 들이면, "이 모델과 저 모델 중 뭐가 나은가?"에 대한 답을 신뢰구간의 겹침으로 시각적으로 판단할 수 있다.

### 2. 이항 비율의 신뢰구간

분류 정확도는 본질적으로 이항 비율이다 (2.3). 테스트셋 $n$개 중 $k$개를 맞췄으면:

$$\hat{p} = k/n, \quad \text{SE} = \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$$

$$\text{95% CI} = \hat{p} \pm 1.96 \cdot \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$$

| 테스트셋 크기 | 정확도 | 95% CI | 해석 |
|-------------|--------|--------|------|
| 50 | 0.85 | (0.75, 0.95) | 매우 넓음. 75%일 수도 |
| 500 | 0.85 | (0.82, 0.88) | 합리적 |
| 5000 | 0.85 | (0.84, 0.86) | 매우 좁음 |

테스트셋 50개로 "정확도 85%"라고 보고하면, 진짜 성능은 75%에서 95%까지 어디든 있을 수 있다. 이 CI를 함께 보고하지 않으면 의사결정을 오도한다.

### 3. 두 모델 비교

모델 A: 0.85 (CI: 0.82~0.88)
모델 B: 0.87 (CI: 0.84~0.90)

두 CI가 겹친다. 이 경우 "B가 A보다 낫다"고 확신할 수 없다. 차이가 우연에 의한 것일 수 있다. 이 판단을 엄밀하게 하는 것이 3.3~3.4에서 배울 **가설검정**이다.

### 4. 피처 중요도의 불확실성

Random Forest의 `feature_importances_`는 점추정이다. 한 번의 학습 결과다. 부트스트랩으로 여러 번 학습하면 각 피처 중요도의 분포를 얻을 수 있고, 그 CI가 0을 포함하는 피처는 "진짜 중요한 건지 확신할 수 없다."

```python
# 부트스트랩 피처 중요도 CI
from sklearn.ensemble import RandomForestClassifier

n_bootstrap = 100
importances = []
for _ in range(n_bootstrap):
    idx = np.random.choice(len(X_train), size=len(X_train), replace=True)
    model = RandomForestClassifier(n_estimators=50).fit(X_train[idx], y_train[idx])
    importances.append(model.feature_importances_)

importances = np.array(importances)
for j in range(X_train.shape[1]):
    ci = np.percentile(importances[:, j], [2.5, 97.5])
    contains_zero = ci[0] <= 0
    print(f"Feature {j}: {importances[:, j].mean():.4f} "
          f"CI: ({ci[0]:.4f}, {ci[1]:.4f})"
          f"{'  ⚠️ 0 포함' if contains_zero else ''}")
```

## 신뢰구간 vs 예측구간

흔한 혼동 하나를 짚고 넘어간다.

**신뢰구간(Confidence Interval)**: **모수**의 불확실성. "진짜 평균이 이 범위 안에 있다."

**예측구간(Prediction Interval)**: **새로운 관측값**의 불확실성. "다음에 관측될 값이 이 범위 안에 있다."

예측구간은 항상 신뢰구간보다 넓다. 신뢰구간은 "평균이 어디인지"만 추정하면 되지만, 예측구간은 평균의 불확실성에 **개별 관측값의 변동성**까지 더해야 하기 때문이다.

$$\text{예측구간} = \bar{x} \pm t \cdot s\sqrt{1 + \frac{1}{n}}$$

$n$이 아무리 커져도 $s$ 항이 남아 있으므로, 예측구간은 일정 폭 이하로 줄어들지 않는다. 이것은 **데이터 자체의 노이즈** 때문이며, 알 수 없는 불확실성(irreducible error)에 해당한다.

ML에서 `model.predict(X)`는 점예측이고, 예측구간을 함께 제공하면 "이 예측이 얼마나 불확실한지"를 전달할 수 있다. 수율 예측에서 "수율 92% ± 3% (예측구간)"은 의사결정에 훨씬 유용하다.

## Python으로 확인하기

```python
import numpy as np
from scipy import stats

# 1. 신뢰구간 시뮬레이션: 95%가 진짜 95%인지
np.random.seed(42)
true_mu = 50
true_sigma = 10
n = 30
n_experiments = 10000
confidence_level = 0.95

hit_count = 0
for _ in range(n_experiments):
    sample = np.random.normal(true_mu, true_sigma, n)
    mean, se = sample.mean(), sample.std(ddof=1) / np.sqrt(n)
    t_crit = stats.t.ppf((1 + confidence_level) / 2, df=n-1)
    ci_low, ci_high = mean - t_crit * se, mean + t_crit * se
    if ci_low <= true_mu <= ci_high:
        hit_count += 1

print(f"=== 신뢰구간 적중률 ===")
print(f"{n_experiments}개 구간 중 μ 포함: {hit_count} ({hit_count/n_experiments:.1%})")

# 2. 테스트셋 크기별 CI 폭
print(f"\n=== 이항 비율 CI (정확도 0.85) ===")
p_hat = 0.85
for n_test in [50, 200, 500, 1000, 5000]:
    se = np.sqrt(p_hat * (1-p_hat) / n_test)
    ci = (p_hat - 1.96*se, p_hat + 1.96*se)
    width = ci[1] - ci[0]
    print(f"  n={n_test:>5}: CI = ({ci[0]:.3f}, {ci[1]:.3f}), 폭 = {width:.3f}")

# 3. 신뢰구간 vs 예측구간
print(f"\n=== 신뢰구간 vs 예측구간 ===")
sample = np.random.normal(true_mu, true_sigma, 100)
mean, s = sample.mean(), sample.std(ddof=1)
n = len(sample)
t_crit = stats.t.ppf(0.975, df=n-1)

ci_half = t_crit * s / np.sqrt(n)
pi_half = t_crit * s * np.sqrt(1 + 1/n)

print(f"점추정: {mean:.2f}")
print(f"신뢰구간: ({mean-ci_half:.2f}, {mean+ci_half:.2f}), 폭 = {2*ci_half:.2f}")
print(f"예측구간: ({mean-pi_half:.2f}, {mean+pi_half:.2f}), 폭 = {2*pi_half:.2f}")
print(f"→ 예측구간이 {2*pi_half/(2*ci_half):.1f}배 넓다")
```

## 핵심 정리

- **점추정만으로는 불확실성을 표현할 수 없다.** "정확도 85%"가 아니라 "정확도 85% ± 2%"로 보고하라.
- **95% 신뢰구간의 진짜 의미**: "이 방법으로 100번 구간을 만들면 약 95번 적중한다." 특정 구간이 모수를 포함할 "확률"이 95%라는 뜻이 아니다.
- **구간 폭 = 2 × z × SE.** 신뢰수준↑ → 넓어짐. n↑ → 좁아짐 ($\sqrt{n}$ 법칙). 변동성↑ → 넓어짐.
- **신뢰구간 ≠ 예측구간.** 신뢰구간은 평균의 불확실성, 예측구간은 개별 값의 불확실성. 예측구간이 항상 더 넓다.
- **테스트셋 50개의 CI는 무의미하게 넓다.** 모델 성능을 보고할 때 테스트셋 크기에 따른 CI 폭을 반드시 고려하라.
