# 5.1 빈도주의 vs 베이지안 — 두 세계관의 차이

## 이 챕터에서 배우는 것

- 빈도주의와 베이지안이 "확률"을 다르게 정의하는 방식
- 같은 문제에 대해 두 관점이 어떻게 다른 답을 내는지
- "95% 신뢰구간"과 "95% 신용구간"의 결정적 차이
- ML 엔지니어에게 베이지안 관점이 왜 유용한지

---

## 두 세계관

Part 3~4에서 빈도주의 관점의 추론과 모델링 도구를 쌓았다. 이제 같은 문제를 완전히 다른 렌즈로 보는 방법을 배운다. 2.1에서 잠깐 언급했던 두 철학을 본격적으로 다룬다.

통계학에는 200년 넘게 이어져 온 두 가지 철학이 있다. 같은 데이터를 보고도 다른 질문을 하고, 다른 방식으로 답한다.

### 빈도주의 (Frequentist)

**확률 = 무한히 반복했을 때의 상대 빈도.**

"이 동전의 앞면 확률이 0.5다" = "무한히 던지면 앞면이 50% 나온다."

이 관점에서 **모수는 고정된 상수**다. $\mu$는 하나의 값이고, 우리가 모를 뿐이다. 모수에 "확률"을 부여하는 것은 의미가 없다 — 상수에는 확률이 없으니까.

Part 3에서 배운 모든 것이 빈도주의다:
- 신뢰구간: "이 방법을 반복하면 95%가 맞힌다" (모수에 대한 확률이 아님)
- p-value: "H₀이 참일 때 이런 데이터가 나올 빈도"
- MLE: "이 데이터가 나올 빈도를 최대화하는 모수"

### 베이지안 (Bayesian)

**확률 = 불확실성에 대한 주관적 믿음의 정도.**

"이 동전의 앞면 확률이 0.5라고 믿는다" = "내 현재 지식으로 볼 때 앞면이 나올 것이라는 확신이 50%다."

이 관점에서 **모수도 확률변수**다. $\mu$에 확률분포를 부여할 수 있다. "μ가 95~105 사이에 있을 확률이 95%다"라고 직접 말할 수 있다.

---

## 같은 문제, 다른 접근

동전을 10번 던져서 앞면이 7번 나왔다. "이 동전의 앞면 확률 $p$는?"

### 빈도주의의 답

$$\hat{p}_{\text{MLE}} = \arg\max_p \; P(\text{data} \mid p) = 7/10 = 0.7$$

95% 신뢰구간 (Wald 방법): $\hat{p} \pm 1.96\sqrt{\hat{p}(1-\hat{p})/n} = (0.42, 0.98)$

해석: "이 방법으로 100번 구간을 만들면 약 95번 진짜 $p$를 포함한다." 이 특정 구간이 $p$를 포함하는지는 알 수 없다.

### 베이지안의 답

1단계. **사전분포 설정**: 동전에 대한 사전 지식이 없으므로 $p \sim \text{Uniform}(0, 1)$ (= $\text{Beta}(1, 1)$).

2단계. **데이터 관측**: 10번 중 7번 앞면.

3단계. **사후분포 계산**: 베이즈 정리에 의해:

$$p \mid \text{data} \sim \text{Beta}(1+7, \; 1+3) = \text{Beta}(8, 4)$$

4단계. **95% 신용구간**: 사후분포의 2.5~97.5 백분위수: $(0.39, 0.90)$

해석: "$p$가 0.39~0.90 사이에 있을 확률이 95%다." 직접적으로 모수에 대한 확률을 말한다.

```python
from scipy.stats import beta
import numpy as np

# 사전: Beta(1, 1) = Uniform(0, 1)
# 데이터: 10번 중 7번 앞면
# 사후: Beta(1+7, 1+3) = Beta(8, 4)
posterior = beta(8, 4)

mean = posterior.mean()
ci = posterior.ppf([0.025, 0.975])
print(f"사후 평균: {mean:.3f}")
print(f"95% 신용구간: ({ci[0]:.3f}, {ci[1]:.3f})")
print(f"→ 'p가 이 범위에 있을 확률이 95%'라고 직접 말할 수 있다")
```

## 핵심 차이 정리

| | 빈도주의 | 베이지안 |
|--|---------|---------|
| 확률의 의미 | 반복 빈도 | 믿음의 정도 |
| 모수의 성격 | 고정된 상수 | 확률변수 |
| 사전 지식 사용 | 사용 안 함 | 사전분포로 반영 |
| 구간 추정 | 신뢰구간 (방법의 적중률) | 신용구간 (모수에 대한 확률) |
| 학습 | MLE | MAP 또는 사후분포 전체 |
| 예측 | 점예측 $\hat{y} = f(\hat{\theta}, x)$ | 예측분포 $P(y \mid x, \text{data})$ |

---

## 사전분포가 "주관적"이면 문제 아닌가?

베이지안에 대한 가장 흔한 비판: "사전분포가 주관적이니 결과도 주관적이다."

이것은 반은 맞고 반은 틀리다.

**맞는 부분**: 사전분포의 선택은 분석자의 판단이다. 다른 사전분포를 쓰면 다른 사후분포가 나온다.

**틀린 부분**: 데이터가 충분하면 사전분포의 영향이 사라진다. 어떤 합리적인 사전분포를 쓰든, 데이터가 많으면 사후분포가 같은 곳으로 수렴한다. 이것을 **사후 일치성(posterior consistency)**이라 한다.

직관적으로: 동전을 10번 던지면 사전분포가 결과에 큰 영향을 미친다. 하지만 10,000번 던지면, "공정한 동전"이라고 믿고 시작하든 "앞면이 90% 나오는 동전"이라고 믿고 시작하든, 사후분포는 데이터가 말해주는 곳으로 수렴한다.

이것이 왜 중요한가? 사후 일치성이 없다면, 분석자가 어떤 사전분포를 쓰느냐에 따라 결론이 영구적으로 달라져서 객관성을 잃는다. 사후 일치성 덕분에 "베이지안은 주관적"이라는 비판에 답할 수 있다 — 데이터가 충분하면 사전분포의 선택이 결론에 영향을 미치지 않으므로, **장기적으로는 빈도주의와 수렴한다.**

![사후분포의 수렴](/content/images/stats/05_01/posterior_convergence.svg)

빈도주의도 "주관적"이다. 어떤 모델을 쓸지, 어떤 검정을 할지, α를 얼마로 잡을지 — 전부 분석자의 선택이다. 사전분포가 명시적이라는 점에서 오히려 베이지안이 더 투명할 수 있다.

---

## ML 엔지니어에게 베이지안이 유용한 이유

### 1. 불확실성 정량화

빈도주의 모델은 점예측을 한다. "수율은 92%일 것이다." 베이지안 모델은 분포를 준다. "수율은 90~94% 사이에 있을 확률이 95%이고, 88% 이하일 확률은 3%다."

의사결정에는 분포가 더 유용하다. "92%"만으로는 리스크 판단이 안 되지만, "88% 이하 확률 3%"는 리스크를 직접 수치화한다.

### 2. 순차적 학습

베이지안은 데이터를 순차적으로 반영할 수 있다. 오늘의 사후분포가 내일의 사전분포가 된다. 데이터가 들어올 때마다 믿음을 업데이트하는 자연스러운 프레임워크다.

온라인 학습, 적응형 A/B 테스트, 실시간 이상 탐지에 자연스럽게 맞는다.

### 3. 정규화의 원리적 이해

4.4에서 봤다. 정규화 = MAP = 사전분포. 베이지안 관점을 이해하면 "왜 이 정규화가 작동하는가?"에 원리적으로 답할 수 있다.

### 4. 소량 데이터에서의 강점

데이터가 적을 때 빈도주의 방법은 불안정하다 (SE가 크고, 검정력이 낮다). 베이지안은 사전 지식을 통해 불안정성을 보완할 수 있다. 물론 사전분포가 틀리면 오히려 해가 되지만, 합리적인 사전 지식이 있다면 강력한 도구다.

---

## 어느 쪽이 "맞는가"?

둘 다 맞다. 혹은 둘 다 틀리다. 어느 쪽이든 현실의 근사일 뿐이다.

실용적 관점에서:

- **표본이 크고 사전 지식이 없으면** → 빈도주의가 간단하고 충분하다
- **표본이 작고 사전 지식이 있으면** → 베이지안이 유리하다
- **불확실성 정량화가 중요하면** → 베이지안이 자연스럽다
- **계산 비용이 제한적이면** → 빈도주의가 빠르다

대부분의 ML 실무에서는 빈도주의 도구(MLE, 교차검증, p-value)를 쓰면서 베이지안 직관(정규화 = 사전분포, 불확실성 = 분포)을 함께 갖추는 것이 가장 실용적이다. 이것이 Part 5의 목표다.

---

## Python으로 확인하기

```python
import numpy as np
from scipy import stats
import matplotlib.pyplot as plt

# 동전 문제: 빈도주의 vs 베이지안
n_flips, n_heads = 10, 7

# === 빈도주의 ===
p_hat = n_heads / n_flips
se = np.sqrt(p_hat * (1 - p_hat) / n_flips)
ci_freq = (p_hat - 1.96*se, p_hat + 1.96*se)

print("=== 빈도주의 ===")
print(f"MLE: p̂ = {p_hat:.3f}")
print(f"95% 신뢰구간: ({ci_freq[0]:.3f}, {ci_freq[1]:.3f})")
print(f"해석: '이 방법이 장기적으로 95% 적중한다'")

# === 베이지안 ===
# 세 가지 사전분포
priors = {
    '무정보 Beta(1,1)': (1, 1),
    '공정 믿음 Beta(5,5)': (5, 5),
    '앞면 편향 Beta(8,2)': (8, 2),
}

print(f"\n=== 베이지안 (데이터: {n_heads}/{n_flips} 앞면) ===")
for name, (a0, b0) in priors.items():
    posterior = stats.beta(a0 + n_heads, b0 + (n_flips - n_heads))
    ci_bayes = posterior.ppf([0.025, 0.975])
    print(f"\n사전: {name}")
    print(f"  사후 평균: {posterior.mean():.3f}")
    print(f"  95% 신용구간: ({ci_bayes[0]:.3f}, {ci_bayes[1]:.3f})")

# 데이터가 많아지면 사전분포의 영향이 사라짐
print(f"\n=== 사전분포 수렴 (n=1000, heads=700) ===")
n_big, h_big = 1000, 700
for name, (a0, b0) in priors.items():
    posterior = stats.beta(a0 + h_big, b0 + (n_big - h_big))
    print(f"  {name}: 사후 평균 = {posterior.mean():.4f}")
print(f"  → 사전분포에 거의 무관하게 수렴!")
```

## 핵심 정리

- **빈도주의: 확률 = 빈도. 모수 = 상수.** 데이터만으로 추론. 신뢰구간은 "방법의 적중률"이다.
- **베이지안: 확률 = 믿음. 모수 = 확률변수.** 사전 지식 + 데이터 → 사후 분포. 신용구간은 "모수에 대한 확률"이다.
- **데이터가 많으면 두 관점이 수렴한다.** 사전분포의 영향이 사라지고, MLE ≈ MAP ≈ 사후 평균.
- **어느 쪽이 맞다/틀리다가 아니다.** 상황에 맞는 도구를 고르는 것이 엔지니어의 일.
- **ML 실무에서는 빈도주의 도구 + 베이지안 직관이 최적.** 정규화의 원리, 불확실성 정량화, 순차적 학습에서 베이지안 관점이 유용하다.
