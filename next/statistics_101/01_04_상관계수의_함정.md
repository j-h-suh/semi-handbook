# 1.4 상관계수의 함정 — R²=0.01인데 완벽한 관계가 있다?

## 이 챕터에서 배우는 것

- 피어슨 상관계수(Pearson's r)가 정확히 무엇을 측정하고, 무엇을 측정하지 **못하는지**
- R²=0.01인데 완벽한 결정적 관계가 존재하는 사례
- Spearman, Kendall, Mutual Information — 피어슨의 사각지대를 보완하는 도구들
- "상관 ≠ 인과"가 진짜 뜻하는 것

---

## 업계가 빠져 있는 함정

ML 엔지니어가 피처 선택을 할 때, 가장 흔한 첫 번째 단계가 뭔가?

```python
df.corr()
```

피처 간 상관행렬을 뽑고, 타겟과의 상관계수가 높은 피처를 고르고, 낮은 피처를 버린다. 상관행렬 히트맵을 그려서 리포트에 넣는다. 익숙한 워크플로우다.

문제는, 이 `df.corr()`이 기본으로 계산하는 것이 **피어슨 상관계수**라는 것이다. 그리고 피어슨 상관계수는 **선형 관계만 본다.**

이것이 함정이다. "상관계수가 낮다"는 것은 "관계가 없다"를 뜻하지 않는다. **"선형 관계가 없다"**를 뜻할 뿐이다. 비선형 관계가 아무리 강력해도 피어슨 r은 0에 가까울 수 있다.

이 사실을 모르거나, 알아도 무심코 넘기면, **정보량이 풍부한 피처를 버리게 된다.** 모델 성능의 천장이 피처 선택 단계에서 이미 낮아진 것이다. 모델 아키텍처를 아무리 바꿔봐야 소용없다. 버린 피처에 답이 있었으니까.

---

## 피어슨 상관계수: 정확히 무엇을 측정하는가

피어슨 상관계수 $r$의 정의부터 보자.

$$r = \frac{\sum_{i=1}^{n}(x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^{n}(x_i - \bar{x})^2} \cdot \sqrt{\sum_{i=1}^{n}(y_i - \bar{y})^2}}$$

복잡해 보이지만 핵심은 간단하다. 분자의 $(x_i - \bar{x})(y_i - \bar{y})$를 보자.

- $x$가 평균보다 크고 $y$도 평균보다 크면 → 양수 × 양수 = **양수**
- $x$가 평균보다 크고 $y$는 평균보다 작으면 → 양수 × 음수 = **음수**
- $x$가 평균보다 작고 $y$도 평균보다 작으면 → 음수 × 음수 = **양수**

즉, $x$와 $y$가 같은 방향으로 움직이면 양수, 반대 방향이면 음수가 합산된다. 이것을 모든 데이터에 대해 더한 것이 분자(공분산)이고, 분모는 스케일을 -1~1 범위로 정규화하는 역할이다.

| r 값 | 해석 |
|------|------|
| +1 | 완벽한 양의 선형 관계. 모든 점이 우상향 직선 위에 있다. |
| 0 | 선형 관계 없음. **비선형 관계는 있을 수 있다.** |
| -1 | 완벽한 음의 선형 관계. 모든 점이 우하향 직선 위에 있다. |

핵심 단어는 **"선형"**이다. 피어슨 r이 측정하는 것은 "두 변수가 **직선** 관계에 얼마나 가까운가"이다. 그 이상도 이하도 아니다.

## r ≈ 0인데 완벽한 관계가 있는 경우

이제 함정의 실체를 보자.

```python
import numpy as np

x = np.linspace(-3, 3, 1000)
y = x ** 2  # 완벽한 결정적 관계: y는 x의 함수
```

$y = x^2$이다. $x$를 알면 $y$를 100% 정확하게 알 수 있다. 이보다 강한 관계는 없다.

```python
print(f"피어슨 r: {np.corrcoef(x, y)[0,1]:.6f}")
```

결과: **r ≈ 0.00**

피어슨 상관계수가 사실상 0이다. "상관 없음"이라고 판단할 수 있는 수치다. 하지만 $y = x^2$은 완벽한 결정적 관계다. 이 피처를 버렸다면? 모델은 가장 강력한 예측 변수를 잃게 된다.

왜 이런 일이 생기는가? 피어슨 r의 분자 $(x_i - \bar{x})(y_i - \bar{y})$를 떠올려 보자. $y = x^2$이고 $x$가 $[-3, 3]$ 구간이면 $\bar{x} = 0$이다. $x = -2$일 때 $y = 4$이고, $x = +2$일 때도 $y = 4$다. 전자는 분자에 $(-2)(4 - \bar{y}) < 0$으로 기여하고, 후자는 $(+2)(4 - \bar{y}) > 0$으로 기여한다. 대칭 포물선이므로 이런 양수/음수 쌍이 정확히 상쇄되어 합이 0이 된다. 관계가 "없는" 것이 아니라, 피어슨의 합산 방식이 대칭적 비선형 관계를 구조적으로 상쇄시키는 것이다.

<!-- [GRAPH: 2×2 격자. (1) y=x: r=1.0, 완벽한 양의 선형. (2) y=x²: r≈0, 완벽한 포물선. (3) y=sin(x): r≈0, 완벽한 주기함수. (4) 도넛 모양 원형 분포: r≈0, 강한 구조적 관계. 각 그래프에 피어슨 r 값 표시.] -->

이것은 $y = x^2$만의 문제가 아니다. 주기 함수($y = \sin(x)$), 원형 관계, V자 관계, U자 관계 — 세상에 존재하는 비선형 관계의 대부분이 피어슨 r의 사각지대에 놓인다.

## Anscombe's Quartet: 숫자만 보면 속는다

이 문제의 고전적인 사례가 **앤스콤 사중주(Anscombe's Quartet)**다. 1973년 통계학자 프랭크 앤스콤이 만든 네 개의 데이터셋으로, 기술통계량이 거의 동일하지만 실제 데이터의 형태는 완전히 다르다.

네 데이터셋 모두:
- $x$의 평균 ≈ 9.0, 분산 ≈ 11.0
- $y$의 평균 ≈ 7.5, 분산 ≈ 4.1
- 피어슨 r ≈ 0.816
- 선형 회귀선: $y = 3.0 + 0.5x$ (거의 동일)

숫자만 보면 네 데이터셋이 "같다"고 결론 내릴 수 있다. 하지만 산점도를 그리면:

![앤스콤의 4중주](/content/images/stats/01_04/anscombe_quartet.svg)

- **데이터셋 1**: 정상적인 선형 관계. r = 0.816이 올바르게 반영한다.
- **데이터셋 2**: 완벽한 포물선. 선형이 아닌데 r = 0.816. 피어슨이 속았다.
- **데이터셋 3**: 거의 완벽한 선형인데 이상치 하나가 기울기를 왜곡한다.
- **데이터셋 4**: $x$가 거의 같은 값인데 이상치 하나가 상관계수를 만들어낸다.

앤스콤의 메시지는 명확하다: **통계량만 보지 말고, 데이터를 눈으로 봐라.** 50년 전 메시지인데, `df.corr()` 히트맵만 보고 피처를 선택하는 2020년대의 ML 파이프라인에 여전히 유효하다.

## 공분산: 상관계수의 원재료

피어슨 r을 이해하려면 그 안에 들어 있는 **공분산(Covariance)**을 알아야 한다.

$$\text{Cov}(X, Y) = \frac{1}{n} \sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})$$

공분산은 피어슨 r의 분자다. "두 변수가 같은 방향으로 움직이는 경향"을 측정한다. 값이 양수면 같은 방향, 음수면 반대 방향.

문제는 공분산의 크기가 변수의 스케일에 따라 달라진다는 것이다. 키(cm)와 몸무게(kg)의 공분산과, 키(m)와 몸무게(g)의 공분산은 값이 완전히 다르다. 해석이 안 된다.

피어슨 r은 공분산을 각 변수의 표준편차로 나눠서 **-1~1 범위로 정규화한 것**이다.

$$r = \frac{\text{Cov}(X, Y)}{s_X \cdot s_Y}$$

1.2에서 배운 StandardScaler가 하는 일과 구조가 같다. 스케일을 제거하고 비교 가능하게 만드는 것이다.

> 💡 **ML에서 공분산이 직접 등장하는 곳**: PCA(주성분 분석)의 핵심이 공분산 행렬의 고유값 분해다. `sklearn.decomposition.PCA`는 내부적으로 피처들의 공분산 행렬을 계산하고, 분산이 최대인 방향(주성분)을 찾는다. 공분산이 큰 피처 쌍은 하나의 주성분으로 압축될 가능성이 높다.

## R²와 피어슨 r의 관계

여기서 한 가지 명확히 해야 할 것이 있다. **피어슨 r**과 **R²(결정계수)**는 다른 개념이지만, 단순 선형 회귀에서는 정확히 $R^2 = r^2$이 성립한다.

- **피어슨 r** = 두 변수 간 선형 상관의 강도와 방향. 범위: -1 ~ +1
- **R² (결정계수)** = 모델이 타겟의 분산을 얼마나 설명하는가. 단순 선형 회귀에서의 범위: 0 ~ 1 (단, 일반적으로는 모델이 평균보다 못하면 음수도 가능)

$$R^2 = 1 - \frac{\text{SS}_{\text{res}}}{\text{SS}_{\text{tot}}} = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}$$

단순 선형 회귀에서는 이 두 값이 $R^2 = r^2$으로 연결되지만, 다중 회귀나 비선형 모델에서는 이 관계가 성립하지 않는다. Part 4에서 회귀를 다룰 때 이 구분이 중요해지니 기억해 두자.

실무에서 문제가 되는 상황은 이것이다: 피처 선택 단계에서 피어슨 r로 걸렀는데, 정작 모델(Random Forest, XGBoost 등)은 비선형 관계를 잡을 수 있는 모델이다. **선형 필터로 거른 피처를 비선형 모델에 넣고 있는 것**이다. 필터의 해상도보다 모델의 해상도가 높으니, 필터 단계에서 이미 정보를 잃고 있다.

## 대안 1: Spearman 순위 상관계수

피어슨의 한계를 보완하는 첫 번째 도구가 **스피어만 순위 상관계수(Spearman's rank correlation, $\rho$)**다.

아이디어는 단순하다. 원래 값 대신 **순위(rank)**로 바꾼 뒤 피어슨 r을 계산하는 것이다.

```python
from scipy.stats import spearmanr

x = np.linspace(0, 3, 100)
y = np.exp(x)  # 지수 관계: 비선형이지만 단조증가

pearson_r = np.corrcoef(x, y)[0, 1]
spearman_r, _ = spearmanr(x, y)

print(f"피어슨 r:  {pearson_r:.4f}")   # ~0.94 (선형이 아니라 낮음)
print(f"스피어만 ρ: {spearman_r:.4f}")  # 1.00 (단조증가이므로 완벽)
```

피어슨 r은 "직선에 가까운가"를 보지만, 스피어만 ρ는 **"한쪽이 커지면 다른 쪽도 커지는가"**를 본다. 즉, **단조(monotonic) 관계**를 측정한다. 직선이든 지수 곡선이든 로그 곡선이든, 한 방향으로 꾸준히 증가(또는 감소)하기만 하면 스피어만은 이를 포착한다.

| | 피어슨 r | 스피어만 ρ |
|--|---------|----------|
| 측정하는 것 | 선형 관계 | 단조 관계 |
| $y = 2x + 3$ | 1.0 | 1.0 |
| $y = e^x$ | ~0.94 | 1.0 |
| $y = x^2$ (x > 0) | ~0.97 | 1.0 |
| $y = x^2$ (대칭) | ~0.00 | ~0.00 |
| $y = \sin(x)$ | ~0.00 | ~0.00 |

마지막 두 행을 보자. $y = x^2$ (대칭 구간)과 $y = \sin(x)$는 스피어만으로도 잡히지 않는다. 단조 관계가 아니기 때문이다. 스피어만은 피어슨보다 넓은 범위를 커버하지만, 여전히 사각지대가 있다.

## 대안 2: Mutual Information

피어슨도, 스피어만도 잡지 못하는 관계까지 포착하는 도구가 **상호정보량(Mutual Information, MI)**이다.

MI는 정보이론에서 온 개념으로, **"$X$를 알면 $Y$에 대한 불확실성이 얼마나 줄어드는가"**를 측정한다. 선형이든 비선형이든, 단조든 비단조든, 어떤 형태의 관계든 잡아낸다.

$$MI(X; Y) = \sum_{x,y} p(x,y) \log \frac{p(x,y)}{p(x)p(y)}$$

$X$와 $Y$가 완전히 독립이면 $p(x,y) = p(x)p(y)$이므로 MI = 0. 어떤 형태로든 의존 관계가 있으면 MI > 0.

```python
from sklearn.feature_selection import mutual_info_regression

x = np.linspace(-3, 3, 1000).reshape(-1, 1)
y_linear = 2 * x.ravel() + 1
y_quadratic = x.ravel() ** 2
y_sin = np.sin(x.ravel())

print(f"y = 2x+1  → MI: {mutual_info_regression(x, y_linear)[0]:.3f}")
print(f"y = x²    → MI: {mutual_info_regression(x, y_quadratic)[0]:.3f}")
print(f"y = sin(x) → MI: {mutual_info_regression(x, y_sin)[0]:.3f}")
```

<!-- [OUTPUT:
y = 2x+1  → MI: 1.098
y = x²    → MI: 0.892
y = sin(x) → MI: 0.756
] -->

세 가지 모두 MI > 0이다. 피어슨 r로는 0에 가까웠던 $y = x^2$과 $y = \sin(x)$까지 "관계 있음"으로 잡아낸다.

`sklearn`에서 피처 선택할 때 이미 쓸 수 있다:

```python
from sklearn.feature_selection import SelectKBest, mutual_info_regression

selector = SelectKBest(score_func=mutual_info_regression, k=10)
X_selected = selector.fit_transform(X, y)
```

`df.corr()`로 피처를 거르는 대신, MI 기반 선택을 쓰면 비선형 관계까지 보존된다.

<details>
<summary>🔬 Deep Dive — MI의 장단점과 실무 주의사항</summary>

**장점:**
- 어떤 형태의 의존 관계든 잡아낸다. 선형, 비선형, 단조, 비단조 모두.
- 값의 범위가 0 이상이므로 해석이 직관적이다. 0이면 독립, 클수록 강한 관계.

**단점:**
- **방향을 말해주지 않는다.** 피어슨 r은 양의 관계(+)인지 음의 관계(-)인지 알려주지만, MI는 "관계 있음/없음"의 강도만 알려준다.
- **추정이 어렵다.** 연속 변수에서 MI를 정확히 계산하려면 확률 밀도를 추정해야 하는데, 이것 자체가 어려운 문제다. `sklearn`의 `mutual_info_regression`은 k-nearest neighbors 기반 추정을 쓰는데, 샘플 수가 적으면 불안정하다.
- **계산 비용이 크다.** 피어슨 r은 O(n), MI 추정은 O(n log n) 이상. 피처가 수천 개이고 데이터가 수백만 행이면 체감된다.
- **`random_state`에 따라 결과가 달라질 수 있다.** KNN 기반 추정에서 내부적으로 노이즈를 추가하므로, 실행할 때마다 값이 조금씩 다를 수 있다. 중요한 결정을 할 때는 여러 번 실행해서 안정성을 확인하라.

**실무 권장:**
1. 먼저 `df.corr(method='spearman')`으로 빠르게 단조 관계를 체크한다.
2. 스피어만으로도 안 잡히는 피처가 의심되면 MI를 돌린다.
3. 피어슨 r은 **"이 관계가 선형에 가까운가?"**를 확인하는 용도로만 쓴다.

</details>

|-----------|------|---------|----------|-----|
| 선형 | $y = 2x + 1$ | ✅ 높음 | ✅ 높음 | ✅ 높음 |
| 단조 비선형 | $y = e^x$, $y = \log x$ | △ 중간 | ✅ 높음 | ✅ 높음 |
| 비단조 대칭 | $y = x^2$ (전 구간) | ❌ ~0 | ❌ ~0 | ✅ 높음 |
| 주기 함수 | $y = \sin(x)$ | ❌ ~0 | ❌ ~0 | ✅ 높음 |
| 독립 | 관계 없음 | ✅ ~0 | ✅ ~0 | ✅ ~0 |

<!-- [DIAGRAM: 위 표를 벤 다이어그램으로 시각화. 가장 바깥 원: MI (모든 의존 관계). 중간 원: 스피어만 (단조 관계). 가장 안쪽 원: 피어슨 (선형 관계). 각 영역에 해당하는 관계 유형 예시.] -->

피어슨 ⊂ 스피어만 ⊂ MI. 피어슨이 잡는 것은 스피어만도 잡고, 스피어만이 잡는 것은 MI도 잡는다. 반대는 성립하지 않는다.

그렇다면 "항상 MI만 쓰면 되지 않나?"라는 생각이 들 수 있다. 하지만 도구의 "해상도"가 높을수록 비용도 크다. 피어슨은 빠르고 해석이 쉽다. 스피어만은 약간의 추가 비용으로 넓은 범위를 커버한다. MI는 만능이지만 느리고 불안정하다. 상황에 따라 적절한 도구를 고르는 것이 엔지니어의 일이다.

## 상관 ≠ 인과: 한 문단으로 끝내기

"상관은 인과가 아니다(Correlation does not imply causation)"는 통계학에서 가장 유명한 경구다. ML 엔지니어라면 이미 귀에 딱지가 앉았을 것이다. 그래서 여기서는 핵심만 짧게 짚는다.

아이스크림 판매량과 익사 사고 건수는 높은 상관관계를 보인다. 아이스크림이 익사를 유발하는가? 당연히 아니다. 둘 다 **기온**이라는 숨은 변수(confounding variable)에 의해 함께 올라가는 것이다.

ML에서 이것이 위험한 상황은, 모델이 이런 허위 상관(spurious correlation)을 학습할 때다. 학습 데이터에서는 잘 작동하지만, 숨은 변수의 분포가 바뀌는 순간(계절이 바뀌거나, 공장 환경이 바뀌거나) 모델이 무너진다. 이것이 **분포 이동(distribution shift)** 문제의 한 원인이다.

상관에서 인과를 분리하는 방법론은 Part 6.5 (인과추론 입문)에서 본격적으로 다룬다. 여기서는 하나만 기억하자: **`df.corr()`이 높다고 "이 피처가 원인이다"라고 말하지 마라.** "이 피처가 타겟과 함께 움직인다"까지만 말할 수 있다.

---

## Python으로 확인하기

```python
import numpy as np
from scipy.stats import spearmanr, pearsonr
from sklearn.feature_selection import mutual_info_regression

np.random.seed(42)
x = np.linspace(-3, 3, 500)
x_sin = np.linspace(-10*np.pi, 10*np.pi, 500)  # 주기 함수는 여러 주기 포함

# 네 가지 관계
relations = {
    "y = 2x + 1 (선형)":      (x, 2 * x + 1),
    "y = exp(x) (단조 비선형)": (x, np.exp(x)),
    "y = x² (비단조)":         (x, x ** 2),
    "y = sin(x) (주기)":       (x_sin, np.sin(x_sin)),
}

print(f"{'관계':<25} {'피어슨 r':>10} {'스피어만 ρ':>10} {'MI':>10}")
print("-" * 58)

for name, (xi, y) in relations.items():
    pr, _ = pearsonr(xi, y)
    sr, _ = spearmanr(xi, y)
    mi = mutual_info_regression(xi.reshape(-1, 1), y, random_state=42)[0]
    print(f"{name:<25} {pr:>10.4f} {sr:>10.4f} {mi:>10.3f}")
```

print(df.corr(method='spearman')['x'])

## 핵심 정리

- **피어슨 r은 선형 관계만 측정한다.** r ≈ 0이라고 "관계 없음"이 아니다. "선형 관계 없음"일 뿐이다.
- **비선형 모델에 선형 필터를 쓰지 마라.** `df.corr()`로 피처를 거르고 XGBoost에 넣는 것은, 필터 단계에서 정보를 버리는 것이다.
- **스피어만은 단조 관계까지, MI는 모든 관계를 잡는다.** 피어슨 ⊂ 스피어만 ⊂ MI. 해상도가 높을수록 비용도 크다.
- **`df.corr(method='spearman')`** — 한 줄만 바꿔도 피처 선택의 해상도가 올라간다.
- **상관 ≠ 인과.** 높은 상관은 "함께 움직인다"는 뜻이지 "원인이다"가 아니다. Part 6.5에서 계속.
