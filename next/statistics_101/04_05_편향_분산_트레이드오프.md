# 4.5 편향-분산 트레이드오프 — 통계가 ML 일반화를 설명하는 방법

## 이 챕터에서 배우는 것

- 기대 예측 오차를 편향², 분산, 환원 불가능 오차로 분해하는 법
- 과적합과 과소적합이 이 분해에서 정확히 무엇인지
- 모델 복잡도의 "단 지점(sweet spot)"을 찾는 원리
- 정규화, 앙상블, 교차검증이 이 프레임워크에서 어디에 놓이는지

---

## ML의 근본 질문

모델 학습의 궁극적 목표는 **새로운 데이터에서 잘 작동하는 것**이다. 학습 데이터에서 loss를 0으로 만드는 것은 어렵지 않다 — 모델을 충분히 복잡하게 만들면 된다. 문제는 그 모델이 테스트 데이터에서도 잘 작동하느냐다.

"왜 학습 데이터에서는 잘 되는데 테스트에서는 안 되는가?" — 이 질문에 대한 통계학의 답이 **편향-분산 분해(Bias-Variance Decomposition)**다.

---

## 기대 예측 오차의 분해

새로운 데이터 포인트 $x_0$에서의 기대 예측 오차(MSE)를 분해한다. 데이터가 $y = f(x) + \epsilon$이고 $\epsilon \sim N(0, \sigma^2)$일 때:

$$E\left[(y_0 - \hat{f}(x_0))^2\right] = \underbrace{\text{Bias}^2[\hat{f}(x_0)]}_{\text{편향²}} + \underbrace{\text{Var}[\hat{f}(x_0)]}_{\text{분산}} + \underbrace{\sigma^2}_{\text{환원 불가능 오차}}$$

하나씩 보자.

### 편향 (Bias): 평균적으로 정답에서 얼마나 떨어져 있는가

$$\text{Bias}[\hat{f}(x_0)] = E[\hat{f}(x_0)] - f(x_0)$$

"이 모델을 여러 번 학습시켜 예측의 평균을 내면, 진짜 값에서 얼마나 떨어져 있는가?" 3.1에서 배운 추정량의 불편성과 같은 개념이다.

편향이 높다 = 모델이 데이터의 구조를 **체계적으로 놓친다** = **과소적합(underfitting)**.

예: 비선형 데이터에 직선을 피팅하면, 아무리 데이터를 많이 모아도 직선은 곡선의 패턴을 잡을 수 없다. 체계적 오차.

### 분산 (Variance): 데이터에 따라 예측이 얼마나 흔들리는가

$$\text{Var}[\hat{f}(x_0)] = E\left[(\hat{f}(x_0) - E[\hat{f}(x_0)])^2\right]$$

"다른 학습 데이터로 학습시키면, 예측이 얼마나 달라지는가?" 1.2에서 교차검증 fold마다 성능이 널뛰기하는 것이 이 분산이다.

분산이 높다 = 모델이 학습 데이터의 **노이즈까지 학습한다** = **과적합(overfitting)**.

예: 100차 다항 회귀는 학습 데이터에 완벽히 맞지만, 데이터를 바꾸면 예측이 완전히 달라진다.

### 환원 불가능 오차 (Irreducible Error): σ²

데이터 자체의 노이즈. 진짜 관계 $f(x)$를 정확히 알아도 줄일 수 없다. 3.2에서 예측구간이 일정 폭 이하로 줄지 않는다고 한 것이 이것이다.

<!-- [DIAGRAM: 세 항을 과녁으로 표현. 편향 = 평균 적중점과 과녁 중심의 거리. 분산 = 적중점들의 흩어짐. 환원 불가능 오차 = 과녁 중심 자체의 흔들림(진동). 4개 과녁: 저편향+저분산(최적), 고편향+저분산(과소적합), 저편향+고분산(과적합), 고편향+고분산(최악).] -->

<details>
<summary>🔬 Deep Dive — 편향-분산 분해의 유도</summary>

$y_0 = f(x_0) + \epsilon$, $E[\epsilon] = 0$, $\text{Var}(\epsilon) = \sigma^2$이고 $\epsilon$은 $\hat{f}$와 독립.

$$E[(y_0 - \hat{f}(x_0))^2]$$

$E[\hat{f}(x_0)] = \bar{f}(x_0)$로 표기하고, $\hat{f}$를 중심으로 분해:

$$= E[(y_0 - \bar{f} + \bar{f} - \hat{f})^2]$$

$$= E[(y_0 - \bar{f})^2] + E[(\bar{f} - \hat{f})^2] + 2E[(y_0 - \bar{f})(\bar{f} - \hat{f})]$$

교차 항은 0이 된다 ($y_0$와 $\hat{f}$가 독립이므로).

첫 번째 항:
$$E[(y_0 - \bar{f})^2] = E[(f + \epsilon - \bar{f})^2] = (f - \bar{f})^2 + \sigma^2 = \text{Bias}^2 + \sigma^2$$

두 번째 항:
$$E[(\hat{f} - \bar{f})^2] = \text{Var}(\hat{f})$$

합치면:
$$E[(y_0 - \hat{f})^2] = \text{Bias}^2 + \text{Var} + \sigma^2$$

</details>

## 모델 복잡도와 트레이드오프

모델의 복잡도를 높이면(파라미터를 늘리면, 정규화를 줄이면):

- **편향은 감소한다** — 더 유연한 모델이 데이터의 진짜 구조를 잡는다
- **분산은 증가한다** — 더 유연한 모델이 노이즈까지 학습한다

반대로, 복잡도를 낮추면:
- **편향은 증가** — 너무 단순한 모델이 구조를 놓친다
- **분산은 감소** — 단순한 모델이 데이터 변화에 안정적이다

총 오차 = 편향² + 분산 + σ². 편향과 분산이 반대 방향으로 움직이므로, 총 오차를 최소화하는 **최적의 복잡도**가 존재한다.

<!-- [GRAPH: x축: 모델 복잡도. y축: 오차. 세 곡선 — 편향²(감소), 분산(증가), 총 오차(U자). 총 오차의 최솟값에 "sweet spot" 표시. 왼쪽 = 과소적합, 오른쪽 = 과적합.] -->

이것이 ML에서 가장 중요한 그래프 중 하나다. 모든 모델 선택, 정규화, 앙상블 전략이 이 U자 곡선에서 최적점을 찾는 행위다.

## 지금까지 배운 모든 것이 여기에 연결된다

### 정규화 (4.4)

4.4에서 정규화가 "사전분포"라고 했다. 편향-분산 관점에서:

- 정규화 없음 (MLE) → 편향 낮음, 분산 높음
- 정규화 강함 (큰 λ) → 편향 높음, 분산 낮음

$\lambda$를 키우면 모델이 단순해지고(계수가 0 쪽으로), 편향은 올라가지만 분산이 내려간다. 최적의 $\lambda$는 이 트레이드오프의 균형점이다.

Ridge 회귀의 편향과 분산:

$$\text{Bias}_\text{Ridge} = -\lambda(X^TX + \lambda I)^{-1}\beta \quad \text{(0이 아님 — 편향 있음)}$$
$$\text{Var}_\text{Ridge} = \sigma^2(X^TX + \lambda I)^{-1}X^TX(X^TX + \lambda I)^{-1} \quad \text{(OLS보다 작음)}$$

편향이 생기는 대가로 분산을 줄인다. 이것이 "Ridge가 BLUE가 아니지만 BLUE보다 나을 수 있는 이유"다.

### 앙상블 (1.2)

1.2에서 앙상블의 분산 감소를 봤다. 편향-분산 관점에서:

- **Bagging (Random Forest)**: 분산을 줄인다. 고분산 모델(깊은 트리)을 여러 개 평균 내서 분산 감소. 편향은 거의 변하지 않음.
- **Boosting (XGBoost)**: 편향을 줄인다. 이전 모델의 잔차를 반복적으로 피팅하여 체계적 오차를 수정. 분산은 약간 증가할 수 있음.

| 전략 | 편향에 미치는 영향 | 분산에 미치는 영향 |
|------|------------------|------------------|
| 모델 복잡도 ↑ | ↓ 감소 | ↑ 증가 |
| 정규화 ↑ | ↑ 증가 | ↓ 감소 |
| Bagging | ≈ 변화 없음 | ↓ 감소 |
| Boosting | ↓ 감소 | ↑ (약간) 증가 |
| 데이터 ↑ | ≈ 변화 없음 | ↓ 감소 |

마지막 행이 중요하다. **데이터를 더 모으면 분산은 줄지만 편향은 안 줄어든다.** 모델이 구조적으로 틀린 경우(편향이 높은 경우), 데이터를 아무리 많이 모아도 나아지지 않는다. 이때는 모델을 바꿔야 한다.

### 교차검증 (실전)

교차검증이 추정하는 것은 **총 기대 예측 오차** (편향² + 분산 + σ²)다. 학습 곡선을 그려서:

- 학습 오차와 검증 오차가 모두 높다 → **편향 문제** (과소적합). 모델을 복잡하게.
- 학습 오차는 낮은데 검증 오차가 높다 → **분산 문제** (과적합). 정규화, 데이터 추가, 모델 단순화.
- 학습 오차와 검증 오차가 모두 낮고 가깝다 → **좋은 상태**.

```python
from sklearn.model_selection import learning_curve

train_sizes, train_scores, val_scores = learning_curve(
    model, X, y, train_sizes=np.linspace(0.1, 1.0, 10), cv=5
)

plt.plot(train_sizes, train_scores.mean(axis=1), label='학습 오차')
plt.plot(train_sizes, val_scores.mean(axis=1), label='검증 오차')
plt.xlabel('학습 데이터 크기')
plt.ylabel('성능')
plt.legend()
```

## 이중 하강 현상: 전통적 그림을 넘어서

최근 딥러닝 연구에서 전통적인 U자 곡선을 벗어나는 현상이 관측되었다. **이중 하강(Double Descent)**: 모델 복잡도를 극단적으로 키우면(파라미터 수 > 데이터 수), 테스트 오차가 다시 감소하는 현상.

전통적 통계학의 편향-분산 트레이드오프로는 설명하기 어렵다. 이것은 현재 활발한 연구 주제이고, "과파라미터화(overparameterization)"가 왜 오히려 일반화에 도움이 되는지에 대한 이론이 발전 중이다.

> 💡 **실무적 함의**: 전통적 편향-분산 프레임워크는 여전히 대부분의 ML 상황에서 유효하다. 이중 하강은 주로 매우 큰 신경망과 특정 조건에서 나타난다. 기본 원리를 먼저 이해하고, 예외를 나중에 배우는 것이 올바른 순서다.

이 5개 챕터를 관통하는 하나의 문장:

> **"모델의 가정을 알고, 그 가정이 맞는지 진단하고, 편향과 분산의 균형에서 최적을 찾아라."**

Part 5에서는 이 프레임워크를 베이지안 관점으로 확장한다.

## Python으로 확인하기

```python
import numpy as np
from sklearn.linear_model import Ridge
from sklearn.model_selection import cross_val_score

np.random.seed(42)

# 진짜 관계: y = sin(x) + noise
n = 50
X = np.sort(np.random.uniform(0, 2*np.pi, n))
y = np.sin(X) + np.random.normal(0, 0.3, n)

# 편향-분산 시뮬레이션: 다항 회귀 차수별
from sklearn.preprocessing import PolynomialFeatures
from sklearn.pipeline import make_pipeline

n_simulations = 200
x_test = np.array([3.0])  # 테스트 포인트 하나

print(f"=== 편향-분산 분해 (x_test = {x_test[0]}) ===")
print(f"진짜 값: f(3.0) = sin(3.0) = {np.sin(3.0):.4f}\n")
print(f"{'차수':>4} {'편향²':>8} {'분산':>8} {'총오차':>8}")
print("-" * 32)

for degree in [1, 3, 5, 10, 20]:
    predictions = []
    for _ in range(n_simulations):
        X_sim = np.sort(np.random.uniform(0, 2*np.pi, n))
        y_sim = np.sin(X_sim) + np.random.normal(0, 0.3, n)
        
        model = make_pipeline(
            PolynomialFeatures(degree),
            Ridge(alpha=0.01)
        )
        model.fit(X_sim.reshape(-1, 1), y_sim)
        pred = model.predict(x_test.reshape(-1, 1))[0]
        predictions.append(pred)
    
    preds = np.array(predictions)
    bias_sq = (preds.mean() - np.sin(3.0))**2
    variance = preds.var()
    total = bias_sq + variance + 0.3**2  # σ² = 0.09
    
    print(f"{degree:>4} {bias_sq:>8.4f} {variance:>8.4f} {total:>8.4f}")

# 학습 곡선으로 편향 vs 분산 진단
print(f"\n=== 학습 곡선 진단 ===")
for degree, label in [(1, '과소적합'), (5, '적절'), (20, '과적합')]:
    model = make_pipeline(PolynomialFeatures(degree), Ridge(alpha=0.01))
    train_scores = cross_val_score(model, X.reshape(-1,1), y, cv=5,
                                    scoring='neg_mean_squared_error')
    print(f"  {label} (차수 {degree:>2}): CV MSE = {-train_scores.mean():.4f} "
          f"± {train_scores.std():.4f}")
```

## 핵심 정리

- **총 예측 오차 = 편향² + 분산 + σ².** 편향은 모델의 구조적 한계, 분산은 데이터 의존성, σ²는 줄일 수 없는 노이즈.
- **과소적합 = 편향 지배. 과적합 = 분산 지배.** 학습 곡선으로 진단하라.
- **정규화는 편향을 약간 높이고 분산을 크게 줄인다.** λ의 최적값은 이 균형점.
- **데이터를 더 모으면 분산은 줄지만 편향은 안 줄어든다.** 편향이 높으면 모델을 바꿔야 한다.
- **Bagging = 분산 감소, Boosting = 편향 감소.** 어디가 문제인지에 따라 전략이 다르다.
