# 2.5 중심극한정리(CLT) — batch size를 키우면 왜 안정되는가

## 이 챕터에서 배우는 것

- 중심극한정리(CLT)가 말하는 것의 정확한 의미
- 원래 분포가 뭐든 상관없다는 것이 왜 놀라운지
- 표준오차(SE)와 표준편차(SD)의 차이 — 혼동하면 모든 추론이 틀어진다
- batch size, 앙상블, 부트스트랩 — CLT가 작동하는 ML의 세 현장

---

## 통계학에서 가장 중요한 정리

과장이 아니다. 중심극한정리(Central Limit Theorem, CLT)는 통계학의 추론 체계 전체를 떠받치는 정리다. Part 3에서 배울 신뢰구간, 가설검정, p-value가 전부 CLT 위에 서 있다. CLT가 없으면 "표본에서 모집단을 추론한다"는 통계학의 핵심 작업이 불가능해진다.

그런데 이 정리의 내용은 놀라울 정도로 단순하다.

---

## CLT가 말하는 것

$X_1, X_2, \ldots, X_n$이 평균 $\mu$, 분산 $\sigma^2$인 **임의의 분포**에서 독립적으로 뽑은 표본이라 하자. 표본 평균을 $\bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i$라 하면, $n$이 충분히 크면:

$$\frac{\bar{X}_n - \mu}{\sigma / \sqrt{n}} \xrightarrow{d} N(0, 1)$$

또는 동등하게:

$$\bar{X}_n \approx N\left(\mu, \frac{\sigma^2}{n}\right)$$

한국어로 풀면: **어떤 분포에서 뽑든, 표본 평균의 분포는 정규분포에 가까워진다.**

이 정리에서 놀라운 부분은 **"임의의 분포"**다. 원래 분포가 지수분포든, 균등분포든, 포아송이든, 심지어 이상하게 비대칭인 분포든 상관없다. 충분히 많이 뽑아서 평균을 내면 그 평균은 정규분포를 따른다.

## "충분히 크면"이 얼마나 큰 건가

CLT는 $n \to \infty$에서 성립하는 극한 정리다. 현실에서는 $n$이 유한하니, "얼마나 커야 정규에 가까운가?"가 실용적인 질문이다.

대략적인 가이드라인:

| 원래 분포의 형태 | 필요한 n |
|----------------|---------|
| 이미 대칭에 가까운 분포 | ~10이면 충분 |
| 약간 skewed | ~30 |
| 심하게 skewed (지수분포 등) | ~50 이상 |
| 극단적으로 두꺼운 꼬리 | 수백 이상, 또는 부족 |

유명한 "n ≥ 30 규칙"은 여기서 온 것이다. 하지만 이것은 경험 법칙이지 절대적 기준이 아니다. 분포가 대칭에 가까우면 n=10으로도 충분하고, 심하게 skewed되어 있으면 n=30으로도 부족하다. "충분히 큰가"를 진단하려면 부트스트랩으로 표본 평균의 분포를 직접 그려보거나, Shapiro-Wilk 검정을 표본 평균에 적용해 보라 — 정규성에서 크게 벗어나면 n이 부족하다는 신호다.

> 💡 **CLT가 작동하지 않는 경우**: 2.2에서 본 코시 분포처럼 분산이 존재하지 않는 분포에는 CLT가 적용되지 않는다. CLT의 전제 조건은 "분산이 유한할 것"이다. 금융 데이터처럼 극단적으로 두꺼운 꼬리를 가진 데이터에서 CLT를 무조건 신뢰하면 위험하다.

## 표준오차: CLT의 핵심 부산물

CLT에서 표본 평균의 분산이 $\sigma^2/n$이라고 했다. 여기에 루트를 씌운 것이 **표준오차(Standard Error, SE)**다.

$$\text{SE}(\bar{X}) = \frac{\sigma}{\sqrt{n}}$$

표준편차(SD)와 표준오차(SE)는 이름이 비슷해서 자주 혼동되지만, 완전히 다른 것을 측정한다.

| | 표준편차 (SD) | 표준오차 (SE) |
|--|-------------|-------------|
| 측정 대상 | **개별 데이터**의 흩어짐 | **표본 평균**의 흩어짐 |
| 공식 | $\sigma$ (또는 $s$) | $\sigma / \sqrt{n}$ (또는 $s / \sqrt{n}$) |
| n이 커지면 | 변하지 않음 | 줄어든다 ($\propto 1/\sqrt{n}$) |
| 의미 | "데이터가 얼마나 퍼져 있는가" | "평균 추정이 얼마나 정밀한가" |

이 구분이 왜 중요한가? **논문에서 `±` 뒤에 오는 숫자가 SD인지 SE인지에 따라 해석이 완전히 달라진다.**

- `accuracy: 0.85 ± 0.07 (SD)` → "각 fold의 성능이 0.07 정도 흩어져 있다"
- `accuracy: 0.85 ± 0.03 (SE)` → "진짜 성능은 0.85 ± 0.03 범위에 있을 가능성이 높다"

같은 데이터에서 SD = 0.07이면 SE = 0.07/√5 ≈ 0.03 (5-fold 기준). SE가 항상 더 작다. 어떤 논문은 SE를 쓰면서 명시하지 않아서 성능이 "안정적"으로 보이게 만든다. `±` 뒤의 숫자를 볼 때 반드시 SD인지 SE인지 확인하라.

## ML에서 CLT가 작동하는 세 가지 현장

### 1. Batch Size와 Gradient 안정성

1.2에서 복선을 깔았다. 이제 회수할 때다.

미니배치 gradient는 $B$개 샘플의 gradient를 **평균**낸 것이다.

$$\nabla_{\text{batch}} = \frac{1}{B} \sum_{i=1}^{B} \nabla_i$$

각 $\nabla_i$가 (같은 분포에서) 독립적으로 뽑혔다면, CLT에 의해:

$$\nabla_{\text{batch}} \approx N\left(\mu_\nabla, \frac{\sigma^2_\nabla}{B}\right)$$

- **분산이 $1/B$로 줄어든다** → batch size를 키우면 gradient 추정이 안정적
- **분포가 정규에 가까워진다** → 이상한 모양의 gradient 분포도 평균을 내면 정규에 가까워짐

하지만 $1/\sqrt{B}$로만 줄어드므로(표준편차 기준), batch size를 4배로 키워도 표준오차는 절반으로만 줄어든다. 수확 체감이 심하다. 이것이 "batch size를 무한정 키우는 것이 능사가 아닌" 이유의 수학적 근거다.

엄밀하게 따지면, 미니배치 내의 gradient들이 "독립"인 것은 하나의 미니배치 안에서의 이야기이고, 스텝 간에는 가중치가 업데이트되므로 독립이 아니다. 그런데도 CLT 기반의 직관이 작동하는 이유는, 학습률이 충분히 작으면 한 스텝 사이의 가중치 변화가 미미해서 gradient의 분포가 "거의 동일"하게 유지되기 때문이다. 학습률이 크면 이 근사가 깨지고 학습이 불안정해진다 — learning rate warmup이 필요한 이유 중 하나다.

### 2. 앙상블과 분산 감소

1.2에서 앙상블의 분산 감소를 봤다. 이것도 CLT의 직접적인 응용이다.

독립인 $n$개 모델의 예측을 평균 내면:

$$\text{Var}(\bar{f}) = \frac{\sigma^2}{n}, \quad \text{SE}(\bar{f}) = \frac{\sigma}{\sqrt{n}}$$

Random Forest의 100개 트리 → 단일 트리 대비 표준오차 1/10. 정규분포에 가까운 안정적인 예측.

### 3. 부트스트랩: CLT를 직접 구현하기

**부트스트랩(Bootstrap)**은 표본 분포를 직접 시뮬레이션으로 구하는 기법이다. CLT가 이론적으로 보장하는 것을 시뮬레이션으로 직접 확인할 수 있고, CLT의 전제가 약한 상황에서도 사용할 수 있다. 아이디어:

1. 원래 데이터에서 **복원 추출(sampling with replacement)**로 같은 크기의 새 데이터셋을 만든다.
2. 새 데이터셋에서 원하는 통계량(평균, 중앙값, 회귀 계수 등)을 계산한다.
3. 1~2를 1000번 반복한다.
4. 1000개의 통계량 분포를 본다 → 이것이 그 통계량의 **표본 분포(sampling distribution)**의 근사다.

```python
n_bootstrap = 1000
boot_means = []
for _ in range(n_bootstrap):
    boot_sample = np.random.choice(data, size=len(data), replace=True)
    boot_means.append(boot_sample.mean())

ci_95 = np.percentile(boot_means, [2.5, 97.5])
print(f"95% 부트스트랩 CI: ({ci_95[0]:.3f}, {ci_95[1]:.3f})")
```

CLT는 "표본 평균의 분포는 정규"라고 말하는데, 부트스트랩은 그 분포를 **직접 시뮬레이션**으로 만들어낸다. CLT가 이론이면, 부트스트랩은 실천이다.

부트스트랩의 장점은 CLT의 전제 조건(큰 n, 유한한 분산)이 약해도 쓸 수 있다는 것이다. 그리고 평균뿐 아니라 중앙값, 상관계수, 회귀 계수 등 **어떤 통계량이든** 표본 분포를 추정할 수 있다. Part 6.2에서 더 자세히 다룬다.

## CLT와 $\sqrt{n}$의 법칙

CLT에서 반복적으로 등장하는 패턴이 있다. **정밀도가 $\sqrt{n}$에 비례한다**는 것이다.

$$\text{SE} = \frac{\sigma}{\sqrt{n}}$$

이것의 실무적 함의:

| 정밀도를 2배로 하려면 | 필요한 데이터 |
|---------------------|-------------|
| SE를 1/2로 | $n$을 **4배**로 |
| SE를 1/3로 | $n$을 **9배**로 |
| SE를 1/10로 | $n$을 **100배**로 |

데이터를 2배 모으면 정밀도는 $\sqrt{2} \approx 1.41$배만 올라간다. 수확 체감이 극심하다.

이것은 모든 곳에 적용된다:

- **A/B 테스트 기간**: 효과 크기가 작을수록 필요한 샘플이 기하급수적으로 늘어난다 (Part 6.1)
- **모델 성능 추정**: 테스트셋을 4배로 키워야 신뢰구간이 절반으로 줄어든다
- **앙상블 효과**: 모델 10개 → 100개로 늘려도 SE는 $\sqrt{10}$ ≈ 3.16배만 줄어든다

이 $\sqrt{n}$ 법칙을 모르면, "데이터를 더 모으면 되겠지"라는 순진한 기대로 리소스를 낭비하게 된다. 어느 시점에서 데이터를 더 모으는 것보다 모델을 개선하거나 피처를 추가하는 것이 더 효율적인지 판단하는 데 이 법칙이 쓰인다.

## CLT를 직관적으로 이해하기

왜 평균을 내면 정규분포에 가까워지는가? 엄밀한 증명은 특성함수(characteristic function)를 써야 하지만, 직관적 설명은 이렇다.

데이터를 합산하면 다양한 값의 조합이 가능해진다. 극단적인 조합(모두 크거나 모두 작은 경우)은 드물고, 중간 정도의 조합(큰 것과 작은 것이 섞인 경우)은 많다. 합이 커질수록 이 "중간에 몰리는" 효과가 강해지고, 결국 종 모양의 분포가 된다.

<details>
<summary>🔬 Deep Dive — CLT의 수학적 진술과 수렴 속도</summary>

**정확한 진술 (Lindeberg-Lévy CLT):**

$X_1, X_2, \ldots$가 i.i.d.이고 $E[X_i] = \mu$, $\text{Var}(X_i) = \sigma^2 < \infty$이면:

$$\sqrt{n}\left(\bar{X}_n - \mu\right) \xrightarrow{d} N(0, \sigma^2)$$

$\xrightarrow{d}$는 **분포 수렴(convergence in distribution)**을 뜻한다. 표본 평균의 분포가 정규분포에 "가까워진다"는 의미이지, 표본 평균의 값이 특정 숫자에 수렴한다는 뜻이 아니다 (그건 LLN).

**Berry-Esseen 정리 (수렴 속도):**

CLT의 근사 오차는 $O(1/\sqrt{n})$ 이하이다. 더 정확하게:

$$\sup_x |P(\bar{Z}_n \leq x) - \Phi(x)| \leq \frac{C \cdot E[|X - \mu|^3]}{\sigma^3 \sqrt{n}}$$

여기서 $\Phi$는 표준 정규 CDF, $C$는 상수 (≤ 0.4748). 이것이 뜻하는 바:

- 세 번째 절대 적률($E[|X-\mu|^3]$)이 크면, 즉 분포가 **비대칭이거나 꼬리가 두꺼우면**, 수렴이 느리다.
- 대칭에 가까운 분포일수록 수렴이 빠르다.
- 어떤 경우든 $1/\sqrt{n}$ 속도로 수렴하므로, $n$을 4배로 하면 근사 오차가 대략 절반으로 줄어든다.

</details>

## Python으로 확인하기

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

np.random.seed(42)

# 원래 분포: 심하게 skewed된 지수분포
original_dist = stats.expon(scale=2)  # E[X]=2, Var(X)=4
mu, sigma = 2.0, 2.0

# CLT 시뮬레이션
sample_sizes = [1, 2, 5, 10, 30, 100]
n_simulations = 10000

print(f"{'n':>5} | {'표본평균의 평균':>12} | {'표본평균의 SE':>12} | {'이론 SE':>10}")
print("-" * 50)

for n in sample_sizes:
    sample_means = [original_dist.rvs(size=n).mean() for _ in range(n_simulations)]
    empirical_mean = np.mean(sample_means)
    empirical_se = np.std(sample_means)
    theoretical_se = sigma / np.sqrt(n)
    print(f"{n:>5} | {empirical_mean:>12.4f} | {empirical_se:>12.4f} | {theoretical_se:>10.4f}")

# √n 법칙 확인
print(f"\n=== √n 법칙 ===")
print(f"n=100 SE: {sigma/np.sqrt(100):.4f}")
print(f"n=400 SE: {sigma/np.sqrt(400):.4f} (n을 4배 → SE 절반)")
print(f"n=10000 SE: {sigma/np.sqrt(10000):.4f} (n을 100배 → SE 1/10)")

# SD vs SE 구분
data = original_dist.rvs(size=100)
sd = np.std(data, ddof=1)
se = sd / np.sqrt(len(data))
print(f"\n=== SD vs SE (n=100) ===")
print(f"SD: {sd:.4f} (개별 데이터의 흩어짐)")
print(f"SE: {se:.4f} (평균 추정의 정밀도)")
print(f"SE = SD/√n = {sd:.4f}/√100 = {sd/10:.4f}")
```

## 핵심 정리

- **CLT: 어떤 분포에서 뽑든, 표본 평균의 분포는 정규분포에 가까워진다.** 전제 조건은 독립, 동일 분포, 유한한 분산.
- **표준오차(SE) = σ/√n.** 표준편차(SD)와 혼동하지 마라. SD는 데이터의 흩어짐, SE는 평균 추정의 정밀도. 논문의 `±` 뒤에 뭐가 오는지 확인하라.
- **√n 법칙**: 정밀도를 2배로 하려면 데이터가 4배 필요하다. 수확 체감이 극심하다.
- **Batch size, 앙상블, 부트스트랩** — 모두 "평균을 내서 분산을 줄이는" CLT의 응용이다.
- **CLT는 Part 3 전체의 기반이다.** 신뢰구간, 가설검정, p-value가 전부 "표본 평균이 정규분포를 따른다"는 사실 위에 서 있다.
