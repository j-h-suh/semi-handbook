- t-분포가 정규분포보다 꼬리가 두꺼운 이유
- 세 가지 t-검정: 단일 표본, 독립 두 표본, 대응 표본
- ML 모델 비교에서 어떤 검정을 골라야 하는가

---

3.3에서 가설검정의 프레임워크 — p-value, 유의수준, 검정력 — 를 세웠다. 이제 그 프레임워크를 구체적인 검정 도구로 채울 차례다.

## z-검정: 이론의 출발점

3.3에서 검정 통계량을 구할 때 이런 공식을 썼다:

$$z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}}$$

이것이 **z-검정(z-test)**이다. $\sigma$를 안다고 가정하고, CLT에 의해 이 통계량이 $N(0,1)$을 따른다는 것을 이용한다.

문제: **현실에서 $\sigma$를 아는 경우는 거의 없다.**

모표준편차 $\sigma$를 아는 상황이란, 공정의 변동성이 역사적으로 확립된 경우 — 예를 들어 특정 장비의 측정 오차가 $\sigma = 0.5$ nm로 알려져 있다거나 — 정도다. 대부분의 ML 상황에서는 $\sigma$를 모른다.

그래서 실전에서는 거의 항상 t-검정을 쓴다.

---

## t-검정: σ를 모를 때

### t-분포의 등장

$\sigma$ 대신 표본표준편차 $s$를 쓰면:

$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}$$

이 통계량은 정규분포가 아니라 **t-분포(Student's t-distribution)**를 따른다. 자유도(df)는 $n - 1$이다.

t-분포가 정규분포와 다른 점: **꼬리가 더 두껍다.** 직관적으로 이해하면 이렇다. $t = \frac{\bar{x} - \mu}{s / \sqrt{n}}$에서 분모의 $s$도 확률변수다. 표본이 작으면 $s$가 우연히 매우 작게 나올 수 있고, 그러면 $t$가 폭발적으로 커진다. 반대로 $s$가 크면 $t$가 작아진다. 이 "분모의 흔들림" 때문에 $t$의 분포는 정규분포보다 극단적인 값이 나올 확률이 높다 — 즉 꼬리가 두꺼워진다. 표본이 커지면 $s$가 $\sigma$에 수렴하여 흔들림이 줄고, t-분포는 정규분포에 가까워진다.

![t-분포 vs 정규분포](/content/images/stats/03_04/t_distribution_comparison.svg)

| 자유도 (df) | t-분포의 성격 | 95% 양측 임계값 |
|------------|-------------|---------------|
| 3 | 꼬리 매우 두꺼움 | 3.182 |
| 5 | 꼬리 두꺼움 | 2.571 |
| 10 | 약간 두꺼움 | 2.228 |
| 30 | 거의 정규 | 2.042 |
| ∞ | = 정규분포 | 1.960 |

df가 작을수록(= 데이터가 적을수록) 임계값이 커진다. 이것은 "데이터가 적으면 더 강한 증거가 필요하다"는 직관과 일치한다. df = 3에서는 3.182 이상이어야 유의미한데, df = ∞에서는 1.960이면 충분하다.

## 세 가지 t-검정

### 1. 단일 표본 t-검정 (One-sample t-test)

"표본 평균이 특정 값과 다른가?"

$$H_0: \mu = \mu_0, \quad t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}, \quad \text{df} = n - 1$$

**ML 활용**: "이 모델의 정확도가 기준 성능(예: 0.80)과 다른가?"

```python
from scipy import stats

cv_scores = [0.83, 0.86, 0.84, 0.87, 0.85, 0.84, 0.86, 0.83]
t_stat, p_value = stats.ttest_1samp(cv_scores, popmean=0.80)
print(f"t = {t_stat:.3f}, p = {p_value:.4f}")
# → 0.80보다 유의미하게 높은가?
```

### 2. 독립 두 표본 t-검정 (Independent two-sample t-test)

"두 그룹의 평균이 다른가?"

$$t = \frac{\bar{x}_1 - \bar{x}_2}{\text{SE}_{\text{diff}}}, \quad \text{SE}_{\text{diff}} = s_p\sqrt{\frac{1}{n_1} + \frac{1}{n_2}}$$

$s_p$는 합동 표준편차(pooled standard deviation). 두 그룹의 분산이 같다고 가정한다.

**ML 활용**: "A/B 테스트에서 두 그룹의 전환율이 다른가?" 두 그룹이 서로 다른 사용자들이므로 독립이다.

```python
# A/B 테스트: 컨트롤 vs 실험군
group_a = np.random.normal(0.05, 0.02, 500)  # 전환율 (컨트롤)
group_b = np.random.normal(0.055, 0.02, 500)  # 전환율 (실험군)

t_stat, p_value = stats.ttest_ind(group_a, group_b)
print(f"t = {t_stat:.3f}, p = {p_value:.4f}")
```

등분산 가정이 의심되면 **Welch's t-test**를 쓴다:

```python
t_stat, p_value = stats.ttest_ind(group_a, group_b, equal_var=False)
```

> 💡 **실무 규칙**: 등분산 여부를 모르겠으면 그냥 Welch's t-test를 써라. `equal_var=False`가 더 안전하다. 등분산일 때도 검정력 손실이 미미하고, 이분산일 때는 일반 t-검정이 틀리기 때문이다.

### 3. 대응 표본 t-검정 (Paired t-test)

"같은 대상에 대한 두 측정값의 차이가 0이 아닌가?"

$$d_i = x_{1i} - x_{2i}, \quad t = \frac{\bar{d}}{s_d / \sqrt{n}}, \quad \text{df} = n - 1$$

차이 $d_i$를 구한 뒤, 이것에 대해 단일 표본 t-검정을 하는 것과 같다.

**ML 활용**: 같은 데이터셋에서 모델 A와 B를 비교할 때. 각 fold(또는 각 테스트 샘플)에서의 성능 차이를 구한다.

```python
# 같은 5-fold에서 두 모델의 성능
model_a = np.array([0.83, 0.86, 0.84, 0.87, 0.85])
model_b = np.array([0.86, 0.89, 0.87, 0.88, 0.90])

t_stat, p_value = stats.ttest_rel(model_a, model_b)
print(f"t = {t_stat:.3f}, p = {p_value:.4f}")
```

## 어떤 검정을 골라야 하는가

이 선택이 실무에서 가장 헷갈리는 부분이다.

| 상황 | 검정 | 이유 |
|------|------|------|
| 모델 성능이 기준(0.80)보다 높은가? | 단일 표본 t | 하나의 모델 vs 고정된 기준 |
| A/B 테스트: 두 그룹 사용자 비교 | 독립 두 표본 t | 두 그룹이 서로 다른 사용자 |
| 같은 데이터에서 모델 A vs B | **대응 표본 t** | 같은 fold에서 비교 → 쌍을 이룸 |
| 같은 데이터에서 전처리 전 vs 후 | **대응 표본 t** | 같은 데이터의 변환 → 쌍을 이룸 |

ML에서 가장 흔한 상황은 **"같은 데이터에서 두 모델 비교"**이고, 이때는 **대응 표본 t-검정**이 맞다. 독립 두 표본 t-검정을 쓰면 검정력이 크게 떨어진다 — fold 간 난이도 차이를 무시하고 노이즈로 처리하기 때문이다.

<details>
<summary>🔬 Deep Dive — 대응 검정이 독립 검정보다 검정력이 높은 이유</summary>

5-fold 교차검증에서 모델 A와 B의 결과가 이렇다고 하자:

```
Fold 1: A=0.70, B=0.73  (어려운 fold)
Fold 2: A=0.90, B=0.92  (쉬운 fold)
Fold 3: A=0.80, B=0.83  (보통 fold)
```

독립 검정은 A = {0.70, 0.90, 0.80}과 B = {0.73, 0.92, 0.83}을 별개의 그룹으로 본다. A의 분산은 fold 난이도 차이 때문에 크고, B도 마찬가지다. 이 큰 분산이 SE를 키워서 차이를 감지하기 어렵게 만든다.

대응 검정은 차이 $d$ = {0.03, 0.02, 0.03}을 본다. fold 난이도 차이가 상쇄되었으므로 분산이 극적으로 줄어든다. SE가 작아지니 같은 차이도 더 쉽게 감지한다.

핵심: 대응 검정은 **짝 내 변동(within-pair variation)**만 보고, **짝 간 변동(between-pair variation)**을 제거한다. fold 난이도라는 "혼란 변수"를 통제하는 것이다.

</details>

## 단측검정 vs 양측검정

지금까지는 **양측검정(two-sided test)**을 가정했다: "다르다" ($\mu_A \neq \mu_B$).

**단측검정(one-sided test)**은 방향을 지정한다: "더 크다" ($\mu_B > \mu_A$) 또는 "더 작다" ($\mu_B < \mu_A$).

```python
# 양측검정: "다른가?"
t_stat, p_two = stats.ttest_rel(model_a, model_b)

# 단측검정: "B가 더 좋은가?" (B > A, 즉 A - B < 0)
p_one = p_two / 2 if t_stat < 0 else 1 - p_two / 2

# scipy 1.11+ 에서는 alternative 파라미터 사용
t_stat, p_one = stats.ttest_rel(model_a, model_b, alternative='less')
# alternative='less'는 "a < b"를 테스트 (a가 b보다 작은가 = b가 더 좋은가)
```

단측검정은 양측검정보다 p-value가 절반이므로 검정력이 높다. 하지만 **반대 방향의 효과를 완전히 무시한다**는 위험이 있다. B가 A보다 나쁠 가능성을 아예 고려하지 않는 것이다.

실무 규칙: 방향이 사전에 명확히 정해져 있으면 단측, 그렇지 않으면 양측. "어떤 방향이든 차이가 있으면 알고 싶다"면 양측이 안전하다.

## z-검정으로 비율 비교: A/B 테스트의 실제

A/B 테스트에서 전환율처럼 이항 비율을 비교할 때는, t-검정 대신 **비율의 z-검정**을 쓰는 것이 더 적절하다.

$$z = \frac{\hat{p}_B - \hat{p}_A}{\sqrt{\hat{p}(1-\hat{p})\left(\frac{1}{n_A} + \frac{1}{n_B}\right)}}$$

여기서 $x_A$, $x_B$는 각 그룹의 전환(성공) 수이고, $\hat{p} = \frac{x_A + x_B}{n_A + n_B}$는 **합동 비율(pooled proportion)**이다. 귀무가설이 "$p_A = p_B$"이므로, 두 그룹의 전환율이 같다고 가정하고 전체 데이터를 합쳐서 하나의 비율을 추정하는 것이다. 이 합동 비율로 SE를 계산해야 $H_0$ 하에서의 변동성을 올바르게 반영한다.

```python
def ab_test_proportion(conversions_a, n_a, conversions_b, n_b, alpha=0.05):
    """이항 비율의 z-검정"""
    p_a = conversions_a / n_a
    p_b = conversions_b / n_b
    p_pool = (conversions_a + conversions_b) / (n_a + n_b)
    
    se = np.sqrt(p_pool * (1 - p_pool) * (1/n_a + 1/n_b))
    z = (p_b - p_a) / se
    p_value = 2 * (1 - stats.norm.cdf(abs(z)))  # 양측검정
    
    # 효과 크기와 CI
    diff = p_b - p_a
    se_diff = np.sqrt(p_a*(1-p_a)/n_a + p_b*(1-p_b)/n_b)
    ci = (diff - 1.96*se_diff, diff + 1.96*se_diff)
    
    return {
        'p_a': p_a, 'p_b': p_b, 'diff': diff,
        'z': z, 'p_value': p_value, 'ci_95': ci,
        'significant': p_value < alpha
    }

# 예: 컨트롤 5000명 중 250명 전환, 실험 5000명 중 285명 전환
result = ab_test_proportion(250, 5000, 285, 5000)
print(f"컨트롤 전환율: {result['p_a']:.3f}")
print(f"실험 전환율:   {result['p_b']:.3f}")
print(f"차이: {result['diff']:.4f}")
print(f"95% CI: ({result['ci_95'][0]:.4f}, {result['ci_95'][1]:.4f})")
print(f"z = {result['z']:.3f}, p = {result['p_value']:.4f}")
print(f"결론: {'유의미' if result['significant'] else '유의미하지 않음'}")
```

## 검정의 가정과 위반

모든 검정에는 가정이 있고, 가정이 깨지면 결과를 신뢰할 수 없다.

| 가정 | 위반 시 | 대안 |
|------|--------|------|
| **정규성**: 데이터(또는 검정 통계량)가 정규분포 | p-value 부정확 | 비모수 검정, 부트스트랩 |
| **등분산**: 두 그룹의 분산이 같음 | Type I 오류 증가 | Welch's t-test |
| **독립성**: 관측값이 서로 독립 | SE 과소추정, 유의성 과대 | 대응 검정, 클러스터 보정 |
| **랜덤 표본**: 표본이 모집단을 대표 | 결과의 일반화 불가 | 실험 설계 재검토 |

n이 충분히 크면 CLT에 의해 정규성 가정은 자동으로 만족된다. 하지만 **독립성 위반은 n이 커도 해결되지 않는다**. 이것이 가장 위험한 위반이다.

ML에서 독립성이 깨지는 흔한 경우: 같은 사용자의 여러 세션, 같은 웨이퍼의 여러 다이, 시간적으로 인접한 데이터. 이런 데이터를 독립 t-검정에 넣으면 SE가 과소추정되어 유의미한 결과가 과대 보고된다.

## Python으로 확인하기

```python
import numpy as np
from scipy import stats

np.random.seed(42)

# 1. 세 가지 t-검정 비교
print("=== 세 가지 t-검정 ===\n")

# 단일 표본: 정확도가 0.80보다 높은가?
scores = np.array([0.83, 0.86, 0.84, 0.87, 0.85, 0.82, 0.86, 0.84])
t, p = stats.ttest_1samp(scores, 0.80)
print(f"단일 표본 t-검정 (vs 0.80): t={t:.3f}, p={p:.4f}")

# 독립 두 표본: 다른 데이터셋에서 두 모델
set_a = np.random.normal(0.84, 0.03, 20)
set_b = np.random.normal(0.87, 0.03, 20)
t, p = stats.ttest_ind(set_a, set_b, equal_var=False)  # Welch's
print(f"독립 두 표본 (Welch): t={t:.3f}, p={p:.4f}")

# 대응 표본: 같은 fold에서 두 모델
fold_a = np.array([0.83, 0.86, 0.84, 0.87, 0.85])
fold_b = np.array([0.85, 0.89, 0.86, 0.88, 0.87])
t, p = stats.ttest_rel(fold_a, fold_b)
print(f"대응 표본: t={t:.3f}, p={p:.4f}")

# 2. 대응 vs 독립: 검정력 차이
print(f"\n=== 대응 vs 독립 검정력 비교 ===")
n_sim = 10000
true_diff = 0.02
n_folds = 10

paired_sig, ind_sig = 0, 0
for _ in range(n_sim):
    # fold 난이도를 공유하는 상황
    fold_difficulty = np.random.normal(0.85, 0.05, n_folds)
    a = fold_difficulty + np.random.normal(0, 0.01, n_folds)
    b = fold_difficulty + true_diff + np.random.normal(0, 0.01, n_folds)
    
    _, p_paired = stats.ttest_rel(a, b)
    _, p_ind = stats.ttest_ind(a, b)
    
    if p_paired < 0.05: paired_sig += 1
    if p_ind < 0.05: ind_sig += 1

print(f"대응 검정 검정력: {paired_sig/n_sim:.1%}")
print(f"독립 검정 검정력: {ind_sig/n_sim:.1%}")
print(f"→ 대응 검정이 {paired_sig/max(ind_sig,1):.1f}배 강력!")

# 3. t-분포 vs 정규분포 비교
print(f"\n=== 95% 임계값: t vs z ===")
for df in [3, 5, 10, 30, 100]:
    t_crit = stats.t.ppf(0.975, df)
    print(f"df={df:>3}: t = {t_crit:.3f}  (z = 1.960)")
```

## 핵심 정리

- **σ를 모르면 t-검정, 알면 z-검정.** 실전에서는 거의 항상 t-검정이다.
- **t-분포는 정규분포보다 꼬리가 두껍다.** n이 작을수록 차이가 크다. "데이터가 적으면 더 강한 증거가 필요하다."
- **같은 데이터에서 모델 비교 = 대응 t-검정.** 독립 t-검정을 쓰면 검정력이 수 배 떨어진다.
- **등분산을 모르겠으면 Welch's t-test**를 써라. `equal_var=False`가 항상 안전하다.
- **A/B 테스트에서 비율 비교는 z-검정.** 이항 비율의 SE 공식이 다르다.
- **독립성 위반이 가장 위험한 가정 위반이다.** n이 커도 해결 안 된다.
