# 6.4 차원의 저주 — 고차원에서 직관이 무너지는 이유

## 이 챕터에서 배우는 것

- 차원이 높아지면 "거리", "이웃", "부피"의 의미가 왜 무너지는지
- KNN이 고차원에서 실패하는 수학적 이유
- 피처가 많을수록 필요한 데이터가 기하급수적으로 늘어나는 현상
- 차원 축소와 피처 선택이 단순한 "전처리"가 아닌 이유

---

## 고차원에서 일어나는 반직관적 현상

### 1. 모든 점이 "멀어진다"

2차원에서 단위 정사각형 안에 랜덤하게 점 두 개를 찍으면, 평균 거리는 약 0.52. 100차원에서 단위 초입방체 안에 랜덤 점 두 개를 찍으면, 평균 거리는 약 4.08.

더 중요한 것: **최대 거리와 최소 거리의 비율이 1에 수렴한다.**

$$\frac{d_{\max} - d_{\min}}{d_{\min}} \to 0 \quad \text{as dimension} \to \infty$$

모든 점이 비슷한 거리에 있게 된다. "가장 가까운 이웃"과 "가장 먼 이웃"의 구분이 무의미해진다. KNN이 고차원에서 망하는 근본 이유다.

```python
import numpy as np

for dim in [2, 10, 50, 100, 500]:
    points = np.random.uniform(0, 1, (1000, dim))

```

### 2. 부피가 "껍데기"에 몰린다

고차원 구의 부피는 대부분 표면 근처에 집중된다. $d$차원에서 반지름 $R$인 구의 부피는 $V_d \propto R^d$이다. 따라서 단위 구(반지름 1) 안에서 반지름 $r = 0.9$ 이내 영역이 차지하는 부피 비율은:

$$\frac{V_d(r=0.9)}{V_d(r=1.0)} = \left(\frac{0.9}{1.0}\right)^d = 0.9^d$$

$d = 100$이면 $0.9^{100} \approx 0.0000266$. 부피의 99.997%가 반지름 0.9~1.0 사이의 얇은 껍데기에 있다.

![차원의 저주](/content/images/stats/06_04/curse_dimensionality.svg)

### 3. 필요 데이터가 기하급수적으로 늘어난다

1차원에서 구간을 10등분하려면 10개의 데이터면 충분. 2차원이면 $10^2 = 100$. $d$차원이면 $10^d$. 50차원이면 $10^{50}$개 — 우주의 원자 수보다 많다.

이것이 **차원의 저주(Curse of Dimensionality)**의 본질. 고차원 공간은 상상 이상으로 "비어" 있다.

현실의 데이터가 얼마나 고차원인지 감을 잡아두자. 텍스트를 TF-IDF로 벡터화하면 어휘 크기만큼의 차원이 되어 수만~수십만 차원이 흔하다. 이미지는 픽셀 수가 곧 차원이다 — 224×224 컬러 이미지라면 $224 \times 224 \times 3 = 150{,}528$차원. 유전체 데이터는 수십만 개의 SNP를 피처로 쓴다. 이런 원시 차원에서 거리 기반 모델을 바로 적용하는 것은 차원의 저주에 정면으로 부딪히는 것이다. 임베딩이나 차원 축소를 먼저 거치는 이유가 여기 있다.

## ML에서의 영향

### 거리 기반 모델의 붕괴

KNN, SVM(RBF 커널), 클러스터링(k-means) 등 거리에 의존하는 모델은 고차원에서 성능이 급격히 저하된다. KNN을 예로 들면: 위에서 본 것처럼 모든 점 사이의 거리가 비슷해지면, "가장 가까운 k개"가 사실상 랜덤 선택이 된다. 이웃이 의미 있으려면 "가까운 이웃은 진짜 가깝고, 먼 이웃은 진짜 멀어야" 하는데, 고차원에서는 이 대비가 사라진다. 또한 고차원에서 k개 이웃을 확보하려면 훨씬 넓은 반경을 탐색해야 하므로, 이웃이 "지역적(local)"이라는 가정 자체가 깨진다.

### 과적합 위험 증가

피처가 많을수록 모델이 노이즈에 맞출 수 있는 "자유도"가 늘어난다. 4.5의 편향-분산에서 봤듯이 분산이 폭발.

### 대응 전략

| 전략 | 방법 | Part 연결 |
|------|------|----------|
| 피처 선택 | Lasso, MI, 카이제곱 | 1.4, 3.5, 4.4 |
| 차원 축소 | PCA, t-SNE, UMAP | 1.4 (공분산) |
| 정규화 | L1/L2, Dropout | 4.4 |
| 도메인 지식 | 물리적으로 관련된 피처만 사용 | 전체 |

## Python으로 확인하기

```python
import numpy as np
from scipy.spatial.distance import cdist

np.random.seed(42)

# 1. 껍데기에 집중되는 부피
print("=== 껍데기에 집중되는 부피 ===")
for d in [2, 10, 50, 100, 500]:
    ratio = 0.9 ** d
    print(f"d={d:>3}: 반지름 0.9 이내 부피 비율 = {ratio:.6f} ({ratio*100:.4f}%)")

# 2. KNN 정확도 vs 차원
# 진짜 결정 경계: 처음 2개 피처에만 의존. 나머지는 노이즈.
print(f"\n=== KNN 정확도 vs 차원 (신호: 2차원, 나머지: 노이즈) ===")
for d in [2, 5, 10, 50, 100]:
    n_train, n_test = 500, 200
    X_train = np.random.randn(n_train, d)
    y_train = (X_train[:, 0] + X_train[:, 1] > 0).astype(int)
    X_test = np.random.randn(n_test, d)
    y_test = (X_test[:, 0] + X_test[:, 1] > 0).astype(int)

    # 1-NN
    dists = cdist(X_test, X_train)
    nn_idx = dists.argmin(axis=1)
    y_pred = y_train[nn_idx]
    acc = (y_pred == y_test).mean()

    contrast = (dists.max(axis=1) - dists.min(axis=1)).mean() / dists.min(axis=1).mean()
    print(f"d={d:>3}: 1-NN 정확도={acc:.1%}, "
          f"거리 대비(max-min)/min={contrast:.2f}")
```

## 핵심 정리

- **고차원에서 모든 점이 "비슷하게 멀다."** 거리 기반 모델이 무력화된다.
- **부피가 껍데기에 집중.** 데이터가 공간을 채우려면 $10^d$개 필요. 현실적으로 불가능.
- **피처를 무작정 추가하면 분산이 폭발한다.** 피처 선택과 차원 축소는 "있으면 좋은 것"이 아니라 필수.
- **해결책: 피처 선택 + 정규화 + 차원 축소.** 이 핸드북에서 배운 도구들이 종합적으로 쓰이는 곳.
