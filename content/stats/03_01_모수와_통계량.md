# 3.1 모수와 통계량 — population vs sample, 왜 n-1로 나누는가

## 이 챕터에서 배우는 것

- 모집단(population)과 표본(sample)의 구분이 왜 추론의 출발점인지
- 모수(parameter)와 통계량(statistic)의 차이 — 하나는 신의 영역, 하나는 우리의 영역
- 좋은 추정량의 세 가지 성질: 불편성, 일치성, 효율성
- 1.2에서 남긴 숙제: "왜 n-1인가"의 완전한 답

---

## 추론의 근본 문제

ML 엔지니어가 매일 하는 일을 한 줄로 요약하면:

> **"가진 데이터(표본)로 아직 보지 못한 데이터(모집단)에 대해 추측한다."**

테스트셋에서 정확도가 85%였다. 프로덕션에 나가면 몇 %일까? 이 질문에 답하려면, "테스트셋(표본)의 85%"로 "모든 가능한 입력(모집단)에서의 성능"을 추론해야 한다.

이것이 **통계적 추론(statistical inference)**의 핵심 문제다. Part 3 전체가 이 문제를 다루는 도구를 쌓는 과정이다.

---

## 모집단과 표본

**모집단(Population)**: 관심의 대상이 되는 전체 집합. 모든 가능한 입력, 모든 가능한 웨이퍼, 모든 가능한 사용자. 대부분의 경우 직접 관측할 수 없다.

**표본(Sample)**: 모집단에서 뽑은 부분집합. 우리가 실제로 가지고 있는 데이터.

| | 모집단 | 표본 |
|--|--------|------|
| 크기 | $N$ (보통 무한 또는 매우 큼) | $n$ (유한) |
| 관측 가능? | 보통 불가능 | 가능 |
| ML에서 | 모든 가능한 데이터 | 학습/테스트 데이터셋 |

핵심 가정: **표본이 모집단을 대표한다.** 이 가정이 성립하려면 표본이 모집단에서 **무작위로** 뽑혀야 한다. 편향된 방식으로 뽑으면 — 예를 들어 주간 데이터만 모아서 야간 성능을 추론하면 — 추론이 틀어진다.

ML에서 이 문제가 구체적으로 나타나는 곳:

- **학습 데이터가 프로덕션 데이터를 대표하는가?** 대표하지 않으면 분포 이동(distribution shift)
- **테스트셋이 충분히 대표적인가?** 특정 클래스가 과소 표현되면 성능 평가가 왜곡
- **교차검증의 fold가 독립적인가?** 시간순 데이터를 랜덤으로 나누면 미래 정보 유출

---

## 모수와 통계량

**모수(Parameter)**: 모집단의 특성을 나타내는 고정된 값. 보통 그리스 문자로 표기.
- $\mu$ = 모평균
- $\sigma^2$ = 모분산
- $p$ = 모비율

**통계량(Statistic)**: 표본에서 계산한 값. 모수의 추정에 쓰인다.
- $\bar{x}$ = 표본평균 → $\mu$를 추정
- $s^2$ = 표본분산 → $\sigma^2$를 추정
- $\hat{p}$ = 표본비율 → $p$를 추정

핵심 차이: **모수는 상수이고, 통계량은 확률변수다.**

모수 $\mu$는 모집단이 정해지면 하나의 고정된 값이다. 우리가 모를 뿐이다. 반면 통계량 $\bar{x}$는 표본을 다시 뽑으면 다른 값이 나온다. 표본에 의존하는 확률변수다.

> 💡 **ML에서의 대응**: 모수는 데이터 생성 과정(DGP)의 진짜 파라미터이고, 통계량은 학습된 모델의 가중치다. `model.coef_`는 매번 학습할 때마다 (데이터 셔플, 초기화에 따라) 달라질 수 있다. 모수는 하나이고, 그것의 추정값은 학습할 때마다 달라진다.

---

## 추정량의 세 가지 성질

통계량이 모수를 "잘" 추정하는지를 판단하는 기준이 세 가지 있다. ML에서 모델을 평가하는 것과 구조가 같다.

### 1. 불편성 (Unbiasedness): 평균적으로 맞히는가

$$E[\hat{\theta}] = \theta$$

추정량의 기댓값이 진짜 모수와 같으면 **불편추정량(unbiased estimator)**이라 한다. "여러 번 반복하면 평균적으로 정답에 맞는다." 이 성질을 달성하기 위해 분모를 조정하는 것이 바로 **자유도(degrees of freedom)** 개념이다 — 아래 "왜 n-1로 나누는가" 섹션에서 본격적으로 다룬다.

표본평균 $\bar{X}$는 모평균 $\mu$의 불편추정량이다:

$$E[\bar{X}] = E\left[\frac{1}{n}\sum_{i=1}^n X_i\right] = \frac{1}{n}\sum_{i=1}^n E[X_i] = \frac{1}{n} \cdot n\mu = \mu$$

기댓값의 선형성(2.2)을 쓰면 한 줄로 증명된다.

### 2. 일치성 (Consistency): 데이터가 많아지면 맞히는가

$$\hat{\theta}_n \xrightarrow{P} \theta \quad \text{as } n \to \infty$$

표본 크기가 커지면 추정량이 모수에 수렴한다. 표본평균의 경우, 이것은 LLN(2.6)의 직접적인 결과다.

불편성과 일치성은 다른 성질이다. 불편이지만 일치적이지 않은 추정량도 있고 (드물지만), 편향이 있지만 일치적인 추정량도 있다 (흔하다). 실무적으로는 **일치성이 더 중요**하다 — 데이터를 많이 모으면 결국 맞힌다는 보장.

### 3. 효율성 (Efficiency): 얼마나 정밀하게 맞히는가

같은 모수를 추정하는 두 불편추정량이 있을 때, 분산이 작은 쪽이 더 **효율적**이다.

$$\text{Var}(\hat{\theta}_1) < \text{Var}(\hat{\theta}_2) \quad \Rightarrow \quad \hat{\theta}_1\text{이 더 효율적}$$

예를 들어, 모평균 $\mu$를 추정할 때 표본평균과 표본중앙값 모두 불편추정량이다 (정규분포 가정 시). 하지만 표본평균의 분산이 더 작다. 그래서 정규분포 데이터에서는 평균이 중앙값보다 효율적인 추정량이다.

하지만! 이상치가 있으면 이야기가 달라진다. 1.1에서 봤듯이 평균은 이상치에 끌려가므로 편향이 생긴다. 중앙값은 이상치에 강건하므로 편향이 작다. **효율성과 강건성은 트레이드오프**다. 이유는 간단하다: 효율적인 추정량일수록 모든 데이터 포인트를 "빠짐없이" 활용하는데, 그만큼 이상치 하나의 영향도 고스란히 받기 때문이다.

![추정량 과녁 비유](/content/images/stats/03_01/estimator_target_board.svg)

ML에서 이 세 성질의 대응:

| 추정량의 성질 | ML 대응 |
|-------------|---------|
| 불편성 (평균적으로 맞힘) | 모델의 편향(bias)이 낮음 |
| 효율성 (흩어짐이 적음) | 모델의 분산(variance)이 낮음 |
| 일치성 (데이터 많으면 수렴) | 데이터 늘리면 성능 향상 |

이것이 Part 4.5에서 다룰 **편향-분산 트레이드오프**의 통계적 기원이다.

## 왜 n-1로 나누는가: 완전한 답

1.2에서 베셀 보정을 다뤘고, "표본 평균이 표본에 맞춰져 있어서 분산이 과소추정된다"는 직관을 줬다. 이제 이 직관을 엄밀하게 완성한다.

### 자유도 (Degrees of Freedom)

$n$개의 데이터가 있을 때, 표본 평균 $\bar{x}$를 먼저 계산했다고 하자. 이 시점에서 데이터에 하나의 **제약 조건**이 걸린다:

$$\sum_{i=1}^n (x_i - \bar{x}) = 0$$

편차의 합은 항상 0이다. 이것은 $\bar{x}$의 정의에서 자동으로 따라오는 성질이다.

이 제약 때문에, $n$개의 편차 $(x_1 - \bar{x}), (x_2 - \bar{x}), \ldots, (x_n - \bar{x})$ 중 $n-1$개만 "자유롭게" 결정되면 나머지 하나는 자동으로 결정된다. 자유롭게 변할 수 있는 값의 수가 **자유도(degrees of freedom, df) = n - 1**이다.

### 불편성 증명

$s^2 = \frac{1}{n-1}\sum(x_i - \bar{x})^2$가 $\sigma^2$의 불편추정량임을 보이자.

$$E\left[\sum_{i=1}^n (X_i - \bar{X})^2\right] = E\left[\sum_{i=1}^n X_i^2 - n\bar{X}^2\right]$$

<details>
<summary>🔬 Deep Dive — 불편성의 전체 유도</summary>

$\sum(X_i - \bar{X})^2$를 전개한다:

$$\sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n X_i^2 - n\bar{X}^2$$

기댓값을 취한다. $E[X_i^2] = \text{Var}(X_i) + (E[X_i])^2 = \sigma^2 + \mu^2$이고, $E[\bar{X}^2] = \text{Var}(\bar{X}) + (E[\bar{X}])^2 = \sigma^2/n + \mu^2$이므로:

$$E\left[\sum X_i^2 - n\bar{X}^2\right] = n(\sigma^2 + \mu^2) - n(\sigma^2/n + \mu^2)$$
$$= n\sigma^2 + n\mu^2 - \sigma^2 - n\mu^2 = (n-1)\sigma^2$$

따라서:

$$E\left[\frac{1}{n-1}\sum(X_i - \bar{X})^2\right] = \frac{(n-1)\sigma^2}{n-1} = \sigma^2$$

$n-1$로 나눠야 정확히 $\sigma^2$가 나온다. $n$으로 나누면 $\frac{n-1}{n}\sigma^2$가 나와서 **항상 과소추정**한다.

핵심: 표본 평균 $\bar{X}$를 사용하면서 자유도를 1 잃었기 때문에, 분모에서 1을 빼서 보상하는 것이다. 이것이 자유도의 수학적 실체다.

</details>

$n-1$로 나누면 $E[s^2] = \sigma^2$. 즉, **표본분산 $s^2$는 모분산 $\sigma^2$의 불편추정량**이다.

$n$으로 나누면? $E\left[\frac{1}{n}\sum(X_i-\bar{X})^2\right] = \frac{n-1}{n}\sigma^2 < \sigma^2$. 항상 과소추정한다. 이것이 1.2에서 예고했던 답의 완성이다.

### 실무적으로 언제 신경 써야 하는가

| 상황 | n으로 나누나? n-1로 나누나? | 이유 |
|------|------------------------|------|
| 교차검증 fold가 5개 | **n-1** | n이 작으므로 차이가 크다 |
| 실험 반복이 10회 | **n-1** | 같은 이유 |
| 데이터 100만 개의 분산 | 상관없음 | $n/(n-1) \approx 1$ |
| BatchNorm의 분산 계산 | 학습 시 n, 추론 시 n-1 | PyTorch 기본 동작 |

```python
# PyTorch BatchNorm의 동작
import torch.nn as nn

bn = nn.BatchNorm1d(10)
# 학습 시: batch의 분산을 n으로 계산 (편향 있지만 gradient 계산에 유리)
# 추론 시: running_var는 Bessel 보정 적용 (불편 추정)
```

## 통계량의 표본 분포

통계량이 확률변수라면, 그것도 분포를 갖는다. 이 분포를 **표본 분포(sampling distribution)**라 한다.

표본 평균 $\bar{X}$의 표본 분포는 CLT(2.5)가 알려준다:

$$\bar{X} \sim N\left(\mu, \frac{\sigma^2}{n}\right) \quad \text{(n이 충분히 크면)}$$

이 표본 분포가 Part 3의 나머지 전체를 관통하는 핵심 도구다.

- **3.2 (신뢰구간)**: 표본 분포의 폭으로 추정의 불확실성을 표현
- **3.3 (가설검정)**: 표본 분포에서 관측값이 얼마나 극단적인지 측정
- **3.4 (t-검정)**: $\sigma$를 모를 때 $s$로 대체하면 표본 분포가 t-분포로 바뀜

표본 분포를 이해하지 않으면 신뢰구간과 p-value를 올바르게 해석할 수 없다. 3.2로 넘어가기 전에 이 개념을 확실히 잡아야 한다.

---

## Python으로 확인하기

```python
import numpy as np

np.random.seed(42)

# 모집단 설정 (실제로는 모름)
true_mu = 100
true_sigma = 15

# 1. 불편성 확인: 여러 표본에서 추정량의 기댓값
n = 10
n_experiments = 100000

sample_means = []
sample_vars_n = []      # n으로 나눈 분산
sample_vars_n1 = []     # n-1로 나눈 분산

for _ in range(n_experiments):
    sample = np.random.normal(true_mu, true_sigma, n)
    sample_means.append(sample.mean())
    sample_vars_n.append(sample.var(ddof=0))    # n
    sample_vars_n1.append(sample.var(ddof=1))   # n-1

print(f"=== 불편성 확인 (n={n}, {n_experiments}회 반복) ===")
print(f"E[X̄] = {np.mean(sample_means):.2f}  (μ = {true_mu})")
print(f"E[s²(n)]   = {np.mean(sample_vars_n):.2f}  (σ² = {true_sigma**2})")
print(f"E[s²(n-1)] = {np.mean(sample_vars_n1):.2f}  (σ² = {true_sigma**2})")
print(f"→ n으로 나누면 {true_sigma**2 - np.mean(sample_vars_n):.2f}만큼 과소추정")

# 2. 자유도 직관: 편차의 합 = 0
sample = np.random.normal(true_mu, true_sigma, 5)
deviations = sample - sample.mean()
print(f"\n=== 자유도 직관 ===")
print(f"데이터: {sample.round(1)}")
print(f"편차:   {deviations.round(4)}")
print(f"편차의 합: {deviations.sum():.10f}  (항상 0!)")

# 3. 표본 분포: 표본 평균의 분포는 정규
from scipy import stats
print(f"\n=== 표본 평균의 표본 분포 ===")
print(f"이론: N({true_mu}, {true_sigma**2/n:.1f})")
print(f"실제: 평균={np.mean(sample_means):.2f}, 분산={np.var(sample_means):.2f}")
_, p_shapiro = stats.shapiro(np.random.choice(sample_means, 500))
print(f"정규성 (Shapiro p-value): {p_shapiro:.4f}")
```

## 핵심 정리

- **모집단은 알 수 없고, 표본만 볼 수 있다.** 추론의 근본 문제. 표본이 모집단을 대표한다는 가정이 깨지면 모든 추론이 틀어진다.
- **모수는 상수, 통계량은 확률변수다.** 모수는 신의 영역, 통계량은 데이터를 바꿀 때마다 달라진다.
- **좋은 추정량의 세 가지**: 불편(평균적으로 맞힘), 일치(데이터 많으면 수렴), 효율(흩어짐 적음). 효율성과 강건성은 트레이드오프.
- **n-1로 나누는 이유**: 표본 평균으로 자유도를 1 잃었기 때문. $n-1$로 나눠야 분산의 불편추정량. $n$이 작을 때 중요하다.
- **표본 분포가 Part 3의 핵심 도구다.** 신뢰구간, 가설검정, p-value가 전부 표본 분포 위에 서 있다.
