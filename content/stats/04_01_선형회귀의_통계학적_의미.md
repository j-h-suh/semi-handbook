# 4.1 선형회귀의 통계학적 의미 — OLS는 왜 "최소제곱"인가

## 이 챕터에서 배우는 것

- `LinearRegression().fit()`이 내부적으로 풀고 있는 최적화 문제의 정체
- OLS 추정량이 "최고의 추정량"인 조건 — 가우스-마르코프 정리
- 회귀 계수도 확률변수다 — 신뢰구간과 가설검정이 가능한 이유
- R²의 재방문: 1.4에서 심었던 복선을 회수한다

---

## sklearn 한 줄 뒤에서 벌어지는 일

```python
from sklearn.linear_model import LinearRegression
model = LinearRegression()
model.fit(X, y)
```

이 세 줄이 내부적으로 풀고 있는 문제:

$$\hat{\beta} = \arg\min_{\beta} \sum_{i=1}^{n} (y_i - \beta_0 - \beta_1 x_{i1} - \cdots - \beta_p x_{ip})^2$$

잔차 제곱합(RSS)을 최소화하는 계수 $\beta$를 찾는다. 이것이 **최소제곱법(Ordinary Least Squares, OLS)**이다.

왜 "제곱"인가? 2.4에서 답을 이미 봤다. **잔차가 정규분포를 따른다고 가정하면, MSE 최소화 = 우도 최대화(MLE)**다. "제곱"을 쓰는 것은 정규 노이즈 가정의 자연스러운 결과다.

### 닫힌 형태의 해

선형회귀는 ML에서 드물게 **닫힌 형태(closed-form)**의 해를 갖는다. 닫힌 형태란 반복적 최적화 없이 유한한 수학 연산(덧셈, 곱셈, 역행렬 등)만으로 정확한 해를 한 번에 구할 수 있다는 뜻이다. 경사하강법이 필요 없다.

행렬 표기로:

$$\hat{\beta} = (X^T X)^{-1} X^T y$$

이 공식은 RSS를 $\beta$에 대해 미분하고 0으로 놓으면 나온다.

<details>
<summary>🔬 Deep Dive — OLS 해의 유도</summary>

행렬 표기에서 모델: $y = X\beta + \epsilon$

RSS:

$$\text{RSS}(\beta) = (y - X\beta)^T(y - X\beta) = y^Ty - 2\beta^TX^Ty + \beta^TX^TX\beta$$

$\beta$에 대해 미분하고 0으로 놓으면:

$$\frac{\partial \text{RSS}}{\partial \beta} = -2X^Ty + 2X^TX\beta = 0$$

$$X^TX\beta = X^Ty$$

$$\hat{\beta} = (X^TX)^{-1}X^Ty$$

이것이 **정규방정식(normal equation)**이다. "normal"은 정규분포가 아니라 "직교(perpendicular)"라는 뜻이다 — 잔차 벡터 $(y - X\hat{\beta})$가 $X$의 열공간에 직교한다는 기하학적 의미에서.

$X^TX$가 역행렬을 가지려면 $X$의 열들이 선형 독립이어야 한다. 완벽한 다중공선성이 있으면 $(X^TX)^{-1}$이 존재하지 않아 OLS 해가 유일하지 않다. 이것이 4.2에서 다룰 다중공선성 문제의 수학적 근원이다.

</details>

### 기하학적 직관

OLS가 하는 일을 기하학적으로 보면: $y$를 $X$의 열공간에 **정사영(projection)**하는 것이다. $\hat{y} = X\hat{\beta}$는 $X$의 열들의 선형 결합으로 표현 가능한 벡터 중에서 $y$에 가장 가까운 것이다. 잔차 $e = y - \hat{y}$는 $X$의 열공간에 직교한다.

![OLS 시각화](/content/images/stats/04_01/ols_fit_visualizer.svg)

이 직관이 왜 유용한가? "왜 잔차의 합이 0인지"(정사영의 성질), "왜 잔차와 예측값이 상관이 없는지"(직교), "왜 R²가 cos²θ와 같은지"(각도)가 전부 이 그림에서 나온다.

---

## 가우스-마르코프 정리: OLS가 "최고"인 조건

OLS 추정량이 특별한 이유를 설명하는 것이 **가우스-마르코프 정리(Gauss-Markov Theorem)**다.

> **가정 (GM 조건):**
> 1. 모델이 올바르게 설정됨: $E[y \mid X] = X\beta$ (선형)
> 2. $E[\epsilon] = 0$ (오차의 기댓값이 0)
> 3. $\text{Var}(\epsilon_i) = \sigma^2$ for all $i$ (등분산, homoscedasticity)
> 4. $\text{Cov}(\epsilon_i, \epsilon_j) = 0$ for $i \neq j$ (오차 간 무상관)

> **결론:**
> 이 가정 하에서 OLS 추정량 $\hat{\beta}$는 모든 선형 불편추정량 중 **분산이 가장 작다** (= 가장 효율적이다).

이것을 줄여서 **BLUE (Best Linear Unbiased Estimator)**라 한다.

각 가정이 뜻하는 것과 깨졌을 때의 영향:

| 가정 | 깨지면 | ML에서 흔한 상황 |
|------|--------|----------------|
| 선형성 | $\hat{\beta}$이 편향됨 | 비선형 관계를 선형으로 피팅 |
| 오차 기댓값 0 | $\hat{\beta}$이 편향됨 | 누락 변수, 잘못된 함수 형태 |
| 등분산 | $\hat{\beta}$은 불편이지만 SE 추정이 틀림 | 예측값이 커질수록 오차도 커지는 경우 |
| 무상관 | $\hat{\beta}$은 불편이지만 SE 과소추정 | 시계열, 공간 데이터 |

정규분포 가정은 가우스-마르코프에 **포함되지 않는다.** 정규성은 "BLUE" 성질에는 필요 없다. 하지만 가설검정과 신뢰구간에는 필요하다 — 또는 n이 충분히 크면 CLT가 대신해 준다.

---

## 회귀 계수는 확률변수다

3.1에서 배웠다: 통계량은 확률변수다. 회귀 계수 $\hat{\beta}$도 마찬가지다. 데이터를 다시 뽑으면 다른 값이 나온다. 따라서 $\hat{\beta}$도 **분포를 갖고, 신뢰구간과 가설검정이 가능하다.** 3.1에서 표본평균 $\bar{X}$의 표본분포를 다뤘는데, 회귀 계수도 정확히 같은 논리다 — 표본에서 계산한 통계량이므로 불확실성이 있고, 그 불확실성을 표준오차로 정량화할 수 있다.

$$\hat{\beta}_j \sim N\left(\beta_j, \; \sigma^2 (X^TX)^{-1}_{jj}\right)$$

각 계수의 표준오차:

$$\text{SE}(\hat{\beta}_j) = s \cdot \sqrt{(X^TX)^{-1}_{jj}}$$

여기서 $s$는 잔차의 표준편차 추정값.

### 계수의 t-검정

"이 피처가 타겟에 영향을 주는가?"를 검정할 수 있다.

$$H_0: \beta_j = 0 \quad (\text{이 피처는 효과 없음})$$

$$t = \frac{\hat{\beta}_j}{\text{SE}(\hat{\beta}_j)}, \quad t \sim t(n-p-1)$$

```python
import statsmodels.api as sm

X_with_const = sm.add_constant(X)
model = sm.OLS(y, X_with_const).fit()
print(model.summary())
```

`summary()`의 출력에서 각 계수 옆의 `t`와 `P>|t|`가 바로 이 검정이다. p-value가 작으면 그 피처가 "유의미하게" 타겟과 관련이 있다.

> 💡 **sklearn은 이 정보를 주지 않는다.** `LinearRegression`은 계수만 반환할 뿐, 표준오차, t-값, p-value를 제공하지 않는다. 통계적 추론이 필요하면 `statsmodels`를 쓰라. 이것이 ML 라이브러리와 통계 라이브러리의 철학적 차이다 — sklearn은 예측 중심, statsmodels는 추론 중심.

### 전체 모델의 F-검정

3.5에서 ANOVA의 F-통계량을 배웠다. 회귀에서도 같은 논리가 적용된다:

$$H_0: \beta_1 = \beta_2 = \cdots = \beta_p = 0 \quad (\text{어떤 피처도 효과 없음})$$

$$F = \frac{SS_{reg}/p}{SS_{res}/(n-p-1)} = \frac{MSR}{MSE}$$

여기서 $SS_{reg} = SS_{tot} - SS_{res}$는 회귀가 설명하는 변동, $SS_{res}$는 잔차 변동이다.

이것이 `model.summary()`의 맨 위에 나오는 F-statistic이다.

## R² 재방문

1.4에서 R²의 함정을 다뤘다. 이제 회귀의 맥락에서 R²를 정식으로 정의한다.

$$R^2 = 1 - \frac{SS_{res}}{SS_{tot}} = 1 - \frac{\sum(y_i - \hat{y}_i)^2}{\sum(y_i - \bar{y})^2}$$

- $SS_{tot}$: 타겟의 전체 변동. "아무 예측도 안 하고 평균만 쓸 때의 오차."
- $SS_{res}$: 잔차 변동. "모델을 쓸 때 남는 오차."
- $R^2$: 모델이 설명하는 변동의 비율.

R² = 0.85면, 타겟 변동의 85%를 모델이 설명하고, 15%는 설명하지 못한다.

### R²의 함정: 회귀 맥락

1.4에서 "피어슨 r은 선형만 본다"고 했다. 단순 회귀에서 $R^2 = r^2$이므로, **R²도 선형 관계의 강도만 반영한다.**

하지만 다중 회귀에서는 상황이 더 복잡해진다:

**문제 1: 피처를 추가하면 R²는 항상 증가한다.** 심지어 무관한 피처를 넣어도. 피처 수 $p$가 $n$에 가까워지면 R² → 1이 된다. 극단적으로 $p = n$이면 R² = 1이 되지만, 과적합의 극치다.

이 문제를 보정한 것이 **조정된 R² (Adjusted R²)**:

$$R^2_{adj} = 1 - \frac{SS_{res}/(n-p-1)}{SS_{tot}/(n-1)} = 1 - \frac{n-1}{n-p-1}(1-R^2)$$

무관한 피처를 추가하면 $R^2_{adj}$가 오히려 감소할 수 있다. 피처 수에 대한 벌칙이 내장되어 있다.

**문제 2: R²가 높다고 모델이 좋은 것은 아니다.** R² = 0.95인데 잔차에 패턴이 남아 있으면, 모델이 데이터의 구조를 제대로 잡지 못한 것이다. 실무 예시: 집값 예측에서 면적만 넣고 R² = 0.85를 얻었다. 좋아 보이지만, 잔차를 그려보니 고가 주택일수록 잔차가 체계적으로 양수다 — 위치(강남/비강남)라는 누락 변수가 있는 것이다. R²만 보면 이 문제를 놓친다. 4.2에서 이 진단을 다룬다.

**문제 3: R²가 낮다고 모델이 나쁜 것은 아니다.** 타겟 자체의 변동성이 크면(노이즈가 많으면) R²가 낮을 수밖에 없다. 중요한 것은 R²의 절대값이 아니라 "이 모델이 다른 모델보다 나은가?"다.

---

## 선형회귀의 가정 요약

지금까지 배운 것을 정리하면, 선형회귀가 통계적으로 올바르게 작동하려면:

**1. 선형성**: $E[y \mid X] = X\beta$. 타겟과 피처의 관계가 선형.

**2. 독립성**: 관측값들이 서로 독립.

**3. 등분산성(Homoscedasticity)**: 잔차의 분산이 일정. $\text{Var}(\epsilon_i) = \sigma^2$.

**4. 정규성**: 잔차가 정규분포. $\epsilon \sim N(0, \sigma^2)$. (가설검정에 필요)

**5. 다중공선성 없음**: 피처들이 서로 강하게 상관되지 않음.

이 가정들을 확인하는 방법이 4.2의 주제다.

---

## 선형회귀를 "넘어서는" 모델의 의미

"현실이 선형이 아닌데 왜 선형회귀를 배우는가?"

두 가지 이유가 있다.

**첫째, 선형회귀는 모든 회귀의 기준선(baseline)이다.** 어떤 복잡한 모델을 쓰든, "선형회귀보다 얼마나 나은가?"로 가치를 판단한다. 기준선을 모르면 비교가 안 된다.

**둘째, 비선형 모델도 통계적 프레임워크는 같다.** 로지스틱 회귀(4.3), 정규화(4.4), 편향-분산(4.5)은 전부 선형회귀의 프레임워크를 확장한 것이다. 선형회귀의 통계적 의미를 이해하면, 비선형 모델에서도 "이 모델이 무엇을 가정하고 있는가?"를 물을 수 있게 된다.

## Python으로 확인하기

```python
import numpy as np
import statsmodels.api as sm
from sklearn.linear_model import LinearRegression

np.random.seed(42)

# 데이터 생성: y = 3x1 + 1.5x2 + 0*x3 + noise
n = 100
X = np.random.normal(0, 1, (n, 3))
y = 3*X[:, 0] + 1.5*X[:, 1] + 0*X[:, 2] + np.random.normal(0, 1, n)

# 1. sklearn vs statsmodels
print("=== sklearn ===")
sk_model = LinearRegression().fit(X, y)
print(f"계수: {sk_model.coef_.round(3)}")
print(f"R²: {sk_model.score(X, y):.4f}")
print("(표준오차, p-value 없음)\n")

print("=== statsmodels ===")
X_const = sm.add_constant(X)
sm_model = sm.OLS(y, X_const).fit()
print(sm_model.summary().tables[1])

# 2. R² vs Adjusted R²: 무관한 피처 추가
print(f"\n=== R² vs Adjusted R² ===")
for n_noise_features in [0, 5, 20, 50]:
    X_aug = np.hstack([X, np.random.normal(0, 1, (n, n_noise_features))])
    X_aug_const = sm.add_constant(X_aug)
    model = sm.OLS(y, X_aug_const).fit()
    print(f"피처 {3+n_noise_features}개: R²={model.rsquared:.4f}, "
          f"Adj R²={model.rsquared_adj:.4f}")

# 3. 회귀 계수의 표본 분포 시뮬레이션
print(f"\n=== β₁의 표본 분포 (진짜 β₁ = 3.0) ===")
beta1_estimates = []
for _ in range(1000):
    X_sim = np.random.normal(0, 1, (n, 3))
    y_sim = 3*X_sim[:, 0] + 1.5*X_sim[:, 1] + np.random.normal(0, 1, n)
    model = LinearRegression().fit(X_sim, y_sim)
    beta1_estimates.append(model.coef_[0])

beta1_arr = np.array(beta1_estimates)
print(f"E[β̂₁] = {beta1_arr.mean():.4f} (불편: 진짜 값 3.0에 가까움)")
print(f"SE(β̂₁) = {beta1_arr.std():.4f}")
print(f"95% 범위: ({np.percentile(beta1_arr, 2.5):.3f}, "
      f"{np.percentile(beta1_arr, 97.5):.3f})")
```

## 핵심 정리

- **OLS = 잔차 제곱합 최소화 = 정규 노이즈 하의 MLE.** 제곱을 쓰는 이유는 정규분포 가정에서 자연스럽게 나온다.
- **가우스-마르코프: OLS는 GM 가정 하에서 BLUE.** 선형 불편추정량 중 분산이 가장 작다. 가정이 깨지면 이 보장이 사라진다.
- **회귀 계수는 확률변수다.** 표준오차, 신뢰구간, t-검정이 가능하다. `statsmodels`를 써서 통계적 추론을 하라.
- **R²는 피처를 추가하면 항상 증가한다.** Adjusted R²로 보정하라. R²가 높아도 잔차에 패턴이 있으면 모델이 부족하다.
- **sklearn은 예측 도구, statsmodels는 추론 도구.** 둘 다 필요하다.
