# 0.3 환경과 첫 호출 — 설치 · Vertex 인증 · `query()` 한 줄

## 이 챕터에서 배우는 것

- SDK를 설치하는 법 — `uv add`로 의존성에 박기
- Vertex AI로 인증하는 법 — 환경 변수와 ADC
- 첫 `query()` 한 줄을 돌려 *엔진이 돈다*를 확인하는 법
- 시동을 거는 것과 운전하는 것은 다르다는 것 (Part 1로 가는 다리)

---

## 차에 올라 시동을 건다

0.2에서 우리는 탈것을 골랐다 — 내가 모는 차, Agent SDK. 이제 차에 올라 시동을 걸 차례다. 설치하고, 인증하고, `query()` 한 줄을 돌려 엔진이 도는지 확인한다. 거창할 것 없다. 이 챕터의 목표는 딱 "부릉" 소리를 듣는 것이다.

## 설치 — `uv add`

의존성은 `uv`로 관리한다. SDK를 프로젝트에 박는다.

```bash
uv add claude-agent-sdk
```

이러면 `pyproject.toml`에 의존성이 기록되고 `uv.lock`이 갱신돼, 다음에 `uv sync`로 같은 환경을 어디서든 재현할 수 있다. SDK는 내부적으로 Claude Code CLI를 함께 쓰므로, 실행 환경에 그 CLI가 준비돼 있어야 한다(설치 안내는 SDK 문서를 따른다).

## Vertex 인증

엔터프라이즈 환경에선 Anthropic API를 직접 부르는 대신 **Vertex AI**(Google Cloud의 모델 서빙)를 거치는 경우가 많다. 사내 GCP 프로젝트·결제·보안 경계 안에서 Claude를 쓰기 위해서다. 환경 변수로 "Vertex를 거치라"고 일러두고, 자격 증명은 ADC로 잡는다.

```bash
export CLAUDE_CODE_USE_VERTEX=1                 # Vertex 경로를 쓴다
export ANTHROPIC_VERTEX_PROJECT_ID=my-gcp-project
export CLOUD_ML_REGION=us-east5                  # 모델이 서빙되는 리전

gcloud auth application-default login            # ADC 자격 증명
```

`CLAUDE_CODE_USE_VERTEX=1`이 "직접 호출 말고 Vertex로"를 켜고, 프로젝트·리전을 일러준 뒤, `gcloud`의 **애플리케이션 기본 자격 증명(Application Default Credentials, ADC)**으로 인증을 잡는다. 키를 코드에 박지 않고 환경에서 받는 게 핵심이다.

> ⚠️ **자격 증명을 코드·로그에 남기지 마라.** 프로젝트 id·키·토큰은 환경 변수와 ADC로만 흐르게 한다. 인증 정보를 `print`하거나 로그에 찍지 않는다 — 운영의 기본이다.

## 첫 시동 — `query()` 한 줄

이제 엔진을 돌려 본다. 가장 작은 프로그램이다.

```python
import anyio
from claude_agent_sdk import query

async def main():
    async for msg in query(prompt="너는 어떤 내장 도구를 쓸 수 있어? wafer 수율 lot 파일을 읽을 수 있니?"):
        print(msg)

anyio.run(main)
```

돌리면 메시지가 *주르륵* 흘러나온다. 에이전트가 자기가 쓸 수 있는 도구를 설명하고, 맨 끝에 결과 메시지가 온다. 이 흐름을 봤다면 시동이 걸린 것이다 — 설치·인증·호출이 다 맞물렸다는 증거다.

> ⚙️ **에러가 난다면 대개 인증이다**: 첫 호출이 막히면 십중팔구 Vertex 환경 변수나 ADC다. 프로젝트 id·리전이 맞는지, `gcloud auth application-default login`을 했는지부터 본다. 모델 접근 권한이 GCP 프로젝트에 있는지도 확인한다.

## 시동이 걸렸다 — 이제 출발

여기까지가 Part 0이다. 우리는 *왜* 되돌리기인가를 세우고(0.1), 이 책이 *어디* 서는지 긋고(0.2), 차에 올라 *시동*을 걸었다(0.3).

다만 시동을 건 것과 운전하는 것은 다르다. 방금 `query()` 한 줄은 엔진이 돈다는 증거일 뿐, 아직 어디로도 가지 않았다. 진짜 운전 — 호출을 다루고, 능력을 주고, 앱으로 감싸고, 되돌릴 수 있는 상태를 짓는 일 — 은 Part 1부터다. 다음 챕터에서 그 `query()`를 제대로 들여다본다.

> ⚠️ **코드 미검증 — 검증 레포 실행 필요**: 위 `uv add` 패키지명·Vertex 환경 변수(`CLAUDE_CODE_USE_VERTEX`·`ANTHROPIC_VERTEX_PROJECT_ID`·`CLOUD_ML_REGION`)·`query()` 첫 호출은 설계 초안이다. 정확한 변수명·리전·러너는 검증 레포와 SDK 문서로 확인해야 한다.

---

## 핵심 정리

- **설치는 `uv add claude-agent-sdk`.** `pyproject.toml`·`uv.lock`에 박혀 `uv sync`로 환경이 재현된다. SDK는 Claude Code CLI를 함께 쓴다.
- **Vertex 인증은 환경 변수 + ADC다.** `CLAUDE_CODE_USE_VERTEX=1`로 경로를 켜고 프로젝트·리전을 일러준 뒤 `gcloud`의 ADC로 자격을 잡는다 — 키를 코드에 박지 않는다.
- **첫 `query()`가 흘러나오면 시동이 걸린 것이다.** 메시지가 주르륵 나오고 결과로 끝나면 설치·인증·호출이 맞물린 증거다. 막히면 대개 인증이다.
- **시동 ≠ 운전.** 한 줄은 엔진이 돈다는 증거일 뿐, 진짜 운전은 Part 1부터다.
