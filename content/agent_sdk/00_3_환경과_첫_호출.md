## 차에 올라 시동을 건다

0.2에서 우리는 탈것을 골랐다 — 내가 모는 차, Agent SDK. 이제 차에 올라 시동을 걸 차례다. 설치하고, 인증하고, `query()` 한 줄을 돌려 엔진이 도는지 확인한다. 거창할 것 없다. 이 챕터의 목표는 딱 "부릉" 소리를 듣는 것이다.

## 설치 — `uv add`

의존성은 `uv`로 관리한다. SDK를 프로젝트에 박는다.

```bash
uv add claude-agent-sdk
```

이러면 `pyproject.toml`에 의존성이 기록되고 `uv.lock`이 갱신돼, 다음에 `uv sync`로 같은 환경을 어디서든 재현할 수 있다. SDK는 내부적으로 Claude Code CLI를 함께 쓰므로, 실행 환경에 그 CLI가 준비돼 있어야 한다(설치 안내는 SDK 문서를 따른다).

## Bedrock 인증

엔터프라이즈 환경에선 Anthropic API를 직접 부르는 대신 **AWS Bedrock**(AWS의 모델 서빙)을 거치는 경우가 많다. 사내 AWS 계정·결제·보안 경계 안에서 Claude를 쓰기 위해서다. 환경 변수로 "Bedrock을 거치라"고 일러두고, 자격 증명은 bearer 토큰으로 잡는다.

```bash
export CLAUDE_CODE_USE_BEDROCK=1                 # Bedrock 경로를 쓴다
export AWS_REGION=ap-northeast-2                  # 모델이 서빙되는 리전
export AWS_BEARER_TOKEN_BEDROCK=...               # Bedrock API 키(bearer 토큰)
```

`CLAUDE_CODE_USE_BEDROCK=1`이 "직접 호출 말고 Bedrock으로"를 켜고, 리전을 일러준 뒤, **Bedrock API 키**를 `AWS_BEARER_TOKEN_BEDROCK`에 담아 인증을 잡는다. 키를 코드에 박지 않고 환경에서 받는 게 핵심이다.

> ⚠️ **자격 증명을 코드·로그에 남기지 마라.** 리전·키·토큰은 환경 변수로만 흐르게 한다. bearer 토큰을 `print`하거나 로그에 찍지 않는다 — 운영의 기본이다.

## 첫 시동 — `query()` 한 줄

이제 엔진을 돌려 본다. 가장 작은 프로그램이다.

```python
import anyio
from claude_agent_sdk import query

async def main():
    async for msg in query(prompt="너는 어떤 내장 도구를 쓸 수 있어? wafer 수율 lot 파일을 읽을 수 있니?"):
        print(msg)

anyio.run(main)
```

돌리면 메시지가 *주르륵* 흘러나온다. 에이전트가 자기가 쓸 수 있는 도구를 설명하고, 맨 끝에 결과 메시지가 온다. 이 흐름을 봤다면 시동이 걸린 것이다 — 설치·인증·호출이 다 맞물렸다는 증거다.

> ⚙️ **에러가 난다면 대개 인증이다**: 첫 호출이 막히면 십중팔구 Bedrock 환경 변수다. `AWS_REGION`이 맞는지, `AWS_BEARER_TOKEN_BEDROCK`이 유효한지부터 본다. 그 리전에서 해당 모델에 접근 권한이 있는지도 확인한다.

## 시동이 걸렸다 — 이제 출발

여기까지가 Part 0이다. 우리는 *왜* 되돌리기인가를 세우고(0.1), 이 책이 *어디* 서는지 긋고(0.2), 차에 올라 *시동*을 걸었다(0.3).

다만 시동을 건 것과 운전하는 것은 다르다. 방금 `query()` 한 줄은 엔진이 돈다는 증거일 뿐, 아직 어디로도 가지 않았다. 진짜 운전 — 호출을 다루고, 능력을 주고, 앱으로 감싸고, 되돌릴 수 있는 상태를 짓는 일 — 은 Part 1부터다. 다음 챕터에서 그 `query()`를 제대로 들여다본다.

> ✅ **검증됨 (검증 레포)**: `uv add claude-agent-sdk` 설치와 Bedrock 환경 변수(`CLAUDE_CODE_USE_BEDROCK`·`AWS_REGION`·`AWS_BEARER_TOKEN_BEDROCK`)로 첫 `query()`가 실제로 흘러나옴을 확인했다(`probes/basics_probe.py`, ap-northeast-2 · opus-4-8). 검증 레포 전체가 이 Bedrock 경로로 돈다(`.env.example` 참조).

## 핵심 정리

- **설치는 `uv add claude-agent-sdk`.** `pyproject.toml`·`uv.lock`에 박혀 `uv sync`로 환경이 재현된다. SDK는 Claude Code CLI를 함께 쓴다.
- **Bedrock 인증은 환경 변수 + bearer 토큰이다.** `CLAUDE_CODE_USE_BEDROCK=1`로 경로를 켜고 리전을 일러준 뒤 `AWS_BEARER_TOKEN_BEDROCK`으로 자격을 잡는다 — 키를 코드에 박지 않는다.
- **첫 `query()`가 흘러나오면 시동이 걸린 것이다.** 메시지가 주르륵 나오고 결과로 끝나면 설치·인증·호출이 맞물린 증거다. 막히면 대개 인증이다.
- **시동 ≠ 운전.** 한 줄은 엔진이 돈다는 증거일 뿐, 진짜 운전은 Part 1부터다.
