# 4.4 분석 결과의 staleness — 재집계와 옛 결론

## 이 챕터에서 배우는 것

- 분석 결과는 원천 사실 위에 세운 파생물이라, 원천이 바뀌면 낡는다
- 파생물은 저절로 갱신되지 않는다 — 캐시 무효화와 같은 문제
- 의존성을 기록해 "무엇이 바뀌면 어느 결론이 낡는지" 잇는 법
- 옛 결론을 지우지 않고 "그때 기준"으로 변호하는 닫기

---

## 4.3에서 4.4로

4.3에서 사실에는 시간이 둘이라는 걸 봤다 — 참이었던 때와 알게 된 때. 그래서 옛 사실과 정정된 사실이 나란히 살 수 있었다.

그런데 지금까지의 시간 이야기는 모두 *원자적 사실* 하나에 대한 것이었다. "lot A 수율 = 89%" 같은. 분석 에이전트가 실제로 만들어내는 건 그게 아니다. 에이전트는 그런 사실 수십, 수백 개를 모아 *결론*을 낸다. "1분기 평균 수율 91%, 이상치는 equip_X에 몰려 있다." 이 결론은 어떻게 되는가, 밑에 깔린 lot A가 92%에서 89%로 정정되면?

## 결론은 파생물이다

핵심을 먼저 박자. 분석 결과는 **파생 결과(derived result)** — 원천 사실들 위에 세운 2차 산물이다. 평균은 개별 수율에서 나오고, 추세는 시계열에서 나오며, "원인은 장비"라는 판단은 여러 lot의 공통점에서 나온다.

파생물의 운명은 원천에 묶여 있다. 원천이 바뀌면 파생물은 **낡는다(stale)** — 더 이상 현재 데이터를 반영하지 않는 상태가 된다. lot A가 89%로 정정되는 순간, 그것을 포함해 계산한 "1분기 평균 91%"는 조용히 틀린 값이 된다. 아무 에러도 없이.

문제는 이거다 — **파생물은 저절로 갱신되지 않는다.** 원천 사실을 무효화(4.2)해도, 그 사실로 만든 결론은 메모리 어딘가에 옛값 그대로 누워 있다.

## 캐시와 같은 문제 (비유)

AI 엔지니어에게 이건 낯선 문제가 아니다. **캐시 무효화(cache invalidation)** 바로 그것이다.

캐시는 원본에서 계산한 값을 빠르게 쓰려고 따로 둔 사본이다. 원본이 바뀌면 캐시는 stale해지고, 누군가 *무효화해주지 않으면* 낡은 값을 계속 내놓는다. 분석 결론이 정확히 이 캐시다 — 원천 사실에서 계산해 저장해둔 값이고, 원천이 바뀌면 낡지만, 알아서 갱신되진 않는다.

더 구체적으로는 **스프레드시트의 수식 셀**에 가깝다. 원천 셀이 바뀌면 그것을 참조하는 수식 셀이 자동 재계산된다. 스프레드시트가 이걸 해낼 수 있는 건 *어느 셀이 어느 셀을 참조하는지*, 즉 의존성을 추적하기 때문이다. 분석 메모리도 똑같은 추적이 있어야 한다.

```python
# 결론에 '무엇에 기댔는지'와 '언제 기준인지'를 박는다
conclusion = {
    "id": "C1",
    "claim": "1분기 평균 수율 91%",
    "depends_on": ["lot_A", "lot_B", "lot_C"],  # 계보 — 사실 또는 다른 결론의 id
    "as_of": "2026-04-01",                       # 이 시점 데이터 기준
    "stale": False,
}

def on_fact_changed(changed_id, conclusions):
    """바뀐 것에 기댄 결론을 stale로 — 전이적으로 위까지 전파한다."""
    dirty = {changed_id}
    while True:
        newly = [c for c in conclusions
                 if not c["stale"] and dirty & set(c["depends_on"])]
        if not newly:
            break                          # 더 번질 곳이 없으면 멈춘다
        for c in newly:
            c["stale"] = True              # 지우지 않는다 — '재검토 필요' 표시
            dirty.add(c["id"])             # 이 결론에 기댄 상위도 다음 회차에 stale
```

`depends_on`이 스프레드시트의 셀 참조에 해당한다. lot A가 정정되면 `on_fact_changed("lot_A", ...)`가 그것에 기댄 결론에 `stale` 깃발을 세우고, *그 결론에 기댄 상위 결론까지* 연쇄로 번진다 — "분기 추세"가 "1분기 평균"에 기댔다면, lot 하나가 흔들려도 추세까지 낡는다. 무관한 결론은 건드리지 않는다. 단 이 함수는 사실이 *정정*(무효화)됐을 때 부르는 것이다 — 같은 대상의 *새 측정*(다른 valid time)이라면 옛 결론은 여전히 유효하므로, 4.2처럼 정정인지 별개 측정인지부터 가른 뒤 호출한다.

> 💡 **비유의 한계**: 스프레드시트의 진짜 힘은 *전이* 재계산이다 — 셀 하나가 바뀌면 그걸 쓴 셀, 또 그 셀을 쓴 셀까지 자동으로 다시 푼다. 분석 결론에선 공짜가 아니다. `depends_on`(계보, lineage)을 결론 만들 때 직접 기록해야 하고, 전이 전파도 위 `while` 루프처럼 손수 짜야 한다. 게다가 팹 데이터는 수십 기가급이라 매번 전부 재계산은 비현실적이라, "자동 전부 재계산"이 아니라 "기록된 계보로 영향받은 것만 골라 식히기"가 현실의 모양이다.

## 낡았다고 지울 것인가

`stale` 깃발을 세운 다음이 갈림길이다. 셋 중 하나다.

- **즉시 재집계(recompute)** — 바뀐 원천으로 결론을 다시 계산한다. 정확하지만 비싸고, 자주 바뀌면 계속 다시 돈다.
- **지연 재집계** — stale 표시만 해두고, 그 결론을 *다시 쓸 때* 재계산한다. 안 쓰일 결론에 비용을 안 들인다.
- **만료 후 재검토** — "이 결론은 4월 1일 데이터 기준"을 명시하고, 일정 시간이 지나거나 원천이 흔들리면 사람이/에이전트가 다시 본다.

무엇을 고르든, 한 가지는 4.3에서 그대로 가져온다 — **옛 결론을 지우지 않는다.** stale로 표시하되 `as_of`와 함께 남긴다. 그래야 "4월에 왜 91%라고 결론 냈지?"라는 물음에, "그때 그 시점 데이터로는 91%가 맞았다"고 변호할 수 있다. 결론에도 원자 사실처럼 *시점*을 박는 것이다.

## 그래서 — 사실도 결론도, 지우지 말고 시간과 함께

Part 4를 닫자. 네 챕터가 한 방향을 가리킨다.

망각은 안 쓰는 걸 식히는 설계였고(4.1), 무효화는 덮어쓰기 대신 "여기까지 유효" 표시였고(4.2), 두 시간은 참인 때와 안 때를 가르는 모델이었고(4.3), staleness는 그 원리를 *파생 결론*에까지 끌고 온 것이다(4.4). 공통 원리는 하나다 — **지우지 말고, 시간과 함께, 무효화로 다뤄라.**

그러니 내 분석 메모리는 원자 사실과 파생 결론 *둘 다*에 "언제 기준이고 무엇에 기댔나"를 박아야 한다. 그러면 원천이 흔들려도 옛 결론을 변호하면서 새 결론으로 간다. 둘 중 하나를 버리지 않는다.

여기까지가 원리다. 유형(1), 저장(2), 인출(3), 잊기와 시간(4). 이제 손을 움직일 차례다 — 이 원리들을 가장 작은 메모리로 직접 구현하는 Part 5로 간다.

> ✅ **검증됨 (`playground/handbook/memory`).** 위 `on_fact_changed`의 전이 전파 — 바뀐 사실에 직접 기댄 결론뿐 아니라 그 결론에 기댄 상위 결론까지 stale이 번지고, 무관한 결론은 건드리지 않는 동작 — 을 검증 레포에서 확인했다(`checks/ch04_4_staleness.py` · `test_part4.py`). 외부 의존이 없어 본문 로직 그대로 돈다.

## 핵심 정리

- **분석 결론은 원천 사실의 파생물이다.** 평균·추세·원인 판단은 모두 2차 산물이라, 원천이 바뀌면 조용히 낡는다.
- **파생물은 저절로 갱신되지 않는다 — 캐시 무효화 문제다.** 원천을 고쳐도 결론은 옛값 그대로 누워 있으므로, 의존성을 추적해 골라 식혀야 한다.
- **의존성(계보)을 결론에 박아둬야 무효화가 가능하다.** `depends_on`이 없으면 무엇이 바뀔 때 무엇이 낡는지 알 수 없고, 전부 재계산은 비현실적이다.
- **옛 결론도 지우지 말고 시점과 함께 변호한다.** `as_of`를 박아 "그때는 그게 맞았다"를 지키는 것이 Part 4 전체를 관통하는 원리다.
