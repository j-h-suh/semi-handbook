# 에이전트 메모리 핸드북 — 목차 (초안)

**대상 독자**: 메모리 프레임워크가 우후죽순인데 "뭘 써야 하지"에서 막힌 엔지니어
**목표**: 내 에이전트에 *어떤 기억을 어떻게 설계해 줄지* 판단하고 직접 구현하기
**분량**: 약 140페이지 (26챕터 · 원리형 4–5p / 코드·mini형 6–7p)
**언어**: 한국어 (기술 용어 영어 병기)
**자매서**: 에이전트 SDK 핸드북(단기 상태 = 세션·event) — 이 책은 그 위의 **장기 기억**. 엔진 내부 메커니즘은 클로드 핸드북.

> 컨셉: **"도구는 바뀐다, 기억의 원리는 남는다."** 프레임워크 카탈로그가 아니라 설계서.

## 작성 가이드 (이 핸드북 특유)

상위 스타일은 `/CLAUDE.md`, 세부 표기는 `docs/handbook-conventions.md`. 아래는 이 책만의 추가 가드레일.

- **직교**: 원리 → 의사결정 → 직접 구현 축. **프레임워크 사용법 나열 금지** — Part 6도 "사용법"이 아니라 *원리로 분류·평가*. 자매서(Agent SDK·클로드) 메커니즘은 재설명하지 않는다.
- **도메인**: 반도체 데이터 분석 예제 유지(lot 수율 등). 내부 제품명 0건.
- **품질 합격선**: 매 챕터는 `chapter-rubric.md`(A 객관 가드 + B 질적 기준)를 통과한다. 기준 챕터 = `04_3_두_개의_시간.md`.
- **각 챕터**: CLAUDE.md 챕터 구조 — "이 챕터에서 배우는 것" → 본문 → 핵심 정리 → 다음 티저.
- **척추**: Part 5(직접 만든 원리)로 Part 6(남의 프레임워크)을 평가하는 흐름.
