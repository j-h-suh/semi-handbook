# 횡단 용어 보완 항목 (claude_code)

> 목적: 한 챕터에 한정되지 않고 여러 챕터에 반복 등장하는 CS/도메인 용어 중 정의/설명/병기가 부족한 항목을 누적.
> 진행: 챕터 작업 중 발견 → 여기에 추가만 → 1순회 종료 후 일괄 표준화.
>
> 챕터 한정 보완 (특정 위치의 압축적 설명 확장, 코드 보완 등)은 `_handbook_revisions.md`에서 관리.

## 항목 구조

```
### [용어] SSE (Server-Sent Events)
- **첫 등장**: 02_3 / "스트리밍" 섹션
- **반복 등장**: 07_1, 07_4 등
- **현상**: 풀네임 병기 없음, 한 줄 정의 없음
- **요청**: 첫 등장 위치에 `**서버-전송 이벤트(Server-Sent Events, SSE)**` + 한 줄 정의 도입.
- **표준 정의안**: "...HTTP 위에서 서버가 클라이언트로 단방향 스트리밍하는 표준."
- **상태**: [pending]
```

상태 라벨:
- `[pending]` — 협의 전, 일단 추가
- `[decision-needed]` — 정의 표현/도입 위치 정해야 함
- `[in-progress]` — 표준화 작업 중
- `[done]` — 모든 등장 위치에 일관 적용 완료

## 표준화 작업 원칙 (1순회 종료 후 적용)

1. **첫 등장 위치 확정**: 등장 챕터 중 가장 빠른 곳에 정식 도입 (`**한국어(영어)**` + 한 줄 정의).
2. **이후 등장**: 굵게 처리 없이 자연스럽게 사용. 필요 시 첫 등장 챕터로 cross-link.
3. **약어 일관성**: 첫 도입 후 동일 약어 사용 (예: SSE).
4. **챕터 간 정의 충돌 점검**: 동일 용어를 다른 챕터에서 다르게 설명한 경우, 첫 등장 위치의 정의로 통일.
