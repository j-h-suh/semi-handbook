## Part 1 — 하네스 해부 (01_1 / 01_2 / 01_3)

### 01_1 하네스란 무엇인가
- **[H] 게이트웨이 정의가 GitHub 1차 출처와 정면 충돌** (36·46~47행): Hermes·OpenClaw는 자체 루프를 돌리는 computer-use/데몬 에이전트, '코딩 하네스 호출'은 선택적 ACP 위임일 뿐 → 정의를 '메신저 위에서 자체 루프를 돌리는 하네스'로 바로잡고 호출은 '(선택적) 위임'으로 격하.
- **[H] 비교표 'Hermes 상태=파일+SQLite+사용자모델'이 정본(3.3·07_1·1.3)과 충돌** (72행): 가운데 셀을 정본 어휘 '증류'로('원본+증류+사용자모델'), SQLite 같은 구현 세부는 직교로 제거.
- **[H] 권한 '5가지 모드+Hook'의 맨숫자 '5'가 무출처·버전의존** (71행): '5'를 빼고 다른 칸과 같은 추상 수준('모드+Hook')으로, 정확한 수는 클로드 핸드북 위임.
- **[H] 비교표가 CLI vs 게이트웨이 범주 혼합을 무신호로 섞음** (64~74행): "앞의 둘은 CLI, 세 번째는 게이트웨이인데도 — 같은 다섯 칸으로 나뉜다"는 구절로 혼란을 'aha'로 전환.

## Part 4 — 확장 축 (04_1 / 04_2 / 04_3)

> **공통 [H] ACP 프로토콜 정체성 오인 — 챕터 전체가 잘못된 전제 위에 섬** (04_2 제목·16·24~26·42~45·71~73행; 02_3·04_1·04_3 전파): Zed/JetBrains의 'Agent Client Protocol'은 에디터↔코딩에이전트 프로토콜인데 책은 '에이전트가 에이전트에게 위임'(A2A)을 붙임 → (A) 명칭을 A2A로 바꾸고 출처+시점태그 달거나 (B) 에디터↔코딩에이전트로 재정의해 '하네스가 하네스를 부른다' 프레임 폐기 + 'ACP가 세 프로토콜로 갈려 쓰인다' 💡 추가. *(시리즈 차원 결정 필요)*

- **[M] 시종 추상적 — 실물 MCP 서버/실명 하네스 0개** (22·40~44행): 파일시스템·GitHub MCP 서버 하나를 실명으로.
- **[M] '게이트웨이'가 정의·굵게 없이 등장** (28·44행): 첫 등장 반 줄 환기.

### 04_2 ACP

## 전체 패턴 진단 (3대 구조 문제)

**1. 신생 표준·신생 하네스의 1차 출처 미검증이 가장 치명적·광범위 (High 절반 이상).**
ACP 프로토콜 오인이 02_3·04_1·04_2·04_3 네 챕터를 관통하며 제목·정의·비교표를 잘못된 전제(에이전트↔에이전트 위임) 위에 세움. 게이트웨이 정의(01_1)도 Hermes·OpenClaw의 자체 루프 성격을 'GitHub 1차 출처 확인'을 요구한 바로 그 자리에서 어긋나게 단정. **책 스스로 건 가드레일을 본문 단정형이 반복적으로 앞질러 감.** → ACP를 A2A/Agent Client Protocol 중 무엇으로 다룰지 **시리즈 차원 결정** + 게이트웨이·Hermes·OpenClaw를 GitHub 1차 출처로 일괄 재검증이 최우선.

**2. 정본(canonical) 어휘·사실이 챕터 간에 표류 (특히 비교표·종합표).**
'CLI 하네스'(01_1) vs '코딩 하네스'(02_1), 'Hermes' vs 'Hermes Agent', 'Hermes 상태=파일+SQLite'(01_1) vs '증류'(3.3·07_1), 'bi-temporal' 귀속(07_3 내부 모순), 시리즈 권수 '여섯 권' vs 실제 5권 열거. **비교를 파는 책에서 내부 명칭·사실이 흔들리면 자기모순으로 읽힘.** → **마스터 글로서리**(용어·제품 사실·범주명 정본 1개)로 전 챕터 정합.

**3. 비유-산출물 정합 실패 + B2(축 가로지르기) 시연 부족.**
중심 비유가 산출물에서 회수 안 됨(주기율표 '빈칸'이 표엔 0개·03_4), 한 섹션 두 비유 경합(캐시 vs 정유·03_3, 조수 vs 서브루틴·06_1), ledger/journal 오매핑(03_1). 동시에 '여러 하네스가 같은 축을 다르게 푸는 구체 대조'(기준 1.2의 핵심)가 추상 나열에 그침(03_2·04_3·05_2·05_3·06_1). → 각 챕터 ① 중심 비유 1개+한계 ② 표/산출물이 비유 핵심을 실제로 보여주는지 ③ 최소 1개 하네스 가로지르기 미니 대조 — 일관 템플릿 적용.
