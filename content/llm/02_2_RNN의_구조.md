# 2.2 RNN의 구조 — hidden state가 기억이다

## 이 챕터에서 배우는 것

- RNN이 2.1의 세 요구(가변 길이·순서·파라미터 공유)를 한 번에 푸는 방식
- hidden state — 지금까지 읽은 것을 담은 고정 크기 기억
- RNN을 "시퀀스에 대한 fold"로 보는 관점
- 이 구조에 이미 심어진 두 한계의 씨앗 — 단일 채널과 순차성

> 이 장은 RNN을 *빠르게 설정*한다. 사이토 2권에서 RNN을 다뤘다면 복습이고, 처음이라도 따라올 수 있게 자족적으로 둔다. 무게는 이 책이 쓸 부분 — 구조에 박힌 한계 — 에 싣는다.

---

## 메모리를 들고 순서대로

2.1에서 필요한 기계의 모양을 그렸다. 가변 길이를 순서대로 읽으며, 위치와 무관하게 같은 처리를 하고, 지금까지의 요약을 들고 다음으로 넘어가는 기계. **RNN(Recurrent Neural Network, 순환 신경망)** — 하나의 hidden state를 매 스텝 갱신하며 시퀀스를 훑는 신경망 — 이 정확히 그것이다.

핵심은 **은닉 상태(hidden state)** — 지금까지 읽은 시퀀스를 압축해 담은 고정 크기 벡터 — 하나다. 토큰을 하나 읽을 때마다, 새 토큰과 직전 상태를 합쳐 상태를 갱신한다. 갱신 규칙은 이렇다.

$$h_t = \tanh(W_x x_t + W_h h_{t-1} + b)$$

$x_t$는 지금 읽는 토큰의 벡터, $h_{t-1}$은 직전까지의 기억, $h_t$는 갱신된 기억이다. 같은 $W_x, W_h$를 *매 스텝 똑같이* 쓴다는 점이 중요하다 — 이 파라미터 공유가 2.1의 세 번째 요구를 푼다. 위치가 1번이든 500번이든 같은 규칙으로 처리한다.

## fold로서의 RNN

ML 엔지니어에게 익숙한 그림으로 옮기면, RNN은 *시퀀스에 대한 fold(reduce)*다. 누적값(accumulator)을 들고 리스트를 순회하며 매 원소로 누적값을 갱신하는 그 패턴. 여기서 누적값이 hidden state다.

```python
import numpy as np

def rnn_cell(x_t, h_prev, W_x, W_h, b):
    return np.tanh(x_t @ W_x + h_prev @ W_h + b)   # 한 스텝 갱신

def run_rnn(xs, h0, W_x, W_h, b):
    h = h0
    for x_t in xs:              # 시퀀스를 순서대로 fold
        h = rnn_cell(x_t, h, W_x, W_h, b)
    return h                    # 마지막 h = 시퀀스 전체의 요약
```

`run_rnn`의 `for` 루프가 fold 그 자체다. 리스트가 몇 개든 돌면 되니 *가변 길이*가 풀리고, 누적 순서가 결과에 반영되니 *순서*가 보존된다. 2.1에서 막혔던 세 벽이 이 짧은 루프 하나로 무너진다.

마지막 `h`는 시퀀스 전체를 담은 한 벡터다. 분류라면 여기에 출력층을 붙이고, 다음 토큰 예측이라면 매 스텝의 `h`마다 예측을 붙인다(2.5에서 본다).

## 구조에 이미 박힌 두 한계

RNN은 우아하게 작동하지만, 바로 이 구조에 *이 책 전체를 끌고 갈 두 한계의 씨앗*이 이미 들어 있다. 지금 심어두고, 4.1에서 거둔다.

첫째, **모든 정보가 하나의 채널을 지난다.** 500번째 토큰을 처리할 때, 1번 토큰의 정보는 오직 `h`라는 고정 크기 벡터를 *거쳐서만* 전해진다. 멀리서 온 정보일수록 그동안 수백 번 덮어쓰인 `h` 안에서 희미해진다. 이게 장거리 의존 문제의 씨앗이다.

둘째, **`for` 루프는 순차적이다.** `h_t`는 `h_{t-1}` 없이 계산할 수 없다. 시퀀스를 건너뛰며 병렬로 처리할 방법이 구조적으로 없다. 이게 병렬화 불가의 씨앗이다.

> 💡 **씨앗은 지금 심고, 4.1에서 거둔다**: 두 한계는 지금은 작은 흠처럼 보인다. 짧은 시퀀스에선 실제로 거의 문제가 안 된다. 하지만 이 책의 후반에서, 시퀀스가 길어지고 스케일이 커질 때 이 두 씨앗이 LSTM의 운명을 가르는 한계로 자란다. RNN의 우아함과 그 우아함의 대가를 함께 기억해 두자.

vanilla RNN에는 더 급한 문제가 하나 있다. 단일 채널의 기억이 *너무 빨리* 희미해진다는 것이다. 몇십 스텝만 지나도 초반 정보가 거의 사라진다. 이 기억 소실을 게이트로 완화한 것이 다음 장의 LSTM이다.

## 핵심 정리

- **RNN은 hidden state 하나로 2.1의 세 벽을 푼다.** 가변 길이(루프), 순서(누적), 파라미터 공유(같은 가중치 재사용)를 한 번에 해결한다.
- **hidden state는 고정 크기 기억이다.** 지금까지 읽은 시퀀스를 한 벡터로 압축해 다음 스텝으로 들고 간다.
- **RNN은 시퀀스에 대한 fold다.** 누적값(hidden state)을 들고 순회하며 갱신하는 그 패턴이며, `for` 루프가 그 정체다.
- **구조에 두 한계의 씨앗이 있다.** 모든 정보가 단일 채널을 지나고(장거리 의존), 루프가 순차적이다(병렬화 불가). 4.1에서 거둘 씨앗이다.
- **vanilla RNN은 기억이 너무 빨리 샌다.** 단일 채널이 금세 희미해지는 이 문제를 게이트로 완화한 게 다음 장의 LSTM이다.
