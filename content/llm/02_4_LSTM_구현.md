# 2.4 LSTM 구현 — 셀 하나를 NumPy로

## 이 챕터에서 배우는 것

- LSTM 셀 하나를 NumPy로 직접 짜 보며 2.3의 직관을 코드에 대응시키기
- 세 게이트와 셀 갱신이 코드에서 어떻게 단 몇 줄로 떨어지나
- 시퀀스 전체를 셀로 훑는 fold가 RNN과 같은 모양임을 확인하기

> 이 장은 *이해를 위한 스케치*다. 실제로는 프레임워크의 검증된 LSTM을 쓰지, 이 코드를 쓰진 않는다. 목적은 게이트가 손에 잡히게 하는 것이다.

---

## 직관을 회로로 내린다

2.3에서 LSTM을 밸브 달린 컨베이어 벨트로 그렸다. 이제 그 그림을 NumPy 셀 하나로 내린다. 게이트는 곱셈 한 번, 셀 갱신은 더하기 한 번이다 — 직관이 코드에선 의외로 단순하다.

```python
import numpy as np

def sigmoid(z):
    return 1.0 / (1.0 + np.exp(-z))

def lstm_cell(x_t, h_prev, c_prev, p):
    # 입력 토큰과 직전 hidden 을 한 벡터로 합친다
    z = np.concatenate([x_t, h_prev])

    f = sigmoid(z @ p["Wf"] + p["bf"])    # 망각: 셀에서 무엇을 지울까 (0~1)
    i = sigmoid(z @ p["Wi"] + p["bi"])    # 입력: 무엇을 새로 써넣을까 (0~1)
    o = sigmoid(z @ p["Wo"] + p["bo"])    # 출력: 무엇을 내보낼까 (0~1)
    g = np.tanh(z @ p["Wg"] + p["bg"])    # 후보: 써넣을 새 내용 (-1~1)

    c = f * c_prev + i * g                # 셀 갱신: 지우고(f) 더한다(i)
    h = o * np.tanh(c)                    # hidden: 셀에서 내보낼 만큼만(o)
    return h, c
```

2.3의 세 밸브가 `f`, `i`, `o` 세 줄에 그대로 대응한다. 모두 `sigmoid`라 0~1 값이고, 곱셈으로 "얼마나 통과시킬지"를 조절한다. 핵심은 셀 갱신 한 줄이다.

```python
c = f * c_prev + i * g
```

이 한 줄이 컨베이어 벨트의 정체다. `f`가 1에 가까우면 `c_prev`가 *거의 그대로* 흘러간다 — 정보가 보존되는 통로. `i * g`가 그 위에 새 내용을 *더한다*. 덮어쓰기가 아니라 지우기와 더하기의 조합이라, 2.2의 vanilla RNN처럼 통째로 새로 쓰지 않는다. 이 "더하는 통로"가 긴 기억을 가능하게 한다.

## 시퀀스를 훑는다 — 또 하나의 fold

셀은 한 스텝을 처리한다. 시퀀스 전체는 2.2에서와 똑같이 fold로 훑는다. 다만 이번엔 hidden과 셀, 두 상태를 함께 들고 간다.

```python
def run_lstm(xs, h0, c0, p):
    h, c = h0, c0
    for x_t in xs:                       # 시퀀스를 순서대로
        h, c = lstm_cell(x_t, h, c, p)   # 두 상태를 함께 갱신
    return h, c
```

`run_lstm`의 모양이 2.2의 `run_rnn`과 판박이다. 누적값이 하나(`h`)에서 둘(`h`, `c`)로 늘었을 뿐, *순서대로 fold하는 구조*는 똑같다. 그리고 바로 그 똑같음이 중요하다 — LSTM도 결국 `for` 루프 안에 있다. 2.2에서 심은 순차성의 씨앗이 LSTM에도 고스란히 있음을, 이 코드가 다시 확인해 준다.

> 💡 **게이트는 따로 배우는 게 아니다**: `Wf`, `Wi`, `Wo`, `Wg` 네 묶음의 가중치는 모두, 1권에서 본 그 최적화로 *동시에* 학습된다. "언제 무엇을 잊고 기억할지"의 규칙을 사람이 짜 넣는 게 아니라, 데이터가 게이트의 여닫음을 빚는다. 우리가 한 일은 게이트가 들어갈 *자리*를 설계한 것뿐이다.

이제 셀이 손에 있다. 그런데 이걸로 "언어 모델"을 만들려면 한 가지가 더 필요하다 — 매 스텝의 hidden state를 *다음 토큰에 대한 예측*으로 바꾸는 출력층, 그리고 그 예측을 이어 붙여 텍스트를 생성하는 법. 다음 장에서 LSTM을 언어 모델로 세운다.

## 핵심 정리

- **게이트는 sigmoid 한 줄씩이다.** 망각·입력·출력이 각각 0~1 값을 내고, 곱셈으로 흐름을 조절한다 — 2.3의 세 밸브가 코드 세 줄로 떨어진다.
- **셀 갱신은 지우기와 더하기다.** `c = f * c_prev + i * g`. 덮어쓰기가 아니라 보존 통로 위에 더하는 구조가 긴 기억의 비결이다.
- **시퀀스 처리는 또 하나의 fold다.** `run_lstm`은 `run_rnn`과 판박이고, 누적값이 둘로 늘었을 뿐 순차 구조는 같다.
- **게이트 가중치는 데이터가 빚는다.** 네 가중치 묶음이 함께 학습되며, 우리가 설계한 건 게이트의 자리뿐이다.
- **언어 모델엔 출력층이 더 필요하다.** hidden을 다음 토큰 예측으로 바꾸고 이어 붙이는 법이 다음 장이다.
