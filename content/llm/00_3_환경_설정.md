## 최소한의 도구

거창한 환경은 필요 없다. Mini LLM은 노트북 CPU에서도 (느리지만) 돈다.

- **Python 3.12 이상**
- **PyTorch** — Part 5부터 모델을 짓는 데 쓴다
- **NumPy** — Part 1~4에서 원리를 스케치하는 데 쓴다

설치는 셸에서 한 번이면 된다.

```bash
uv add torch numpy
```

> ⚙️ **GPU는 있으면 좋고, 없어도 된다**: 이 책의 Mini GPT는 작아서 CPU로도 학습이 가능하다. GPU가 있으면 Part 6~7의 학습이 빨라지지만, 없다고 막히지 않는다. 원리를 이해하는 데 큰 하드웨어는 필요 없다 — 그게 "Mini"로 가는 이유 중 하나다.

## 두 층의 코드, 언제 무엇을 쓰나

설치하며 도구가 둘인 게 눈에 띈다. 이 책의 코드는 *두 층*으로 나뉘기 때문이다.

- **Part 1~4 (원리)**: NumPy. 토큰화, 임베딩, RNN/LSTM 셀, Attention의 *원리*를 군더더기 없이 스케치한다. 자동 미분도 GPU도 없이, 연산의 *모양*만 투명하게 본다.
- **Part 5~7 (구현)**: PyTorch. 학습되는 진짜 모델을 짓는다. 자동 미분, 최적화, 검증된 레이어가 여기서 필요해진다.

그래서 방금 설치한 PyTorch의 *코드*는 한참 뒤(5.1)에야 처음 등장한다. 지금은 깔아만 두고, Part 1~4는 NumPy로 걷는다. 둘을 섞지 않는 이 규율이 책 전체를 관통한다 — 3.4에서 NumPy로 본 Attention을 5.1에서 PyTorch로 다시 만나는 식이다.

## 관통 예제의 데이터

이 책의 모든 코드는 하나의 데이터를 쓴다 — *캐릭터 레벨 텍스트*. 충분히 크면서도 작고, 외부 토크나이저 없이 글자만으로 다룰 수 있는 텍스트면 무엇이든 좋다(셰익스피어 전집 같은 단일 텍스트 파일이 흔한 선택이다).

데이터를 다루는 첫걸음은 그저 파일을 읽어 들여다보는 것이다. 여기엔 아직 PyTorch가 필요 없다 — 순수 파이썬이면 된다.

```python
from pathlib import Path

text = Path("input.txt").read_text(encoding="utf-8")

print(f"전체 글자 수: {len(text):,}")          # 예: 1,115,394
print(f"고유 글자 수: {len(set(text))}")        # 예: 65
print(text[:200])                              # 앞부분을 눈으로 확인
```

`set(text)`이 보여주는 *고유 글자 수*가 곧 우리의 어휘 크기가 된다 — 캐릭터 레벨이라 외부 사전 없이 텍스트 자신이 어휘를 정한다. 이 정수를 어떻게 모델이 먹을 형태로 바꾸는지는 1.2에서 본격적으로 다룬다. 지금은 데이터가 손에 있고, 그 모양을 눈으로 확인하는 것으로 충분하다.

> 💡 **왜 캐릭터 레벨인가, 다시**: 1.1에서 자세히 보겠지만, 미리 한 줄로 — 글자 단위는 외부 토크나이저가 필요 없어 *자족적*이다. 어휘가 곧 등장 글자 집합이라, 우리는 토크나이저가 아니라 *모델 본체*에 집중할 수 있다. 원리를 보는 데 이만한 단순함이 없다.

## 준비 완료의 기준

다음 장으로 넘어가도 되는 기준은 단순하다.

- `uv add torch numpy`가 에러 없이 끝났다.
- 위 파이썬 조각이 텍스트의 글자 수와 고유 글자 수, 앞부분 샘플을 출력한다.

이 둘이 되면 준비 끝이다. 도구가 손에 있고 데이터가 눈앞에 있으니, 이제 "텍스트를 수로 바꾸는" 첫 관문 — Part 1로 들어간다.

## 핵심 정리

- **환경은 최소면 된다.** Python 3.12+, PyTorch, NumPy. Mini GPT는 CPU로도 돌아, 큰 하드웨어가 필요 없다.
- **코드는 두 층이다.** Part 1~4는 NumPy로 원리를 스케치하고, Part 5~7은 PyTorch로 모델을 짓는다. PyTorch 코드는 5.1에서 처음 등장한다.
- **데이터는 캐릭터 레벨 텍스트다.** 외부 토크나이저 없이 글자만으로 다룬다. 파일을 읽어 글자 수·고유 글자 수를 확인하는 게 첫걸음이다.
- **고유 글자 집합이 곧 어휘다.** 텍스트 자신이 어휘를 정하므로 자족적이다 — 1.2에서 정수 변환을 본격적으로 다룬다.
- **준비 완료는 두 줄이다.** 설치가 끝나고, 데이터의 모양이 출력되면 Part 1로 넘어간다.
