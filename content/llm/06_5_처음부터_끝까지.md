# 6.5 처음부터 끝까지 — 데이터 로드부터 생성까지

## 이 챕터에서 배우는 것

- 흩어진 조각을 하나의 흐름으로 — 데이터에서 생성된 텍스트까지
- 배치 만들기 — 시퀀스를 잘라 입력과 한 칸 민 타깃으로
- 최소 학습 루프의 모양, 그리고 학습된 모델로 생성하기
- 이 작은 코드가 nanoGPT와 같은 골격이라는 것

---

## 기계 전체를 돌려본다

지금까지 부품과 동작을 따로 봤다 — 어휘(1.2), 모델(6.3), 생성(6.4). 이 장은 그 전부를 *하나의 흐름*으로 꿴다. 이 "기계"는 거창한 게 아니라 *데이터 → 배치 → 학습 → 생성*으로 한 바퀴 도는 파이프라인이다. 원시 텍스트 파일에서 출발해, 학습을 거쳐, 모델이 스스로 쓴 텍스트가 나오기까지 — 그 한 바퀴를 처음으로 끝까지 돌려본다.

## 데이터에서 배치로

먼저 텍스트를 정수로 인코딩하고(1.2), 학습용과 검증용으로 나눈다. 그리고 *배치*를 만든다 — 시퀀스에서 `block_size`만큼을 무작위로 잘라, 입력 `x`와 한 칸 민 타깃 `y`를 짝짓는다. 그 "한 칸 밀기"가 2.5에서 본 다음 토큰 목표 그대로다.

```python
import torch
from pathlib import Path

from vocab import encode, decode, vocab_size   # 1.2 의 어휘·인코딩

text = Path("input.txt").read_text(encoding="utf-8")   # 0.3 에서 준비한 데이터
data = torch.tensor(encode(text), dtype=torch.long)    # 정수 시퀀스로
n = int(0.9 * len(data))
train_data, val_data = data[:n], data[n:]              # 학습 90% / 검증 10%

def get_batch(split, batch_size, block_size):
    d = train_data if split == "train" else val_data
    ix = torch.randint(len(d) - block_size, (batch_size,))     # 무작위 시작점들
    x = torch.stack([d[i : i + block_size] for i in ix])
    y = torch.stack([d[i + 1 : i + block_size + 1] for i in ix])  # 한 칸 민 타깃
    return x, y
```

`y`가 `x`를 한 칸 민 것이라는 게 핵심이다. `x`의 각 위치에서 "바로 다음 글자"가 `y`의 같은 위치에 온다. 6.3의 `forward`가 이 `y`로 교차 엔트로피를 계산한다.

## 최소 학습 루프

이제 모델을 만들고, 옵티마이저를 붙이고, 루프를 돈다. 학습 루프의 골격은 1권에서 본 그 최적화의 모양 그대로다 — 순전파로 손실을 구하고, 역전파로 기울기를 얻고, 한 걸음 갱신한다.

```python
from minigpt import MiniGPT            # 6.3

model = MiniGPT(vocab_size, n_embd=128, n_head=4, n_layer=4, block_size=128)
optimizer = torch.optim.AdamW(model.parameters(), lr=3e-4)

for step in range(max_steps):
    x, y = get_batch("train", batch_size=32, block_size=128)
    logits, loss = model(x, y)         # 순전파 + 손실
    optimizer.zero_grad()
    loss.backward()                    # 역전파
    optimizer.step()                   # 한 걸음 갱신
```

단 몇 줄이다. `model(x, y)`가 logit과 손실을 함께 내고(6.3), 나머지 세 줄이 갱신이다. 옵티마이저·스케줄러·평가 같은 디테일은 7.2에서 제대로 다룬다 — 여기서는 *흐름의 모양*만 잡는다.

## 학습된 모델로 쓴다

학습이 끝나면, 6.4의 `generate`로 텍스트를 만든다. 씨앗으로 줄바꿈 하나를 주고, 500글자를 이어 받는다.

```python
from generate import generate         # 6.4

context = torch.tensor([encode("\n")], dtype=torch.long)
out = generate(model, context, max_new_tokens=500, temperature=0.8)
print(decode(out[0].tolist()))         # 1.2 의 decode 로 사람이 읽게
```

데이터 → 배치 → 학습 → 생성. 한 바퀴가 닫혔다. 이 전체가 캐릭터 레벨 nanoGPT의 골격이며, Part 1부터 쌓아온 모든 조각이 이 한 흐름 안에서 제자리를 찾는다.

> 💡 **무엇을 기대할까**: 작은 텍스트(예: 셰익스피어 한 편)로 이 모델을 학습시키면, 처음엔 무작위 글자를 뱉다가 점차 *그럴듯한 영어 비슷한 것*을 만든다. 철자, 단어 비슷한 덩어리, 줄바꿈과 대사 형식까지 흉내 낸다. 의미가 통하진 않아도, *구조*를 배운다. 작은 모델이 다음 토큰 예측만으로 언어의 형태를 잡아가는 걸 두 눈으로 보는 것 — 그게 이 책을 여기까지 끌고 온 목적이다.

> ⚠️ **이것은 골격이다**: 이 루프엔 검증 손실 측정, 체크포인트 저장, 학습률 스케줄 같은 실전 장치가 빠져 있다. 돌아가는 *모양*을 보여줄 뿐, 진지한 학습은 아니다. 그 살을 붙이는 게 Part 7이다.

기계가 돌아가는 걸 봤다. 그런데 우리는 모델을 *대충* 학습시켰다. 얼마나 잘 배웠는지 어떻게 *재는지*, 학습 루프를 어떻게 *제대로* 굴리는지, 무엇을 바꾸면 무엇이 좋아지는지 — 이 질문들이 Part 7의 몫이다. 그 첫걸음은 "언어 모델을 어떻게 평가하나"다.

> ✅ **코드 검증됨 — `playground/handbook/llm` 프로브 통과.** 이 장의 데이터→학습→생성 흐름은 검증 레포에서 실행 확인했다(probe_4_end2end). `get_batch`·옵티마이저·한 바퀴 전체 정상(작은 코퍼스에서 train perplexity 29→8, 생성물이 공백·단어 길이를 잡음).

## 핵심 정리

- **전체 흐름은 네 단계다.** 데이터 인코딩 → 배치 만들기 → 학습 루프 → 생성. Part 1부터의 조각이 여기서 한 흐름으로 모인다.
- **배치는 입력과 한 칸 민 타깃이다.** `y`가 `x`를 한 칸 민 것이라, 각 위치에서 다음 글자를 맞히는 2.5의 목표가 자연히 구현된다.
- **학습 루프는 1권의 그 모양이다.** 순전파로 손실, 역전파로 기울기, 한 걸음 갱신. 단 몇 줄이 본체다.
- **학습된 모델은 씨앗에서 텍스트를 잇는다.** `generate`로 한 글자씩 이어, 학습한 언어의 형태를 흉내 낸다.
- **이건 골격이지 실전이 아니다.** 평가·체크포인트·스케줄이 빠져 있다. 그 살을 붙이는 Part 7이 다음이다.
