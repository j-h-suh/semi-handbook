# 2.5 언어 모델로서의 LSTM — 다음 토큰 예측과 생성

## 이 챕터에서 배우는 것

- hidden state를 다음 토큰에 대한 확률로 바꾸는 출력층
- 언어 모델의 학습 목표 — 매 자리에서 다음 토큰 맞히기
- 자기회귀 생성 — 쓴 것을 도로 입력에 넣어 한 글자씩 이어가기
- 이 작은 LSTM이 정의하는 *과제*가 Transformer까지 그대로 이어진다

---

## hidden을 예측으로 바꾼다

2.4의 LSTM 셀은 매 스텝 hidden state `h`를 낸다. 이걸로 언어 모델을 만들려면 한 겹만 더하면 된다 — `h`를 *어휘 전체에 대한 점수*로 바꾸는 출력층이다.

```python
import numpy as np

def next_token_logits(h, W_out, b_out):
    return h @ W_out + b_out      # (vocab_size,) — 다음 토큰 각각의 점수

def softmax(z):
    z = z - z.max()
    e = np.exp(z)
    return e / e.sum()
```

`h`를 어휘 크기의 벡터로 투영하면, 각 토큰이 다음에 올 *점수(logit)*가 된다. 이걸 softmax로 확률 분포로 바꾼다. "지금까지 본 맥락에서, 다음 글자가 `a`일 확률 3%, `e`일 확률 12%…"가 나온다.

## 학습 목표 — 다음을 맞혀라

언어 모델의 과제는 단순하다. **매 자리에서 다음 토큰을 맞히는 것.** "hell"까지 봤으면 다음은 "o", "hello worl"까지 봤으면 다음은 "d".

학습할 때는 정답 시퀀스를 한 칸 밀어 타깃으로 쓴다. 입력이 `hello`면 타깃은 `ello␣` — 각 자리의 정답이 바로 다음 글자다. 모델의 예측 분포와 이 정답을 1권에서 본 그 교차 엔트로피로 맞춰가며 학습한다. 길이 T인 문장 하나가 T개의 "다음 맞히기" 예제가 되는 셈이다.

> 💡 **이 과제가 끝까지 간다**: "다음 토큰 맞히기"는 이 작은 LSTM만의 과제가 아니다. 5.7에서 봤듯 GPT의 과제가 정확히 이것이고, GPT-3도, 그 뒤의 거대 모델도 본질은 같다. 바뀌는 건 *과제*가 아니라 그 과제를 푸는 *아키텍처*다. LSTM에서 Transformer로 가는 이 책의 여정은, 같은 과제를 더 잘 푸는 길을 찾는 여정이다.

## 생성 — 쓴 것을 도로 넣는다

학습된 모델로 텍스트를 만드는 법은 **자기회귀(autoregressive)** — 자신이 방금 낸 출력을 다음 입력으로 도로 넣어 한 토큰씩 이어가는 방식 — 이다.

```python
def generate(seed_ids, params, n_steps):
    h, c = h0, c0
    ids = list(seed_ids)
    for x_t in embed(ids):                 # 씨앗을 먼저 흘려 넣어 맥락을 만든다
        h, c = lstm_cell(x_t, h, c, params)
    for _ in range(n_steps):
        probs = softmax(next_token_logits(h, params["W_out"], params["b_out"]))
        nxt = np.random.choice(len(probs), p=probs)   # 분포에서 한 토큰 샘플링
        ids.append(nxt)
        h, c = lstm_cell(embed([nxt])[0], h, c, params)  # 뽑은 걸 도로 입력
    return decode(ids)
```

씨앗 문자열로 맥락을 만든 뒤, 다음 토큰 분포에서 하나를 뽑고, 그 토큰을 *도로 입력에 넣어* 다음을 뽑는다. 자동완성이 자기가 제안한 단어를 받아 다음을 제안하듯, 모델이 자기 출력을 먹고 자란다. 이 루프가 텍스트를 만든다.

> ⚠️ **자기회귀의 함정**: 모델은 학습 때 *정답* 앞부분을 봤지만, 생성 때는 *자기 출력* 위에 쌓는다. 한 번 어긋난 토큰이 다음 입력이 되어 오류가 번질 수 있다. 또 매번 가장 높은 확률만 고르면 단조롭게 반복하고, 너무 무작위로 뽑으면 횡설수설한다. 이 균형(temperature 등)은 6.4에서 GPT의 생성을 다룰 때 자세히 본다.

이걸로 우리는 작지만 완전한 언어 모델을 가졌다. 다음 토큰 예측이라는 과제와, 자기회귀 생성이라는 패턴 — 이 책이 끝까지 쓸 두 기둥이 여기서 섰다.

그런데 한 시퀀스를 *다른* 시퀀스로 바꾸는 일, 이를테면 번역은 어떨까. 영어를 읽고 한국어를 쓰려면, 입력 전체를 이해한 뒤 출력을 생성하는 구조가 필요하다. 그 seq2seq 구조와, 거기서 드러나는 새로운 병목이 Part 3의 출발점이다.

## 핵심 정리

- **출력층이 hidden을 예측으로 바꾼다.** `h`를 어휘 크기로 투영해 logit을 내고, softmax로 다음 토큰 확률 분포를 얻는다.
- **언어 모델의 과제는 다음 토큰 맞히기다.** 정답을 한 칸 민 것이 타깃이며, 문장 하나가 여러 예제가 된다 — 1권의 교차 엔트로피로 학습한다.
- **이 과제는 Transformer까지 그대로 간다.** 바뀌는 건 과제가 아니라 아키텍처다. 이 책은 같은 과제를 더 잘 푸는 길을 찾는다.
- **생성은 자기회귀다.** 방금 뽑은 토큰을 도로 입력에 넣어 한 글자씩 잇는다 — 6.4 GPT 생성의 원형이다.
- **seq2seq가 다음 관문이다.** 한 시퀀스를 다른 시퀀스로 바꾸는 구조와 그 병목이 Part 3의 출발이다.
